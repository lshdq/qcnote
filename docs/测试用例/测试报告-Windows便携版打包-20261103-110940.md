## 发现的生产代码问题（仅记录，未修改）

1. **[轻微] `tools/build-portable.ps1` 冒烟结束全量杀进程**（约第 119 行）：`Get-Process qcnote ... | Stop-Process -Force` 会结束机器上**所有** qcnote 实例——打包机上若恰有用户正在运行的 qcnote（开发构建或便携版）会被误杀。建议改为对 `Start-Process -PassThru` 返回的 PID 定向结束（新增的 `tools/verify-portable.ps1` 已采用该做法，可参考）。不影响本次测试结果与产物正确性。

2. 无其他缺陷。
