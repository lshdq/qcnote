## TC-019 冒烟详情（tests/verify-draftcache.ps1，offscreen、黑盒文件级断言）

便携标记钉法：build\qcnote.portable → 缓存 build\drafts\、会话 build\qcnote.ini；每场景启动 4 s 后定向强杀；baselineHash 与 `Document::savedContentHash` 同法（内容 LF 归一化 UTF-8 的 SHA-256 小写 hex）。

| 场景 | 断言 | 结果 |
|------|------|------|
| A 静默恢复（合法条目，hash 相符） | A1 进程存活 / A2 无 QML 错误 / A3 旧条目已删 / A4 按新 uid 续写唯一条目 / A5 续写条目 content/url/name 正确 | 5/5 通过 |
| B 冲突弹窗（hash 不符） | B1 进程存活（弹窗打开不崩溃）/ B2 无 QML 错误 / B3 冲突条目保留（等用户决策，未静默应用） | 3/3 通过 |
| C 未命名恢复（url 空） | C1 进程存活 / C2 无 QML 错误 / C3 旧条目已删 / C4 续写唯一新条目 / C5 新条目 url 空/name 沿用未命名-1/content 正确 | 5/5 通过 |

说明：场景 A 的新条目本身即"恢复的修改经真实 1 s 防抖到期落盘"的产物（等待 4 s > 1 s 防抖），端到端覆盖真实计时器路径；「恢复/丢弃」按钮行为链路由 test_core 单测覆盖，对话框风格由 test_dialogstyle tc011 覆盖。冒烟后已验证：无 qcnote 进程残留，build 下标记/会话/缓存全部清理。
