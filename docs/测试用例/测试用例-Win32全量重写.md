# 测试用例：Win32 全量重写

## 测试范围

覆盖 `docs/需求文档/需求-Win32全量重写.md` 全部 A~F 功能项与非功能指标。分三层：

1. **单元测试（Catch2 v3，自动化）**：C++ 核心逻辑（编码探测/GBK 编解码/换行归一/查找引擎/替换展开/会话序列化/草稿管线/查找替换与多光标语义映射）
2. **进程级集成测试（pwsh 脚本驱动 exe，自动化/半自动）**：启动退出、命令行参数、单实例转发、会话/草稿端到端、指标测量
3. **真机人工验收清单**：无边框窗口交互、IME、DPI、主题观感、多光标手感（无 GUI 自动化路径的项）

## 用例列表

### 一、单元测试（Catch2）

#### U1 编码与换行（storage 层）

- **TC-U01: UTF-8 无 BOM 识别**：纯 ASCII / 中文 UTF-8 字节流 → 识别 UTF-8 无 BOM，解码正确
- **TC-U02: UTF-8 BOM 识别与剥离**：EF BB BF 前缀 → UTF-8 + hasBom=true，BOM 不进内容
- **TC-U03: GBK 识别**：GBK 中文字节（非合法 UTF-8）→ 识别 GBK，按 CP936 解码正确
- **TC-U04: GBK 无效字节容错**：混入无法解码字节 → U+FFFD 呈现，不崩溃
- **TC-U05: 纯 ASCII 判 UTF-8**：不误判 GBK
- **TC-U06: 强制编码解码**：指定 UTF-8/GBK 重载语义（含同一字节流两种解释）
- **TC-U07: GBK 编码校验**：含 emoji/生僻字内容 → 校验失败并返回首个不可编码字符与行号；纯 GBK 可表示内容校验通过
- **TC-U08: 换行归一化**：CRLF/CR/LF 混合 → 内容归一 LF，正确探测原风格（CRLF 优先级）；保存写回按记录风格；空文件/单行文件
- **TC-U09: BOM 写回**：hasBom=true 保存带 BOM；false 不新增；GBK 转 UTF-8 保存 BOM 取历史记录值

#### U2 查找引擎（editor 层）

- **TC-U10: 纯文本查找**：大小写敏感/不敏感、全字匹配（中英文词边界）
- **TC-U11: 正则模式**：PCRE 语义（`.` 不匹配换行、`^`/`$` 仅全文首尾、`(?m)` 生效）
- **TC-U12: 无效正则**：返回错误标志不崩溃（如 `(` 未闭合）
- **TC-U13: 零长度匹配跳过**：`a*` 模式空匹配不计入不高亮不替换
- **TC-U14: >10000 截断**：万级匹配计数返回溢出标志
- **TC-U15: 替换展开**：`$1..$99` 与 `\1..\9` 等价、`$$` 字面 `$`、引用不存在组输出空串、`$0` 整体匹配
- **TC-U16: 全部替换坐标计算**：按原文本坐标一次性计算，替换产物不再参与本轮匹配；从后往前应用偏移稳定
- **TC-U17: 环绕导航**：末尾 findNext 回到首个；头部 findPrev 回到末个；空匹配列表无操作

#### U3 会话与草稿（document 层）

- **TC-U18: 会话序列化往返**：文档列表（URL/光标/编码/uid/位置）+ active + 窗口几何 → 写 ini → 读回等价
- **TC-U19: 会话容错**：坏条目（URL 空、数值非法、目录路径）逐个丢弃不阻断；旧格式（无 uid/编码键）兼容
- **TC-U20: 窗口几何校验**：宽高钳制 [800×500, 屏幕可用区]；位置与任何屏不相交 → 返回空回退默认
- **TC-U21: 草稿条目序列化**：JSON 字段往返（version/url/untitledName/content/cursor/lineEnding/encoding/hasBom/baselineHash/savedAt）；损坏 JSON 静默删除
- **TC-U22: 草稿恢复分类**：哈希匹配→静默恢复；哈希不符/文件缺失→冲突列表；未命名→重建（编号跳号）；应用后条目删除
- **TC-U23: 同 URL 去重**：多条目同 URL 保留 savedAt 最新（缺失按 0，平局按 uid 字典序），落选删除
- **TC-U24: 清理语义**：内容回基线（保存/另存/撤销回基线/编码重载）删条目；关闭仍脏删条目；干净文档关闭不产生条目
- **TC-U25: 关闭现场还原算法**：文件+未命名混排序列 → 恢复插入顺序 = 关闭时顺序（稳定插入）；activeUid > active URL > 首个恢复文档优先级；无位置记录条目排最后；位置越界钳制
- **TC-U26: 基线哈希**：内容 SHA-256 指纹稳定性；外部修改后哈希不符

#### U4 多光标语义映射（editor 层）

- **TC-U27: Scintilla 多选 API 映射**：列选区/多光标集合 ↔ Scintilla selections 转换正确（位置排序、矩形选区参数）
- **TC-U28: 交互语义判定**：Alt+Click、Alt+Shift+拖拽、Ctrl+Alt+↑/↓、Shift+Alt+I、Ctrl+D（严格重叠判定：端点相接允许追加）、Ctrl+Shift+L 的触发条件与光标集合计算
- **TC-U29: 粘贴分发**：剪贴板行数==光标数逐行分发；不等每光标整份；多选区复制按行 \n 拼接（无选区光标贡献空行）
- **TC-U30: 单批撤销**：一次按键全光标编辑合并单次撤销（Scintilla undo 事务）

### 二、进程级集成测试（pwsh 脚本）

- **TC-I01: 构建与产物**：CMake+Ninja+MSVC 全新配置构建通过；单 exe；`dumpbin /dependents` 仅系统 DLL（kernel32/user32/gdi32 等系统库）
- **TC-I02: 启动冒烟**：启动 exe → 进程存活 ≥3s → 干净退出（无崩溃日志）；欢迎页路径（无会话无草稿首启）
- **TC-I03: 命令行参数**：`qcnote.exe a.txt "b c.txt" 中文.md` → 三个文档打开（可经会话文件/截图断言）
- **TC-I04: 单实例转发**：实例 A 运行中，启动实例 B 带文件参数 → B 立即退出、A 打开该文件（打开队列）
- **TC-I05: 热退出草稿 e2e**：启动→新建未命名→写内容（防抖 ≥1.2s 真实到期）→强杀→重启：未命名标签带内容恢复、modified 置位、激活
- **TC-I06: 会话恢复 e2e**：打开多文件+调整光标+窗口几何→正常退出→重启：标签顺序/光标/几何还原
- **TC-I07: 关闭现场还原 e2e**：[文件A, 未命名1, 文件B] 活动=未命名1 →强杀→重启：顺序与活动还原
- **TC-I08: 内存指标**：空壳启动静置 5s 读私有工作集 < 10 MB；开典型文档 ≤ 30 MB（脚本注明口径）
- **TC-I09: 启动时间指标**：热启动计时到主窗口可见 < 200 ms（重复取中值；冷启动单独记录）
- **TC-I10: 便携模式**：exe 旁放 `qcnote.portable` → ini/drafts 落 exe 旁；删除标记 → 落用户目录
- **TC-I11: shell 集成注册**：注册表键写入 `"<exe>" "%1"`（测试环境验证后清理）

### 三、真机人工验收清单

#### 窗口与标题栏（M1）

- **TC-M01: 空白区拖动**（含无文档时全标题栏）；**TC-M02: 双击最大化/还原**；**TC-M03: 最大化拖拽还原+光标锚定继续拖**；**TC-M04: 8 向边缘缩放**；**TC-M05: Win+方向贴靠、拖边缘 Aero Snap**；**TC-M06: 最大化按钮悬停 Snap Layouts 弹出**；**TC-M07: 右键标题栏系统菜单**
- **TC-M08: DPI**：100%/150%/200% 下标题栏按钮尺寸、Scintilla 字体、菜单、弹窗缩放正确；跨屏拖动不同 DPI 切换正确
- **TC-M09: 窗口边界线**：普通窗口 1px 描边、失焦变淡、最大化隐藏

#### 编辑与 IME（M2）

- **TC-M10: 中文 IME**：拼音输入组合窗跟随光标、候选窗位置正确、上屏正确；GB 区字符（如「镕」）、Bopomofo；Shift 切换中英
- **TC-M11: 滚动条常驻观感**；**TC-M12: 拖选自动滚动**（拖出视口边缘选区继续扩展——Scintilla 原生能力）；**TC-M13: 自动换行切换**（含长行横向滚动消失）

#### 多光标手感（M3）

- **TC-M14: Alt+Shift+拖拽列选**（中英混排、短行钳制、全角对齐）；**TC-M15: Ctrl+D 连续选词**；**TC-M16: 列复制粘贴往返**；**TC-M17: Esc/单击退出多光标**

#### 查找替换（M3）

- **TC-M18: 对话框顶部对齐+可拖动**；**TC-M19: 高亮/当前匹配描边观感**；**TC-M20: F3 关闭态跳转不恢复高亮**

#### 主题与观感（M6）

- **TC-M21: 浅/深切换即时生效**（标题栏/编辑区/标签/状态栏/弹窗/滚动条）；**TC-M22: 状态表达非颜色线索核查**（未保存 ●、当前匹配描边、禁用置灰）

## 测试命令

```powershell
# 构建（VS Build Tools 2026 + CMake/Ninja）
# vcvars64 环境下：
cmake -B build-win -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-win
# 单元测试（Catch2）
ctest --test-dir build-win --output-on-failure
# 进程级集成与指标脚本（tools/ 下，逐步补充）
pwsh -NoProfile -File tools/verify-smoke.ps1
pwsh -NoProfile -File tools/verify-metrics.ps1
```
