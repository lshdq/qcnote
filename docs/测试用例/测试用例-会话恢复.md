# 测试用例：会话恢复

## 测试范围

覆盖会话恢复功能的持久化、恢复与校验逻辑：

- `SessionManager`（会话读写、防抖落盘、恢复流程、缺失文件静默跳过、几何校验）
- `Document::cursorPosition` 属性
- `EditorArea` 光标双向同步
- `Main.qml` 启动恢复时序（QML 集成）
- 回归：无会话文件时行为与现状一致

## 用例列表

### TC-001: 会话读写往返（文档列表/顺序/active/光标）
- 前置条件：临时目录作为会话文件路径；DocumentManager 打开 2 个临时文件并设置不同光标、指定 active
- 操作步骤：触发 flush 写盘 → 新建 SessionManager 读取 → 执行 restoreDocuments()
- 预期结果：文档按原顺序打开，active 与各文档光标位置与写入前一致
- 优先级：P0

### TC-002: 缺失文件静默跳过
- 前置条件：会话记录 3 个文件，其中 1 个已从磁盘删除
- 操作步骤：restoreDocuments()
- 预期结果：仅打开存在的 2 个文件；不发射 openFailed（无错误弹窗）；其余文件顺序保持
- 优先级：P0

### TC-003: active 文件丢失时激活最后一个
- 前置条件：会话记录 2 个文件，active 指向的文件已删除
- 操作步骤：restoreDocuments()
- 预期结果：打开第 2 个文件并激活其为活动文档
- 优先级：P0

### TC-004: 空会话/无会话文件容错
- 前置条件：会话文件不存在或 `[documents] size=0`
- 操作步骤：restoreDocuments()
- 预期结果：不打开任何文档、不报错、不崩溃（QML 侧显示欢迎页）
- 优先级：P0

### TC-005: 会话数据损坏容错
- 前置条件：会话文件中光标为负数/非数值、URL 非法、size 与实际不符
- 操作步骤：restoreDocuments()
- 预期结果：坏条目按安全默认值处理或丢弃（光标钳制为 ≥0，非法 URL 跳过），不崩溃
- 优先级：P1

### TC-006: 光标越界钳制
- 前置条件：会话记录的光标位置超出文件内容长度
- 操作步骤：restoreDocuments() 后读取 doc.cursorPosition
- 预期结果：光标钳制到 [0, content.length]
- 优先级：P1

### TC-007: 防抖落盘与退出 flush
- 前置条件：SessionManager 挂接 DocumentManager
- 操作步骤：改变文档集合/active/光标 → 立即读文件（未到防抖期）→ 等待防抖期后读文件 → 再改动后直接触发 aboutToQuit
- 预期结果：防抖期内未落盘；防抖超时后写入最新状态；退出时挂起的防抖立即落盘
- 优先级：P1

### TC-008: Document.cursorPosition 属性行为
- 前置条件：Document 实例
- 操作步骤：设置/读取 cursorPosition；同值重复设置
- 预期结果：值正确读写；同值设置不发射 cursorPositionChanged；applyLoadedState 不改变 cursorPosition
- 优先级：P0

### TC-009: 窗口几何校验与越界回退
- 前置条件：构造各种几何输入（负坐标、超小/超大宽高、完全离屏）
- 操作步骤：调用几何校验函数 / windowState()
- 预期结果：宽高钳制到 [800×500, 屏幕可用区]；离屏位置判无效返回空；合法几何原样返回
- 优先级：P0

### TC-010: 窗口几何保存（仅 Windowed 状态）
- 前置条件：saveWindowState 写入 normal 几何 + maximized 标志
- 操作步骤：写入后读取校验
- 预期结果：x/y/width/height/maximized 正确往返
- 优先级：P1

### TC-011: QML 集成——启动恢复完整链路
- 前置条件：offscreen 平台；预置会话文件（重定向到临时目录）；实例化完整 Main.qml
- 操作步骤：启动 → 断言文档数量/顺序/active/光标 → 驱动窗口关闭
- 预期结果：文档与几何按会话恢复；退出后 会话文件已更新；全程无可见窗口
- 优先级：P0

### TC-012: QML 集成——无会话文件回归
- 前置条件：offscreen 平台；无会话文件；实例化 Main.qml
- 操作步骤：启动 → 检查文档集合为空（欢迎页路径）→ 新建文档
- 预期结果：行为与现状一致，无报错
- 优先级：P0

### TC-013: EditorArea 光标双向同步
- 前置条件：打开文档；QML 测试环境
- 操作步骤：程序化设置 doc.cursorPosition → 检查 TextArea 光标；模拟输入移动光标 → 检查 doc.cursorPosition
- 预期结果：C++ → QML 与 QML → C++ 双向同步，无信号环
- 优先级：P1

### TC-014: 未命名文档不入会话
- 前置条件：临时会话路径；newDocument() 创建未命名文档（无 url）+ 打开 1 个有 url 文件
- 操作步骤：flush() → 直接读会话文件
- 预期结果：[documents] size == 1，唯一条目为有 url 文档；未命名文档不占编号（无 documents/2/url）
- 优先级：P1
- 实现：tests/test_core/tst_sessionmanager.cpp::unnamedDocumentsAreExcludedFromSession

### TC-015: 窗口关闭路径会话落盘
- 前置条件：offscreen 平台；空会话启动后新建两个文档另存为临时文件、移动光标
- 操作步骤：QWindow::close()（干净状态放行）→ 等待防抖落盘 → 新 QSettings 读会话文件
- 预期结果：文档数量/URL/光标与当前文档集一致；[window] 节已写入
- 优先级：P1
- 实现：tests/test_window/tst_sessionrestore.cpp::tc013_closePath_writesSession

### TC-016: 窗口几何持久化往返与恢复光标滚动
- 前置条件：offscreen 平台；经窗口 API 驱动会话进入目标几何（基于主屏可用区构造、经校验纯函数合法化）
- 操作步骤：新窗口实例化 Main.qml 且全程不动窗口 → 跨过防抖窗口读 [window]；打开长文档（80 行）置光标于末行 → 检查滚动；重置 contentY 后直接调用 scrollCursorIntoView
- 预期结果：恢复窗口几何与目标逐值相等且 [window] 不被默认值 (0,0,1000,640) 覆盖（P0-1 回归）；光标在文档末尾时 contentY > 0，且 scrollCursorIntoView 独立生效（P1-1 回归）；新窗口 delegate 重建时恢复光标并滚动到位
- 优先级：P0
- 实现：tests/test_window/tst_sessionrestore.cpp::tc014_windowGeometryAndScrollRestore

### TC-017: 最小化期间 maximized 标志保持
- 前置条件：offscreen 平台；Main.qml 实例化，窗口从 Windowed 迁移到 Maximized 并等 [window]/maximized=true 落盘
- 操作步骤：visibility 置 Minimized → 跨过防抖窗口读会话文件
- 预期结果：最小化触发的写盘仍记录 maximized=true（Minimized 迁移不把缓存覆盖为 false，P2-1 回归）
- 优先级：P2
- 实现：tests/test_window/tst_sessionrestore.cpp::tc015_minimizedKeepsMaximizedFlag
