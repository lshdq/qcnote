# 测试用例：外部文件改动检测

## 测试范围

- `core/externalchangemonitor.h/.cpp`（新增加入 `qcnote_core` 库与 `test_core`）。
- `main.cpp` 接线（timer id 7、决策编排、`--watch-interval-ms` / `--selftest-filewatch` 钩子）。
- `DocumentManager` 若新增 `reloadFromDisk`（或复用 `reloadWithEncoding`）的重载路径。
- 回归：既有保存/另存/重命名/编码重载/草稿/会话管线不受影响。

## 用例列表

### 单元测试（Catch2，test_core 注入 mock）

#### TC-001: 干净文档外部修改判定 Modified
- 前置条件：monitor 注入 mock stat/内容查询；文档有 url、快照已建立、内容与 baselineHash 一致
- 操作步骤：修改 mock stat（mtime+size）与 mock 磁盘内容哈希（与 baselineHash 不同），poll
- 预期结果：返回该文档 `Modified` 一条
- 优先级：P0

#### TC-002: stat 未变跳过（不读内容）
- 前置条件：同 TC-001，但 stat 与快照一致
- 操作步骤：poll；记录内容查询调用次数
- 预期结果：无 finding，内容查询 0 次调用
- 优先级：P0

#### TC-003: touch 不误报（mtime 变、内容同）
- 前置条件：mock stat mtime 变化、size 不变，mock 磁盘内容哈希 == baselineHash
- 操作步骤：poll
- 预期结果：无 finding；且快照更新为新 stat（下次同 stat 不再触发内容比对）
- 优先级：P0

#### TC-004: 文件删除判定 Deleted
- 前置条件：快照已建立
- 操作步骤：mock stat 返回「确认不存在」，poll
- 预期结果：返回 `Deleted` 一条
- 优先级：P0

#### TC-005: stat 查询失败不误报删除
- 前置条件：快照已建立
- 操作步骤：mock stat 返回错误（非确认不存在），poll
- 预期结果：无 finding（本轮跳过，快照不变）
- 优先级：P0

#### TC-006: 删除后恢复原内容判定 Restored 静默
- 前置条件：先经 TC-004 进入已删除提示态
- 操作步骤：mock stat 恢复存在、内容哈希 == baselineHash，poll
- 预期结果：返回 `Restored`（UI 侧静默清除删除态）
- 优先级：P1

#### TC-007: 删除后恢复为不同内容按 Modified 处理
- 前置条件：同 TC-006 但内容哈希 != baselineHash
- 操作步骤：poll
- 预期结果：返回 `Restored` 且携带「内容已变」标记（或直接 `Modified`），不遗漏决策
- 优先级：P1

#### TC-008: refreshBaseline 后同 stat 不报
- 前置条件：文档经保存路径（模拟 markSaved）调用 refreshBaseline，磁盘 stat 已变化（外部改过 + 我们保存过）
- 操作步骤：poll
- 预期结果：无 finding
- 优先级：P0

#### TC-009: url 变化后快照自动重建
- 前置条件：文档 url 改变（另存为/重命名路径），快照记录的还是旧 url
- 操作步骤：poll
- 预期结果：无 finding；快照按新 url 重建
- 优先级：P0

#### TC-010: 「保留」抑制同版本重复报
- 前置条件：脏文档已弹出决策、用户选保留（acknowledge）
- 操作步骤：同一 stat 版本再次 poll
- 预期结果：无 finding；stat 再变化（新版本）后重新报 `Modified`
- 优先级：P0

#### TC-011: 关闭文档后快照清理（uid 遗留不泄漏）
- 前置条件：两个文档先后使用同一 url（关闭旧的开新的）
- 操作步骤：close 旧文档 → 新文档 poll
- 预期结果：按新 uid 重新建立快照，旧 uid 不干扰判定
- 优先级：P1

#### TC-012: 未命名/无 url 文档跳过
- 前置条件：文档无 url
- 操作步骤：poll（传入含该文档的列表）
- 预期结果：无 finding、无 stat 查询
- 优先级：P1

### selftest / e2e（--selftest-filewatch，headless + 短轮询间隔）

#### TC-101: 干净文档外部修改自动重载
- 前置条件：headless 启动，打开临时文件（内容 A），轮询间隔注入短值
- 操作步骤：外部改写磁盘文件为内容 B（含编码/换行变化），推进自测阶段
- 预期结果：文档内容 == B、modified == false、无对话框状态；编辑器/状态栏/标题刷新
- 优先级：P0

#### TC-102: 脏文档外部修改弹三选框
- 前置条件：打开文件后先做编辑（脏）
- 操作步骤：外部改写磁盘文件，推进自测阶段
- 预期结果：三选框出现；模拟选择「重新加载」→ 内容 == 磁盘新内容、modified == false、草稿清理
- 优先级：P0

#### TC-103: 三选框「保留修改」抑制
- 前置条件：同 TC-102
- 操作步骤：选「保留修改」→ 内容保持内存版、modified == true；文件未再变化期间多轮 poll 不再弹
- 预期结果：无重复弹框；文件再次变化后重新弹
- 优先级：P0

#### TC-104: 三选框「另存为…」路径
- 前置条件：同 TC-102
- 操作步骤：选「另存为…」→ 走另存为（注入目标路径）→ 成功后文档干净
- 预期结果：url 更新、modified == false、无外部改动提示残留
- 优先级：P1

#### TC-105: 文件删除提示一次
- 前置条件：打开文件（干净或脏均可）
- 操作步骤：删除磁盘文件 → 提示出现 → 确认 → 多轮 poll 不再弹 → 保存 → 文件重建且无提示
- 预期结果：提示恰好一次；保存成功重建文件
- 优先级：P0

#### TC-106: 非活动文档不检测
- 前置条件：打开两个文件 A（活动）与 B（非活动）
- 操作步骤：外部修改/删除 B 的磁盘文件，推进多轮 poll
- 预期结果：无任何提示与重载；切换活动标签到 B 后立即检测并按管线处理
- 优先级：P0

#### TC-107: 自己保存不触发提示
- 前置条件：打开文件并编辑（脏）
- 操作步骤：执行保存命令 → 多轮 poll
- 预期结果：无提示
- 优先级：P0

#### TC-108: 切换标签立即检测
- 前置条件：A 活动时 B 被外部修改（未检测）
- 操作步骤：激活 B
- 预期结果：无需等待轮询 tick，立即走对应管线
- 优先级：P1
