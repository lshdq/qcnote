# 测试用例：标题栏窗口操作修复

## 测试范围

- 变更文件：`src/qml/DocumentTabs.qml`（ListView 条件 `interactive`）、`src/qml/TitleBar.qml`（dragArea 最大化拖拽还原）。
- 回归范围：标题栏控件（菜单/最小化/最大化/关闭）、Tab 区全部交互、窗口边缘缩放、窗口级快捷键。

## 用例列表

### TC-001: 无文档时空白区拖拽移动窗口
- 前置条件：启动应用，未打开任何文档
- 操作步骤：在标题栏 Tab 条空白区按住左键拖动超过 4px
- 预期结果：窗口跟随移动（系统拖拽）
- 优先级：P0（手动）

### TC-002: 双击空白区最大化/还原
- 前置条件：窗口处于普通状态
- 操作步骤：双击标题栏空白区；再次双击
- 预期结果：第一次双击最大化；第二次双击还原
- 优先级：P0（手动）

### TC-003: 有 Tab 未溢出时空白区操作
- 前置条件：打开 1~2 个文档，Tab 未占满标题栏
- 操作步骤：拖拽最后一个 Tab 右侧的空白区；双击该空白区
- 预期结果：拖拽移动窗口；双击最大化/还原
- 优先级：P0（手动）

### TC-004: Tab 交互无回归（未溢出）
- 前置条件：打开 2 个以上文档
- 操作步骤：单击各 Tab 切换活动文档；悬停查看高亮与未保存 ● 标记；单击关闭按钮；键盘 Tab 焦点 + 左右方向键 + Enter 激活
- 预期结果：激活、悬停、关闭、键盘导航全部正常
- 优先级：P0（手动）

### TC-005: Tab 溢出滚动无回归
- 前置条件：打开足够多文档使 Tab 溢出标题栏
- 操作步骤：在 Tab 区横向拖拽/滚轮滚动；拖动水平滚动条
- 预期结果：Tab 区可横向滚动，滚动条可用，活动 Tab 切换时自动滚动可见
- 优先级：P1（手动）

### TC-006: 最大化状态拖拽还原并继续拖动
- 前置条件：窗口最大化
- 操作步骤：在标题栏空白区按住左键拖动超过阈值
- 预期结果：窗口还原并立即进入系统拖拽，跟随光标移动
- 优先级：P0（手动）

### TC-007: 最大化还原位置合理性
- 前置条件：窗口最大化
- 操作步骤：在标题栏不同水平位置（左/中/右）按住并拖动
- 预期结果：还原后光标仍位于标题栏范围内（窗口顶边在光标上方、水平按按下点比例），无明显跳变
- 优先级：P1（手动）

### TC-008: 窗口其他操作无回归
- 前置条件：窗口普通状态
- 操作步骤：拖动四边/四角缩放窗口；Win+左/右贴靠；点击菜单/最小化/最大化/关闭按钮；Ctrl+N/O/S/W 等快捷键
- 预期结果：缩放、贴靠、按钮、快捷键全部正常
- 优先级：P1（手动）

### TC-009: 既有单元测试通过
- 前置条件：完成构建
- 操作步骤：`ctest --test-dir build --output-on-failure`
- 预期结果：全部通过（3 个测试类共 46 个测试函数，含各类 initTestCase/cleanupTestCase 固定函数）
- 优先级：P0（自动化）

### TC-010: offscreen 冒烟无 QML 错误
- 前置条件：完成构建
- 操作步骤：`QT_QPA_PLATFORM=offscreen` 启动 qcnote.exe，数秒后结束进程，检查无 QML 错误输出
- 预期结果：无 error/warning 刷屏、无 QML 加载失败
- 优先级：P0（自动化）

## 测试场景分类

框架代码（Qt Quick QML 交互行为修复）：TC-009、TC-010 可自动化；TC-001~TC-008 涉及窗口管理器系统交互，offscreen 无法模拟，属手动验证用例（真实窗口验证需用户执行或经用户同意后进行）。
