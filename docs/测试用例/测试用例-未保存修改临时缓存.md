# 测试用例：未保存修改临时缓存

## 测试范围

`DraftCacheManager`（写入/清理/恢复）、`Document` 新增 `uid()`/`savedContentHash()`、`DocumentManager` 未命名草稿恢复入口、`Main.qml` 启动时序与冲突对话框；缓存条目 JSON 格式与便携目录定位。

## 用例列表

### TC-001: 修改后防抖写入缓存
- 前置条件：注入临时缓存目录构造 DraftCacheManager；打开（或新建）文档
- 操作步骤：`doc->setContent()` 修改为不同于基线的内容；等待防抖（或调用 flush）落盘
- 预期结果：`drafts/<uid>.json` 存在；content/url（或 untitledName）/cursor/lineEnding/encoding/hasBom/baselineHash 字段与文档状态一致；文件为合法 JSON
- 优先级：P0

### TC-002: 干净文档不写缓存
- 前置条件：同 TC-001
- 操作步骤：打开文件后不做任何修改，等待超过防抖间隔
- 预期结果：缓存目录无该文档条目
- 优先级：P0

### TC-003: 保存成功清理缓存
- 前置条件：TC-001 已产生缓存条目
- 操作步骤：`DocumentManager::save(doc)` 成功
- 预期结果：条目文件被删除
- 优先级：P0

### TC-004: 另存为后清理缓存
- 前置条件：修改未命名文档并已产生缓存条目
- 操作步骤：`saveAs(doc, url)` 成功
- 预期结果：条目文件被删除（modified 变 false 统一清理）
- 优先级：P1

### TC-005: 放弃关闭清理缓存
- 前置条件：修改文档并已产生缓存条目
- 操作步骤：`DocumentManager::closeDocument(doc)`（关闭时仍 modified，等价于 UI 选"不保存"）
- 预期结果：条目文件被删除
- 优先级：P0

### TC-006: 撤回到基线清理缓存
- 前置条件：修改文档并已产生缓存条目
- 操作步骤：`setContent` 恢复为基线内容（modified 变 false）
- 预期结果：条目文件被删除
- 优先级：P1

### TC-007: 按编码重载覆盖后清理缓存
- 前置条件：修改带 URL 文档并已产生缓存条目
- 操作步骤：`reloadWithEncoding(doc, ...)`（未保存修改被磁盘内容覆盖）
- 预期结果：条目文件被删除
- 优先级：P2

### TC-008: 静默恢复（磁盘未被外部修改）
- 前置条件：手工（或前一轮运行）在缓存目录放置合法条目：url 指向磁盘现存文件、baselineHash == 磁盘当前内容哈希、content 为修改内容
- 操作步骤：`restoreDrafts()`（缓存目录中该 url 的文档已被会话恢复/手动打开）
- 预期结果：文档 content 变为缓存内容、modified == true、光标钳制恢复；条目文件被删除
- 优先级：P0

### TC-009: 外部修改冲突进入提示列表
- 前置条件：条目 baselineHash 与磁盘当前内容哈希不一致（模拟外部程序修改）
- 操作步骤：`restoreDrafts()`
- 预期结果：文档内容未被直接覆盖；发冲突信号（含 url/displayName）；选「恢复」后内容覆盖为未保存修改、条目删除；选「丢弃」后保持磁盘内容、条目删除
- 优先级：P0

### TC-010: 原文件缺失进入提示列表
- 前置条件：条目 url 指向不存在的文件
- 操作步骤：`restoreDrafts()`；选择「恢复」
- 预期结果：以未命名文档恢复缓存内容（modified == true）；选择「丢弃」则仅删条目
- 优先级：P1

### TC-011: 未命名条目恢复
- 前置条件：缓存目录放置 url 为空的合法条目（含 untitledName 与 content）
- 操作步骤：`restoreDrafts()`
- 预期结果：新建未命名文档，显示名沿用记录值，content 即缓存内容，modified == true；条目删除
- 优先级：P0

### TC-012: 损坏条目静默跳过
- 前置条件：缓存目录放置非法 JSON 文件与版本号不符的合法 JSON
- 操作步骤：`restoreDrafts()`
- 预期结果：两个文件被删除，无弹窗、无崩溃、其余条目正常处理
- 优先级：P1

### TC-013: uid 唯一性与不可变性
- 前置条件：无
- 操作步骤：创建多个 Document，多次读取同一文档 uid
- 预期结果：不同文档 uid 互不相同；同一文档 uid 恒定不变；符合 UUID 格式
- 优先级：P1

### TC-014: savedContentHash 反映基线
- 前置条件：打开文档（基线 = 磁盘内容）
- 操作步骤：修改内容后读取 savedContentHash；保存后再读
- 预期结果：修改不影响哈希（仍为基线哈希）；保存后哈希更新为新基线
- 优先级：P1

### TC-015: 恢复不抢占活动标签
- 前置条件：会话恢复激活文档 A；另有文档 B 的缓存待恢复
- 操作步骤：`restoreDrafts()` 恢复 B
- 预期结果：activeDocument 仍为 A（未命名恢复文档仅追加）
- 优先级：P2

### TC-016: 缓存目录不存在时的行为
- 前置条件：注入的缓存目录不存在
- 操作步骤：构造 DraftCacheManager 并修改文档、恢复
- 预期结果：写缓存时自动创建目录；恢复时按空处理，无报错
- 优先级：P1

### TC-017: 便携模式目录定位
- 前置条件：无（纯函数测试）
- 操作步骤：以标记文件存在/不存在两种 appDir 验证目录解析
- 预期结果：便携标记存在 → appDir/drafts；否则 → AppLocalDataLocation/drafts
- 优先级：P2

### TC-018: 防抖挂起时文档被关闭
- 前置条件：修改文档（防抖计时中）
- 操作步骤：计时到期前 `closeDocument(doc)`
- 预期结果：到期写盘不崩溃、不为已关闭文档重建条目（悬垂防护）
- 优先级：P1

### TC-019: QML 启动时序与对话框（冒烟）
- 前置条件：构建产物 qcnote.exe；offscreen 平台
- 操作步骤：放置合法缓存条目后 offscreen 启动；放置冲突条目后 offscreen 启动
- 预期结果：静默恢复场景无弹窗直接恢复；冲突场景冲突对话框可打开（进程正常存活、无 QML 错误输出）
- 优先级：P1
