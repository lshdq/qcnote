# 测试用例：编辑区选中背景色

## 测试范围

`src/qml/AppTheme.qml`（新增 `selection` token）、`src/qml/EditorArea.qml`（编辑区 `TextArea` 的 `selectionColor` / `selectedTextColor`），验证：

- 选区颜色属性正确设置且绑定 AppTheme 语义 token；
- 现有 C++ 单元测试无回归；
- offscreen 冒烟启动正常（无 QML 运行时错误）。

说明：选区视觉效果涉及渲染颜色，offscreen 自动化下以属性值断言（QML 加载后读取 `selectionColor` / `selectedTextColor` / `AppTheme.selection`）为主；肉眼视觉确认仅按需进行。

## 用例列表

### TC-001: 浅色主题选区背景为半透明强调蓝
- 前置条件：应用处于浅色主题（`AppTheme.dark == false`），编辑区有文档
- 操作步骤：拖选一段文字（或 Ctrl+A 全选）
- 预期结果：`selectionColor` 为 `#293564d4`（`AppTheme.selection` 浅色值），无红色
- 优先级：P0

### TC-002: 深色主题选区背景为半透明强调蓝
- 前置条件：切换到深色主题（`AppTheme.dark == true`）
- 操作步骤：拖选一段文字
- 预期结果：`selectionColor` 为 `#336f9bff`（`AppTheme.selection` 深色值）
- 优先级：P0

### TC-003: 选中文字保持原色可读
- 前置条件：任意主题
- 操作步骤：拖选一段文字
- 预期结果：`selectedTextColor` 为 `AppTheme.textPrimary`（与未选中文字一致），在半透明蓝底上对比度足够
- 优先级：P0

### TC-004: 主题切换后选区颜色跟随
- 前置条件：编辑区存在选区
- 操作步骤：切换主题（浅 ↔ 深）
- 预期结果：`selectionColor` 随 `AppTheme.selection` 绑定即时切换
- 优先级：P1

### TC-005: 多光标选区颜色不变且与原生选区一致
- 前置条件：Ctrl+D 或 Alt+单击添加多光标并产生选区
- 操作步骤：比较多光标选区高亮（`multiSelection`）与原生选区（`selection`）
- 预期结果：`multiSelection` 取值不变，且与 `selection` 同值，视觉一致
- 优先级：P1

### TC-006: 构建无错误
- 前置条件：构建目录已配置
- 操作步骤：`cmake --build build`
- 预期结果：构建成功，无 QML 语法/编译错误
- 优先级：P0

### TC-007: 现有 C++ 单元测试无回归
- 操作步骤：`ctest --test-dir build --output-on-failure`
- 预期结果：全部测试通过
- 优先级：P0

### TC-008: offscreen 冒烟启动
- 操作步骤：`QT_QPA_PLATFORM=offscreen` 启动 `qcnote.exe`，稍候结束进程
- 预期结果：正常启动，无 QML 运行时错误输出
- 优先级：P1
