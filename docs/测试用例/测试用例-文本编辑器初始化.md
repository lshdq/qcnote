# 测试用例：文本编辑器初始化

## 测试范围

- C++ 核心逻辑（QtTest 单元测试，自动化）：Document 状态、PlainTextFormat、LocalStorage、DocumentManager；
- QML UI 交互（手工冒烟）；
- 构建与工具链验证。

## 用例列表

### TC-001: 新建文档
- 前置条件：应用已启动
- 操作步骤：Ctrl+N（或菜单"新建"）连续两次
- 预期结果：出现两个新标签，名称"未命名-1"、"未命名-2"，内容为空、无未保存标记
- 优先级：P0

### TC-002: 打开文件
- 前置条件：存在 UTF-8 编码 .txt 文件
- 操作步骤：Ctrl+O 选择该文件
- 预期结果：新标签显示文件名，内容与源文件一致，无未保存标记，状态栏路径正确
- 优先级：P0

### TC-003: BOM 与 CRLF 处理
- 前置条件：存在带 BOM、CRLF 换行的 UTF-8 文件
- 操作步骤：打开 → 编辑追加一行 → Ctrl+S → 用十六进制工具检查
- 预期结果：BOM 不出现在编辑内容中；状态栏显示 CRLF；保存后文件无 BOM 且换行为 CRLF
- 优先级：P0

### TC-004: 修改标记与保存
- 操作步骤：输入字符 → 观察 Tab 与标题 → Ctrl+S
- 预期结果：输入后 Tab 显示 `●`、标题文件名带 `*`；保存后标记消失，磁盘内容更新
- 优先级：P0

### TC-005: 另存为
- 操作步骤：Ctrl+Shift+S → 选择新路径保存
- 预期结果：文件写入新路径；标签名与状态栏路径更新；原文件（若曾有）不被修改
- 优先级：P0

### TC-006: 关闭未保存文档
- 前置条件：某标签有未保存修改
- 操作步骤：点 Tab 关闭按钮（或 Ctrl+W）
- 预期结果：弹窗三选——保存→保存并关闭；放弃→直接关闭；取消→标签保留、内容不变
- 优先级：P0

### TC-007: 多标签状态保持
- 操作步骤：两个标签均输入不同内容且不保存，来回切换
- 预期结果：各自内容与 `●` 标记均保留，无丢失
- 优先级：P0

### TC-008: 退出时未保存确认
- 前置条件：存在未保存文档
- 操作步骤：菜单退出 / 点窗口关闭按钮
- 预期结果：弹出确认；全部处理后应用退出；取消则不退出
- 优先级：P1

### TC-009: 重复打开同一文件去重
- 操作步骤：打开文件 A 后再次打开 A
- 预期结果：不产生重复标签，激活已有标签
- 优先级：P1

### TC-010: 状态栏信息
- 操作步骤：移动光标、选中一段文本
- 预期结果：行列随光标更新；显示选中字符数与总字符数；路径 tooltip 完整
- 优先级：P1

### TC-011: 窗口操作
- 操作步骤：标题栏拖拽移动、双击最大化/还原、三个窗口按钮、边缘拖拽缩放、Win+左/右贴靠
- 预期结果：行为符合 Windows 习惯；贴靠生效；窗口控制按钮不被 Tab 挤压
- 优先级：P1

### TC-012: Tab 溢出
- 操作步骤：打开超过可视宽度数量的标签
- 预期结果：Tab 区横向滚动，窗口控制按钮仍完整可见
- 优先级：P2

### TC-013: 空状态欢迎页
- 操作步骤：关闭全部标签
- 预期结果：显示欢迎页；新建/打开后欢迎页消失
- 优先级：P2

### TC-014: 单元测试-LocalStorage
- 操作步骤：运行 test_core
- 预期结果：write/read 往返一致；读取不存在文件返回错误；BOM 剥离；CRLF/CR 归一化为 LF；保存按记录的换行风格写回（LF 文件保持 LF、CRLF 保持 CRLF）；写入非法路径返回错误
- 优先级：P0

### TC-015: 单元测试-Document/DocumentManager
- 操作步骤：运行 test_core
- 预期结果：修改状态翻转正确（同值写入不置脏）；displayName 取文件名；未命名编号递增；格式按扩展名匹配且未知扩展兜底到纯文本；storage 按 scheme 分发；重复 URL 去重激活
- 优先级：P0

### TC-016: 保存/打开失败反馈
- 操作步骤：保存到不存在目录；打开无权限文件
- 预期结果：弹出错误对话框且内容不丢失
- 优先级：P1
