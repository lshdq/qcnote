# 测试用例：弹窗拖动

## 测试范围

qcnote 五个应用内弹窗（unsavedDialog / errorDialog / ctxMenuPromptDialog / reloadConfirmDialog / SearchDialog）的拖拽移动、边界约束、重开复位、resize 跟随/重约束，以及模态/关闭/焦点行为回归；另含全局 desktop-ui-design skill 文档更新验证。

实现载体：新增 `src/qml/MovableDialog.qml`（继承 Dialog，header 拖拽把手 + 边界 clamp + 重开复位），Main.qml 四个对话框与 SearchDialog.qml 根类型接入。

## 用例列表

### TC-001: 默认打开位置不变
- 前置条件：应用启动（offscreen），窗口尺寸已知。
- 操作步骤：分别打开四个 Main 对话框与 SearchDialog。
- 预期结果：四个 Main 对话框居中（x/y 与窗口中心差 ≤1px）；SearchDialog 水平居中、y=96（DEC-002 顶部对齐）。
- 优先级：P0

### TC-002: 标题栏拖拽移动弹窗
- 前置条件：任一弹窗处于打开状态。
- 操作步骤：合成鼠标在标题栏把手中心 press → move(+dx, +dy) → release（dx/dy 为窗口内普通位移）。
- 预期结果：弹窗 x/y 精确增加 (dx, dy)（±1px 容差）。
- 优先级：P0

### TC-003: 拖动边界约束（把手不丢失）
- 前置条件：弹窗打开。
- 操作步骤：分别向左、右、上、下大幅拖动（超界）。
- 预期结果：弹窗可部分移出窗口，但满足 `x ≥ -(width - keepWidth)`、`x ≤ parent.width - keepWidth`、`y ≥ 0`、`y ≤ parent.height - 标题栏高度`（keepWidth 约 80px），把手始终在窗口内可抓回。
- 优先级：P0

### TC-004: 重开复位默认位置
- 前置条件：弹窗已拖离默认位置。
- 操作步骤：关闭弹窗（Esc 或按钮）后再次打开。
- 预期结果：位置复位到默认（TC-001 的断言重新成立）。
- 优先级：P0

### TC-005: 未拖动时窗口 resize 跟随
- 前置条件：弹窗打开且未被拖动。
- 操作步骤：改变窗口尺寸。
- 预期结果：弹窗跟随默认位置（居中/顶部对齐随窗口重算），保持原 tst_dialogstyle 的 resize 跟随语义。
- 优先级：P1

### TC-006: 拖动后窗口 resize 重新约束
- 前置条件：弹窗已被拖到边界附近。
- 操作步骤：缩小/移动窗口尺寸使原位置越界。
- 预期结果：弹窗位置被重新 clamp，把手仍在窗口内（TC-003 不等式全部成立）。
- 优先级：P1

### TC-007: 模态与关闭行为回归
- 前置条件：弹窗打开（可能已拖动）。
- 操作步骤：按 Esc；合成鼠标点击弹窗外部遮罩；检查 footer 按钮。
- 预期结果：Esc 关闭；点击遮罩不关闭（closePolicy 仅 CloseOnEscape）；footer 仍为 WinLayout、按钮角色/文案/primary 不变。
- 优先级：P0

### TC-008: 键盘路径回归
- 前置条件：弹窗打开。
- 操作步骤：Tab 遍历、Enter 触发主按钮（如保存分支）、Esc 取消。
- 预期结果：焦点顺序与既有行为一致；Enter/Esc 分支结果不变；拖拽把手不进入焦点链、不干扰输入框。
- 优先级：P1

### TC-009: SearchDialog 拖动后功能正常
- 前置条件：打开查找替换对话框并拖动到新位置。
- 操作步骤：输入查找串，Enter/F3 跳转、替换、全部替换，Esc 关闭。
- 预期结果：查找/替换/高亮/F3 跳转全部正常，状态行显示不受拖动影响。
- 优先级：P1

### TC-010: 构建与全量测试
- 前置条件：无。
- 操作步骤：执行测试命令节的构建与 ctest。
- 预期结果：构建零错误，ctest 全部通过（含 tst_dialogstyle 适配与新增拖动用例）。
- 优先级：P0

### TC-011: 人工视觉验收
- 前置条件：真实窗口运行（需用户同意，最小化快速核验）。
- 操作步骤：肉眼检查标题栏视觉与现状一致（文案/字号/边距），拖动跟手。
- 预期结果：视觉无回退，拖动流畅。offscreen 无法覆盖，见测试报告"未执行"清单。
- 优先级：P2

### TC-012: skill 文档规则更新（文档验证）
- 前置条件：无。
- 操作步骤：读取 `D:\Program\opencode\data\config\opencode\skills\desktop-ui-design\SKILL.md`。
- 预期结果：第 2 节新增"对话框和弹出层"小节（必须支持拖拽移动、边界约束、重开位置策略明确、拖拽不破坏模态/焦点/Esc、原生对话框例外），第 7 节验收清单含对应检查项；表述框架无关。
- 优先级：P2

