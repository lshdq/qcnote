# 测试用例：窗口关闭一次生效

## 测试范围

`src/qml/Main.qml` 的窗口关闭/退出流程（`onClosing` 重构 + 移除 `beginExitCheck`），验证：

- 无未保存修改时各类关闭入口一次生效；
- 有未保存修改时确认流程各分支行为不回归；
- 现有 C++ 核心测试无回归。

## 用例列表

### TC-001: 干净状态点击关闭图标一次退出
- 前置条件：应用启动，存在一个未修改的新文档（或无文档）
- 操作步骤：点击标题栏关闭图标（X）一次
- 预期结果：应用立即退出，无需第二次点击；无确认框弹出
- 优先级：P0

### TC-002: 干净状态 Alt+F4 一次退出
- 前置条件：同 TC-001
- 操作步骤：按 Alt+F4 一次
- 预期结果：应用立即退出
- 优先级：P0

### TC-003: 干净状态菜单"退出"一次生效
- 前置条件：同 TC-001
- 操作步骤：打开主菜单，点击"退出"
- 预期结果：应用立即退出
- 优先级：P0

### TC-004: 有未保存修改点击关闭图标弹确认框
- 前置条件：打开或新建文档并输入内容（modified = true）
- 操作步骤：点击标题栏关闭图标（X）
- 预期结果：弹出"未保存的修改"确认框（保存 / 放弃 / 取消），窗口不直接关闭
- 优先级：P0

### TC-005: 未保存确认框选择"放弃"退出
- 前置条件：同 TC-004，确认框已弹出
- 操作步骤：点击"放弃"
- 预期结果：文档被关闭；无其他未保存文档时应用退出；还有未保存文档时继续弹下一个确认框
- 优先级：P0

### TC-006: 未保存确认框选择"保存"退出
- 前置条件：同 TC-004，文档有保存路径
- 操作步骤：点击"保存"
- 预期结果：文档写盘后关闭；全部处理完应用退出
- 优先级：P0

### TC-007: 未保存确认框选择"取消"中止
- 前置条件：同 TC-004
- 操作步骤：点击"取消"
- 预期结果：确认框关闭，应用继续运行，文档内容保留；随后再次点击 X 仍重新弹确认框
- 优先级：P0

### TC-008: 无路径文档保存转另存为并取消
- 前置条件：新建文档输入内容（modified = true，无 url）
- 操作步骤：点击 X → 确认框选"保存" → 另存为对话框选"取消"
- 预期结果：流程中止，应用继续运行，内容保留
- 优先级：P1

### TC-009: 模态 UI 打开时关闭请求被忽略
- 前置条件：主菜单展开（或错误对话框/文件对话框打开）
- 操作步骤：点击标题栏关闭图标（X）
- 预期结果：关闭请求被忽略，应用继续运行（维持现状）
- 优先级：P1

### TC-010: 现有 C++ 单元测试无回归
- 前置条件：构建目录已配置
- 操作步骤：执行 `ctest --test-dir build --output-on-failure`
- 预期结果：全部测试通过
- 优先级：P0

## 测试命令

```powershell
$env:PATH = "D:\Program\Qt\Tools\CMake_64\bin;D:\Program\Qt\Tools\Ninja;" + $env:PATH
cmake -B build -G Ninja -DCMAKE_PREFIX_PATH=D:/Program/Qt/6.11.2/mingw_64 -DCMAKE_C_COMPILER=D:/Program/Qt/Tools/mingw1310_64/bin/gcc.exe -DCMAKE_CXX_COMPILER=D:/Program/Qt/Tools/mingw1310_64/bin/g++.exe
cmake --build build
ctest --test-dir build --output-on-failure
```
