## 功能概述

首次启动（`HKCU\Software\qcnote\qcnote` 无 `contextMenuPrompted` 标记）弹对话框询问是否将“用qcnote打开”加入资源管理器**文件**右键菜单；同意写入 `HKCU\Software\Classes\*\shell\qcnote`（默认值/Icon/command `"<exe>" "%1"`），拒绝仅写标记，此后不再提示。配套：命令行参数打开（恢复会话后叠加）、QLocalServer 单实例转发（服务名 `qcnote-<USERNAME>`，JSON URL 数组换行分帧，主实例叠加打开并前置窗口）。

## 已知限制（评审接受）

1. F4 回滚分支（主键成功+command 失败双失败）无自动化覆盖，改动需人工验证
2. IPC 空闲连接数无上限（本地同用户威胁模型，风险低）
3. exe 路径含 `%` 极端场景 command 值被 explorer 二次展开
4. `-` 开头文件名需 `--` 分隔（右键路径不含）
5. 首启提示与错误对话框可能视觉叠加（无死锁）
6. 主实例前置窗口受 Windows 前台锁定限制（可能仅任务栏闪烁）
7. 版本混跑期双开且旧实例收不到转发，旧实例退出后自愈
