# 测试用例：列式编辑

## 测试范围

- C++ 纯逻辑引擎 `MultiCursorEngine`（多光标集合运算、编辑指令计算、列选区计算）
- 编辑指令在 `QTextDocument` 上的原子应用（撤销合并为单步）
- QML 集成层（覆盖层渲染、事件拦截、状态栏）——offscreen 冒烟 + 人工交互验证

## 用例列表

### 单元测试（自动化，引擎与文档应用层）

### TC-001: 列选区计算-等长行
- 前置条件：文本 3 行等长（如 `aaaa/bbbb/cccc`）
- 操作步骤：以第 1 行列 2 为锚点、第 3 行列 4 为游标计算列选区
- 预期结果：3 个选区，每行覆盖列 2 至列 3（0 基偏移正确）
- 优先级：P0

### TC-002: 列选区计算-短行截断
- 前置条件：中间行长度小于选区起始列
- 操作步骤：跨短行计算列选区
- 预期结果：短行生成空选区，位置钳制在行末（不越界到下一行）
- 优先级：P0

### TC-003: 列选区计算-反向拖拽
- 前置条件：任意多行文本
- 操作步骤：锚点在右下、游标在左上（反向）计算列选区
- 预期结果：与正向等价（行列区间取 min/max），每行选区 start 小于 end
- 优先级：P0

### TC-004: 上下添加光标-保持列
- 前置条件：光标在中间行某列
- 操作步骤：`addCursorBelow` / `addCursorAbove`
- 预期结果：新增光标位于相邻行同列（字符列保持）
- 优先级：P0

### TC-005: 上下添加光标-短行钳制与边界
- 前置条件：相邻行短于当前列；或当前行已是首/末行
- 操作步骤：`addCursorBelow`（短行）；首行 `addCursorAbove`
- 预期结果：短行新光标钳制行末；首行上方添加为无操作
- 优先级：P0

### TC-006: 光标去重
- 前置条件：多光标存在
- 操作步骤：添加与现有光标同位置的光标；或编辑后产生同位光标
- 预期结果：重复（同 anchor 同 position）光标合并，数量减少
- 优先级：P0

### TC-007: 多光标插入字符
- 前置条件：3 个光标（2 个带选区、1 个空）
- 操作步骤：`insertText("x")`
- 预期结果：带选区光标替换选区为 `x`，空光标处插入 `x`；新光标位于插入文本之后
- 优先级：P0

### TC-008: 多光标 Backspace
- 前置条件：光标分别处于：有选区 / 行中有字符 / 行首
- 操作步骤：`backspace()`
- 预期结果：选区删除；行中删除前一个字符；行首与上一行合并
- 优先级：P0

### TC-009: 多光标 Delete
- 前置条件：光标分别处于：有选区 / 行中有字符 / 行尾
- 操作步骤：`deleteChar()`
- 预期结果：选区删除；行中删除后一个字符；行尾与下一行合并
- 优先级：P1

### TC-010: 多光标 Enter
- 前置条件：多个光标
- 操作步骤：`insertNewline()`
- 预期结果：各光标处插入 `\n`，光标位于新行首
- 优先级：P0

### TC-011: 多光标 Home/End（含 Shift）
- 前置条件：光标在行中间，部分带选区
- 操作步骤：`moveHome(false)` / `moveEnd(true)` 等
- 预期结果：Home/End 移至行首/行末；keepAnchor 时选区随之扩展/收缩
- 优先级：P1

### TC-012: 方向键移动与 Shift 选择
- 前置条件：多光标位于不同行列
- 操作步骤：`moveLeft/Right/Up/Down(keepAnchor)`，Up/Down 跨不同行长
- 预期结果：位置按预期移动；Up/Down 保持目标列（短行钳制）；keepAnchor 生成/调整选区
- 优先级：P0

### TC-013: Ctrl+D 下一个相同词
- 前置条件：文本含某单词多处
- 操作步骤：光标置于单词内（无选区）`selectNextOccurrence`；连续调用至环绕
- 预期结果：首次选中当前单词；后续依次追加后续出现；环绕后跳过已选；全部选中后再调用为无操作；匹配大小写敏感且不跨行
- 优先级：P0

### TC-014: Ctrl+Shift+L 全部相同词
- 前置条件：文本含某单词 N 处
- 操作步骤：选中单词后 `selectAllOccurrences`
- 预期结果：N 个选区，每个精确覆盖一处
- 优先级：P1

### TC-015: Shift+Alt+I 行尾光标
- 前置条件：选区跨越多行（含部分行选中）
- 操作步骤：`endOfLines`
- 预期结果：选区覆盖的每行行末各生成一个空选区光标，原选区清除
- 优先级：P1

### TC-016: 列复制文本拼接
- 前置条件：多个选区（含一个无选区光标）
- 操作步骤：`selectedTexts`
- 预期结果：按光标顺序返回各行文本列表（无选区对应空字符串）
- 优先级：P1

### TC-017: 粘贴-行数匹配分发
- 前置条件：3 个光标，剪贴板 3 行
- 操作步骤：`pasteLines`
- 预期结果：第 i 行插入第 i 个光标处
- 优先级：P0

### TC-018: 粘贴-行数不匹配整份插入
- 前置条件：3 个光标，剪贴板 5 行
- 操作步骤：`pasteLines`
- 预期结果：每个光标处插入以 `\n` 连接的整份文本
- 优先级：P1

### TC-019: Esc 退出保留末光标
- 前置条件：多光标
- 操作步骤：`clearToLast`
- 预期结果：仅保留按位置排序最末的光标
- 优先级：P1

### TC-020: 编辑后光标重叠合并
- 前置条件：多光标编辑后可能汇聚到同一位置
- 操作步骤：构造汇聚场景执行编辑
- 预期结果：同位光标合并为一个，光标数减少
- 优先级：P1

### TC-021: 撤销原子性
- 前置条件：`QTextDocument` 上多光标执行一次批量编辑
- 操作步骤：editBlock 应用后调用一次 `undo`
- 预期结果：一次 undo 完整回滚整批编辑（文本与撤销前一致）
- 优先级：P0

### TC-022: 边界-空文档与单行文档
- 前置条件：空文档；单行无换行文档
- 操作步骤：执行加光标、列选、编辑、Ctrl+D 等操作
- 预期结果：无崩溃、无越界，行为语义合理（无操作或钳制）
- 优先级：P0

### TC-023: Ctrl+D 重叠选区跳过与混合光标回退
- 前置条件：文档 `aaaa` 手动选区 [1,3)（部分重叠场景）；或多光标混合状态（末位为空光标）
- 操作步骤：`selectNextOccurrence`；部分重叠场景继续 `insertText("X")`；混合状态调用 `selectNextOccurrence`
- 预期结果：与任一现有选区区间严格重叠的出现被跳过（`aaaa` 选 [1,3) 时光标集不变，输入仅替换原选区得 `aXa`，不再出现编辑静默丢弃）；边界相接不算重叠，允许追加（如 `foofoo` 连续重复词：选 [0,3) 后 Ctrl+D 追加 [3,6)）；完全不相交的出现仍正常追加；末位空光标时回退取最后一个有选区光标为目标正常追加
- 优先级：P0

### TC-108: 单步撤销

- 操作步骤：多光标激活，用中文输入法输入并提交

- 操作步骤：添加多光标观察状态栏

- 预期结果：拖拽全程列选区持续跟随鼠标更新，不出现选区中途消失/定格为空；松开后列选区保留，后续多光标编辑操作正常
- 优先级：P0

## 列选区视觉对齐（增补）

> TC-V 编号为"列选区视觉对齐"需求的增补系列，独立于既有 TC-1xx 编号（既有 TC-115 为真机人工验证项，与下文自动化测试函数名 tc115 无冲突）。需求与决策详见 `决策记录-列选区视觉对齐-20261105135812.md`。

### TC-V001: 引擎区间对更新接口（自动化：test_core `tc024_columnSelectPairsUpdate`）
- 前置条件：文本任意多行；引擎实例
- 操作步骤：未进入列选状态时调 `updateColumnSelectPairs`（应无操作）；`startColumnSelect` 后传入多行区间对（含逆序、重复对、空区间）
- 预期结果：仅列选状态中生效；光标集合 = 区间对（正向、排序去重）；`isColumnSelecting` 保持 true；`finishColumnSelect` 后定格
- 优先级：P0

### TC-V003: 鼠标列选——中文混排视觉对齐（自动化：test_editor `tc114_columnDrag_cjkVisualAlignment`）
- 前置条件：文本含中文与英文行，如 `你好world\nabcdefgh\n中文xyzabc`
- 操作步骤：以行 1 某字符边界 x 为锚点 x、另一边界 x 为游标 x，跨 3 行拖拽（坐标经 `positionToRectangle` 换算）
- 预期结果：3 个选区；各行选区起点的 `positionToRectangle().x` 与第一行起点 x 一致（容差 ±2px）；选区字符数按各行实际命中确定（不按字符列复制）
- 优先级：P0

### TC-V004: 鼠标列选——短行不塌缩，竖直窄矩形（自动化：test_editor `tc115_columnDrag_shortLine_verticalNarrow()`）
- 前置条件：`aaaaaaaaaa\nbb\ncccccccccc`
- 操作步骤：行 1 列 8 的光标 x 处竖直拖拽到行 3 同 x
- 预期结果：行 1、行 3 为该列空选区（如 `8:8`、`22:22`），行 2 钳制行末 `13:13`；**不得**出现宽选区（旧行为会得 `[2,8)` 塌缩矩形）。注：位置为 fixture 行偏移下的文档坐标（行 2 行末=13、行 3 列 8=22）
- 优先级：P0

### TC-V005: 鼠标列选——短行不塌缩，水平端点（自动化：test_editor `tc116_columnDrag_shortLine_horizontalEnd()`）
- 前置条件：同 TC-V004 文本
- 操作步骤：锚点行 1 列 2，拖到行 2（短行）超出行末的 x
- 预期结果：行 1 保持 `[2, 预期列)` 宽度不变，行 2 钳制行末；不得使行 1 选区变窄
- 优先级：P0

### TC-V006: 键盘列选——短行不塌缩 + 期望 x 粘性（自动化：test_editor `tc117_keyboardColumn_shortLine_stickyX()`）
- 前置条件：同 TC-V004 文本；光标位于行 1 列 8
- 操作步骤：`Ctrl+Alt+Shift+Down` 两次（经短行到行 3）
- 预期结果：每次扩展后行 1 选区恒为 `8:8`（不塌缩）；行 2 为 `13:13`；到行 3 后行 3 为 `22:22`（粘性列恢复，非短行钳制列 2）
- 优先级：P0

### TC-V007: 键盘列选——Left/Right 字符步进与不跨行（自动化：test_editor `tc118_keyboardColumn_leftRight_fullWidth()`）
- 前置条件：行含全角字符（如 `你好world`）；光标行首
- 操作步骤：`Ctrl+Alt+Shift+Right` 步进跨过 `你`、`好`；行末继续 Right；行首 Left
- 预期结果：全角字一次整字跨过（期望 x 为该字右缘）；行末 Right / 行首 Left 不跨行、无操作（选区不变）
- 优先级：P1

### TC-V008: 键盘列选——中文混排视觉对齐（自动化：test_editor `tc119_keyboardColumn_cjkVisualAlignment()`）
- 前置条件：`你好world\nabcdefgh`；光标行 1 列 4 之后（`你`=`好` 后）
- 操作步骤：`Ctrl+Alt+Shift+Right` 数次后 `Down` 扩展到行 2
- 预期结果：行 2 选区起点视觉 x 与行 1 起点一致（±2px），而非同字符列位置
- 优先级：P1

### TC-V009: 鼠标/键盘列选——自动换行可视行分段（自动化：test_editor `tc120_columnSelect_wordWrap_visualRowSegments()`）
- 前置条件：wrap 开启；长逻辑行折为 ≥2 可视行
- 操作步骤：跨折行段做列选（鼠标或键盘）
- 预期结果：同一逻辑行按可视行产生多段选区；每段钳制各自段末；覆盖层段数正确
- 优先级：P1

### TC-V010: 鼠标列选——反向拖拽等价（自动化：test_editor `tc121_columnDrag_reverseDrag()`）
- 前置条件：任意中文/短行混排文本
- 操作步骤：自下而上拖拽（锚点在下）
- 预期结果：与正向拖拽（同矩形）产生相同选区集合
- 优先级：P1

### TC-V013: 边界与状态机（自动化：test_editor `tc122_columnSelect_boundaries_stateMachine`）
- 前置条件：单行文档、空文档、光标在首行/末行
- 操作步骤：单行/空文档上键盘列选 Up/Down；Esc / 单击退出；拖拽越出文本上/下边界
- 预期结果：边界无操作或收敛到文档边界；退出路径行为与现状一致；无越界位置、无告警日志（QTextCursor::setPosition 越界类）
- 优先级：P1

> 说明：.localdoc 原始用例系列中的 TC-V002（引擎既有接口零回归）、TC-V011（既有集成用例零回归）、TC-V012（test_searchui 适配）为零回归保障项，其断言即既有 TC-001~023 与 TC-101~115 本身，随全量 `ctest` 覆盖，不单独设立新自动化用例。

### TC-V014（真机人工）：中英文交替多行列选逐行覆盖核对
- 前置条件：Windows 真机（非 offscreen）；打开 ≥10 行中英文交替文本
- 操作步骤：先以 Alt+Shift 拖拽做列选区，再以 Ctrl+Alt+Shift+Down 连续扩展做列选区，逐行核对两种方式下选区覆盖的行数
- 预期结果：选区逐行连续覆盖，无跳行/重复行（覆盖真机字体回退下"全部可视行同高"假设）；若真机证实行高不均，按 DEC-009 备案方向（逐行推进替代固定行高累加）另行修复
- 优先级：P0
