# 测试用例：列式编辑

## 测试范围

- C++ 纯逻辑引擎 `MultiCursorEngine`（多光标集合运算、编辑指令计算、列选区计算）
- 编辑指令在 `QTextDocument` 上的原子应用（撤销合并为单步）
- QML 集成层（覆盖层渲染、事件拦截、状态栏）——offscreen 冒烟 + 人工交互验证

## 用例列表

### 单元测试（自动化，引擎与文档应用层）

### TC-001: 列选区计算-等长行
- 前置条件：文本 3 行等长（如 `aaaa/bbbb/cccc`）
- 操作步骤：以第 1 行列 2 为锚点、第 3 行列 4 为游标计算列选区
- 预期结果：3 个选区，每行覆盖列 2 至列 3（0 基偏移正确）
- 优先级：P0

### TC-002: 列选区计算-短行截断
- 前置条件：中间行长度小于选区起始列
- 操作步骤：跨短行计算列选区
- 预期结果：短行生成空选区，位置钳制在行末（不越界到下一行）
- 优先级：P0

### TC-003: 列选区计算-反向拖拽
- 前置条件：任意多行文本
- 操作步骤：锚点在右下、游标在左上（反向）计算列选区
- 预期结果：与正向等价（行列区间取 min/max），每行选区 start 小于 end
- 优先级：P0

### TC-004: 上下添加光标-保持列
- 前置条件：光标在中间行某列
- 操作步骤：`addCursorBelow` / `addCursorAbove`
- 预期结果：新增光标位于相邻行同列（字符列保持）
- 优先级：P0

### TC-005: 上下添加光标-短行钳制与边界
- 前置条件：相邻行短于当前列；或当前行已是首/末行
- 操作步骤：`addCursorBelow`（短行）；首行 `addCursorAbove`
- 预期结果：短行新光标钳制行末；首行上方添加为无操作
- 优先级：P0

### TC-006: 光标去重
- 前置条件：多光标存在
- 操作步骤：添加与现有光标同位置的光标；或编辑后产生同位光标
- 预期结果：重复（同 anchor 同 position）光标合并，数量减少
- 优先级：P0

### TC-007: 多光标插入字符
- 前置条件：3 个光标（2 个带选区、1 个空）
- 操作步骤：`insertText("x")`
- 预期结果：带选区光标替换选区为 `x`，空光标处插入 `x`；新光标位于插入文本之后
- 优先级：P0

### TC-008: 多光标 Backspace
- 前置条件：光标分别处于：有选区 / 行中有字符 / 行首
- 操作步骤：`backspace()`
- 预期结果：选区删除；行中删除前一个字符；行首与上一行合并
- 优先级：P0

### TC-009: 多光标 Delete
- 前置条件：光标分别处于：有选区 / 行中有字符 / 行尾
- 操作步骤：`deleteChar()`
- 预期结果：选区删除；行中删除后一个字符；行尾与下一行合并
- 优先级：P1

### TC-010: 多光标 Enter
- 前置条件：多个光标
- 操作步骤：`insertNewline()`
- 预期结果：各光标处插入 `\n`，光标位于新行首
- 优先级：P0

### TC-011: 多光标 Home/End（含 Shift）
- 前置条件：光标在行中间，部分带选区
- 操作步骤：`moveHome(false)` / `moveEnd(true)` 等
- 预期结果：Home/End 移至行首/行末；keepAnchor 时选区随之扩展/收缩
- 优先级：P1

### TC-012: 方向键移动与 Shift 选择
- 前置条件：多光标位于不同行列
- 操作步骤：`moveLeft/Right/Up/Down(keepAnchor)`，Up/Down 跨不同行长
- 预期结果：位置按预期移动；Up/Down 保持目标列（短行钳制）；keepAnchor 生成/调整选区
- 优先级：P0

### TC-013: Ctrl+D 下一个相同词
- 前置条件：文本含某单词多处
- 操作步骤：光标置于单词内（无选区）`selectNextOccurrence`；连续调用至环绕
- 预期结果：首次选中当前单词；后续依次追加后续出现；环绕后跳过已选；全部选中后再调用为无操作；匹配大小写敏感且不跨行
- 优先级：P0

### TC-014: Ctrl+Shift+L 全部相同词
- 前置条件：文本含某单词 N 处
- 操作步骤：选中单词后 `selectAllOccurrences`
- 预期结果：N 个选区，每个精确覆盖一处
- 优先级：P1

### TC-015: Shift+Alt+I 行尾光标
- 前置条件：选区跨越多行（含部分行选中）
- 操作步骤：`endOfLines`
- 预期结果：选区覆盖的每行行末各生成一个空选区光标，原选区清除
- 优先级：P1

### TC-016: 列复制文本拼接
- 前置条件：多个选区（含一个无选区光标）
- 操作步骤：`selectedTexts`
- 预期结果：按光标顺序返回各行文本列表（无选区对应空字符串）
- 优先级：P1

### TC-017: 粘贴-行数匹配分发
- 前置条件：3 个光标，剪贴板 3 行
- 操作步骤：`pasteLines`
- 预期结果：第 i 行插入第 i 个光标处
- 优先级：P0

### TC-018: 粘贴-行数不匹配整份插入
- 前置条件：3 个光标，剪贴板 5 行
- 操作步骤：`pasteLines`
- 预期结果：每个光标处插入以 `\n` 连接的整份文本
- 优先级：P1

### TC-019: Esc 退出保留末光标
- 前置条件：多光标
- 操作步骤：`clearToLast`
- 预期结果：仅保留按位置排序最末的光标
- 优先级：P1

### TC-020: 编辑后光标重叠合并
- 前置条件：多光标编辑后可能汇聚到同一位置
- 操作步骤：构造汇聚场景执行编辑
- 预期结果：同位光标合并为一个，光标数减少
- 优先级：P1

### TC-021: 撤销原子性
- 前置条件：`QTextDocument` 上多光标执行一次批量编辑
- 操作步骤：editBlock 应用后调用一次 `undo`
- 预期结果：一次 undo 完整回滚整批编辑（文本与撤销前一致）
- 优先级：P0

### TC-022: 边界-空文档与单行文档
- 前置条件：空文档；单行无换行文档
- 操作步骤：执行加光标、列选、编辑、Ctrl+D 等操作
- 预期结果：无崩溃、无越界，行为语义合理（无操作或钳制）
- 优先级：P0

### TC-023: Ctrl+D 重叠选区跳过与混合光标回退
- 前置条件：文档 `aaaa` 手动选区 [1,3)（部分重叠场景）；或多光标混合状态（末位为空光标）
- 操作步骤：`selectNextOccurrence`；部分重叠场景继续 `insertText("X")`；混合状态调用 `selectNextOccurrence`
- 预期结果：与任一现有选区区间严格重叠的出现被跳过（`aaaa` 选 [1,3) 时光标集不变，输入仅替换原选区得 `aXa`，不再出现编辑静默丢弃）；边界相接不算重叠，允许追加（如 `foofoo` 连续重复词：选 [0,3) 后 Ctrl+D 追加 [3,6)）；完全不相交的出现仍正常追加；末位空光标时回退取最后一个有选区光标为目标正常追加
- 优先级：P0

### 交互测试（人工验证，QML 集成层）

### TC-101: Alt+Click 添加光标与同步输入
- 前置条件：打开多行文本文档
- 操作步骤：`Alt+单击` 两处添加光标，输入字符、Backspace
- 预期结果：出现 2+ 光标，输入在所有光标同步生效；额外光标可见
- 优先级：P0

### TC-102: Ctrl+Alt+Up/Down 加光标
- 操作步骤：连续 `Ctrl+Alt+Down` 三次后输入
- 预期结果：4 行同列各一个光标，同步输入
- 优先级：P0

### TC-103: Alt+Shift+拖拽列选区
- 操作步骤：`Alt+Shift` 按住拖拽出矩形，输入字符，再试 Backspace
- 预期结果：每行高亮列区间；输入逐行替换各行选区；覆盖层高亮随滚动正确
- 优先级：P0

### TC-104: 键盘列选区
- 操作步骤：`Ctrl+Alt+Shift+Down/Right` 扩展列选后输入
- 预期结果：与鼠标列选等价
- 优先级：P1

### TC-105: Shift+Alt+I 行尾光标
- 操作步骤：普通方式选中多行，`Shift+Alt+I`，输入 `;`
- 预期结果：每行行末出现光标，各行行尾同时插入 `;`
- 优先级：P1

### TC-106: Ctrl+D / Ctrl+Shift+L
- 操作步骤：`Ctrl+D` 连续多次；`Ctrl+Shift+L`；输入替换
- 预期结果：依次/全部选中相同单词并同步替换
- 优先级：P0

### TC-107: 列复制/粘贴/剪切
- 操作步骤：列选后 `Ctrl+C` 粘贴到记事本核对；多光标 `Ctrl+V` 行数匹配与不匹配两种；`Ctrl+X` 后核对删除
- 预期结果：复制为按行拼接文本；匹配逐行分发、不匹配整份插入；剪切删原选区
- 优先级：P0

### TC-108: 单步撤销
- 操作步骤：多光标一次输入后按一次 `Ctrl+Z`
- 预期结果：所有光标的插入一步回滚；重做一步恢复
- 优先级：P0

### TC-109: Esc/单击退出多光标
- 操作步骤：多光标状态下 `Esc`；再次多光标后普通单击
- 预期结果：退回单光标（保留末光标 / 单击处），后续编辑单点生效
- 优先级：P1

### TC-110: 中文输入法分发
- 操作步骤：多光标激活，用中文输入法输入并提交
- 预期结果：预编辑仅在主光标显示，提交后所有光标同步插入
- 优先级：P1

### TC-111: 状态栏光标数
- 操作步骤：添加多光标观察状态栏
- 预期结果：显示"光标 ×N"（N 大于 1 时），退出后消失
- 优先级：P2

### TC-112: 单光标回归
- 操作步骤：不加多光标时执行原有全部编辑操作（输入、选择、复制、粘贴、撤销、IME）
- 预期结果：与改动前行为完全一致，无事件被拦截
- 优先级：P0

### TC-113: 标签页切换与外部重置
- 操作步骤：A 文档多光标后切到 B 再切回；对 A 重新打开（外部重置内容）
- 预期结果：切回后多光标保留；内容重置后退回单光标且不崩溃
- 优先级：P1

### TC-114: offscreen 冒烟
- 操作步骤：`QT_QPA_PLATFORM=offscreen` 启动 qcnote.exe，新建文档、输入、结束进程
- 预期结果：启动与退出无崩溃、无 QML 错误输出
- 优先级：P0

### TC-115: Alt+Shift 长时间拖拽列选区不被 Alt 自动重复中断
- 前置条件：Windows 真机（非 offscreen）；打开多行文本文档
- 操作步骤：按住 Alt+Shift 后按住鼠标左键向斜下方拖拽形成列选区，保持按住 Alt 与鼠标持续拖拽 3 秒以上（覆盖 Windows Alt 键自动重复期间），松开鼠标完成选择；再按 Shift+方向键等验证选区仍可继续操作
- 预期结果：拖拽全程列选区持续跟随鼠标更新，不出现选区中途消失/定格为空；松开后列选区保留，后续多光标编辑操作正常
- 优先级：P0
