# 测试用例：最大化图标切换修复

## 测试范围

`src/qml/CaptionButton.qml` 的 Canvas 重绘触发补充；验证最大化/还原图标随窗口状态切换。

## 用例列表

### TC-001: 点击按钮最大化后图标切换为恢复图形
- 前置条件：应用启动，窗口为普通状态，图标显示"最大化"图形（单个矩形）
- 操作步骤：点击标题栏最大化按钮
- 预期结果：窗口最大化，按钮图标立即变为"恢复大小"图形（两个叠加矩形），无障碍名称变为"还原"
- 优先级：P0

### TC-002: 点击按钮还原后图标切换回最大化图形
- 前置条件：窗口处于最大化状态，图标显示"恢复大小"图形
- 操作步骤：点击标题栏该按钮
- 预期结果：窗口还原为普通状态，图标立即变回"最大化"图形，无障碍名称变为"最大化"
- 优先级：P0

### TC-003: 双击标题栏空白区最大化/还原图标跟随
- 前置条件：应用启动，窗口为普通状态
- 操作步骤：双击标题栏空白区 → 再双击一次
- 预期结果：第一次双击后图标变为"恢复"图形；第二次双击还原后图标变回"最大化"图形
- 优先级：P1

### TC-004: 系统快捷键（Win+Up / Win+Down）图标跟随
- 前置条件：应用启动，窗口为普通状态
- 操作步骤：按 Win+Up 最大化 → 按 Win+Down 还原
- 预期结果：图标随两次状态变化分别切换为"恢复"/"最大化"图形
- 优先级：P1

### TC-005: 最大化时拖拽标题栏还原图标跟随
- 前置条件：窗口处于最大化状态
- 操作步骤：按住标题栏空白区向下拖动（触发拖拽还原）
- 预期结果：窗口还原并跟随拖拽，图标变回"最大化"图形
- 优先级：P1

### TC-006: 其他标题栏按钮不受影响
- 前置条件：应用启动
- 操作步骤：悬停/点击菜单、最小化、关闭按钮，观察图标与行为
- 预期结果：三个按钮图标绘制正常、悬停/按下状态正常、行为不变
- 优先级：P1

### TC-007: 现有单元测试无回归
- 前置条件：项目已构建
- 操作步骤：`ctest --test-dir build --output-on-failure`
- 预期结果：全部既有测试通过（3 个测试类共 46 个测试函数）
- 优先级：P0

### TC-008: offscreen 冒烟无 QML 错误
- 前置条件：项目已构建
- 操作步骤：`QT_QPA_PLATFORM=offscreen` 启动 qcnote.exe，检查 QML/控制台错误输出，随后结束进程
- 预期结果：无 QML 错误、无绑定错误；进程正常退出
- 优先级：P0

### TC-009: qmllint 改动行无警告
- 前置条件：无
- 操作步骤：对 `src/qml/CaptionButton.qml` 运行 qmllint
- 预期结果：改动行无新增警告
- 优先级：P2
