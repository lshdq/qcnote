# 测试用例：退出免提示与草稿缓存单例修复

## 测试范围

`DocumentManager` 单例构造修复、`DraftCacheManager` 恢复激活与失焦即写、`Main.qml` 退出免提示热退出、QML 集成级草稿链路回归（真实 Main.qml + 真实防抖）。

## 用例列表

### TC-001: QML 单例解析经 create 工厂（根因回归）
- 前置条件：offscreen 加载真实 Main.qml
- 操作步骤：QML 侧触发 DocumentManager 单例解析；C++ 侧比对引擎使用实例与 `DocumentManager::instance()`（经「newDocument 后 documentsChanged 联动」或等价探针断言同源）
- 预期结果：全程仅一个 DocumentManager 实例；DraftCacheManager 收到文档信号
- 优先级：P0

### TC-002: 真实防抖链路写盘（修复前红/修复后绿）
- 前置条件：TC-001 环境；缓存目录重定向到临时目录
- 操作步骤：`newDocument()` + `setContent("...")`；等待 ≥1.2 秒（不手动 flush）
- 预期结果：草稿条目落盘，字段正确（content/name/uid）
- 优先级：P0

### TC-003: 未命名草稿恢复后激活
- 前置条件：缓存目录放置合法未命名条目；会话无文档（无活动标签）
- 操作步骤：加载 Main.qml（restoreDrafts 运行）
- 预期结果：未命名文档恢复、`activeDocument` 指向它、内容区显示其内容（非欢迎页）
- 优先级：P0

### TC-004: 会话有活动标签时恢复仍不抢占
- 前置条件：会话恢复激活文档 A；另有未命名草稿条目
- 操作步骤：restoreDrafts 恢复未命名文档
- 预期结果：activeDocument 仍为 A（既有 TC-015 语义不变）
- 优先级：P1

### TC-005: 失焦即写
- 前置条件：C++ 单测（QGuiApplication 或注入模拟）；脏文档在防抖窗口内
- 操作步骤：触发 applicationStateChanged(ApplicationInactive)
- 预期结果：pending 立即落盘（不等待防抖到期）
- 优先级：P0

### TC-006: 退出免提示（文件文档脏）
- 前置条件：offscreen Main.qml；打开文件并修改（modified）
- 操作步骤：`QWindow::close()`（等价 X/Alt+F4）
- 预期结果：不弹未保存确认框，窗口直接关闭放行；草稿条目保留（未被清理）
- 优先级：P0

### TC-007: 退出免提示（未命名文档脏）
- 前置条件：未命名文档有内容
- 操作步骤：close()
- 预期结果：同 TC-006，草稿保留
- 优先级：P0

### TC-008: 退出后有模态打开仍拒绝
- 前置条件：任一模态对话框打开（如错误框）
- 操作步骤：close()
- 预期结果：close 被拒绝（uiLocked 语义不变）
- 优先级：P1

### TC-009: 标签页关闭确认保留
- 前置条件：脏文档；Ctrl+W 等价调用
- 操作步骤：关闭标签 → 三选框出现；选「不保存」
- 预期结果：确认框行为与现状一致；该文档草稿被清理（重启不恢复）
- 优先级：P0

### TC-010: 热退出全链路（端到端）
- 前置条件：便携标记钉缓存目录（或等价重定向）；真实进程
- 操作步骤：新建标签输入内容 → 等 2 秒 → 正常退出（非强杀）→ 重启
- 预期结果：内容恢复为未保存状态且标签激活
- 优先级：P1

### TC-011: 强杀全链路（端到端，用户场景）
- 前置条件：同 TC-010
- 操作步骤：新建标签输入内容 → 等 2 秒 → TerminateProcess 强杀 → 重启
- 预期结果：同 TC-010
- 优先级：P0

### TC-012: 强杀前失焦场景（端到端）
- 前置条件：同 TC-010
- 操作步骤：输入后立即（<1 秒）使窗口失焦 → 强杀 → 重启
- 预期结果：草稿恢复（失焦即写兜住防抖窗口）
- 优先级：P1

### TC-013: 既有行为回归
- 前置条件：全量测试
- 操作步骤：ctest 全量
- 预期结果：10/10（含语义更新后的 test_window 与新增 test_draftsingleton）；无回归
- 优先级：P0
