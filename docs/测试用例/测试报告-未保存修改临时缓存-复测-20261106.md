### 2. 补充独立视角用例（落仓库，见"测试代码变更"）

`tripleUrlEntriesDedupeKeepsNewestAmongThree`：**三条目同 URL 不同 savedAt 的多路去重 + 未命名条目混合**。三条目按枚举顺序到达 savedAt=100 → 300 → 200，其中第二条触发"保留者被替换"（`kept = candidate`）分支，第三条再与替换后的保留者比较落选——若去重的下标/对象在替换后失准，第三条会与已被替换出的第一条幽灵比较胜出，最终错误应用中间条目内容（断言 content == "newest-draft" 可捕获）；同盘混入未命名条目（savedAt 最小），断言其不参与去重、不受影响、独立恢复（displayName/content/modified）。结果：**pass**（前置断言 4 条目在盘 → 恢复后 0 条目、2 文档、无冲突信号）。

### 3. 全子集回归

`QC_TEST_ONLY=draftcache` 全量 25 用例（24 既有 + 1 本次补充）：函数级 pass=27（含 init/cleanup）、fail=0，退出码 0。

**修复 #1 结论：通过。** 源码级复核（src/document/draftcachemanager.cpp 阶段二）确认：去重发生在分类处理之前、落选条目立即删文件、未命名条目不参与去重、平局规则确定性（不依赖目录枚举顺序），与 DEC-009 决策一致。
