# 测试用例：打开文件图标更换

## 测试范围

图标资源替换后的内容风格一致性、构建、运行冒烟与既有测试回归。

## 用例列表

### TC-001: 图标文件内容正确
- 前置条件：`src/qml/icons/open.svg` 已替换为 folder-open。
- 操作步骤：读取该文件，对照 `new.svg` / `save.svg` 检查参数。
- 预期结果：24×24 viewBox、`fill="none"`、`stroke="#000000"`、`stroke-width="2"`、`stroke-linecap="round"`、`stroke-linejoin="round"`，路径为 folder-open（掀开盖子的文件夹）形状。
- 优先级：P0

### TC-002: 构建通过
- 前置条件：无。
- 操作步骤：`cmake --build build`。
- 预期结果：构建成功，图标打包进 QML 资源。
- 优先级：P0

### TC-003: offscreen 启动无资源错误
- 前置条件：构建产物 `build/qcnote.exe` 存在。
- 操作步骤：`QT_QPA_PLATFORM=offscreen` 启动，随后结束进程。
- 预期结果：进程正常启动退出，无 SVG 加载报错。
- 优先级：P0

### TC-004: 既有单元测试不回归
- 前置条件：构建完成。
- 操作步骤：`ctest --test-dir build --output-on-failure`。
- 预期结果：全部测试通过。
- 优先级：P1

## 测试命令

```powershell
$env:PATH = "D:\Program\Qt\Tools\CMake_64\bin;D:\Program\Qt\Tools\Ninja;" + $env:PATH
cmake --build build
ctest --test-dir build --output-on-failure
$env:PATH = "D:\Program\Qt\6.11.2\mingw_64\bin;D:\Program\Qt\Tools\mingw1310_64\bin;" + $env:PATH
$env:QT_QPA_PLATFORM = "offscreen"
Start-Process -FilePath "E:\works\qcnote\build\qcnote.exe"
Get-Process qcnote | Stop-Process -Force
```
