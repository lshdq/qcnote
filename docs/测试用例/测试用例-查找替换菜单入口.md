# 测试用例：查找替换菜单入口

## 测试范围

- 主菜单重组（文件 / 搜索 / 视图）结构与命名正确性。
- 「搜索」四项行为与既有快捷键语义一致性。
- 既有菜单条目与快捷键零回归。
- 构建、单元测试、offscreen 冒烟。

## 用例列表

### TC-001: 菜单结构重组正确
- 前置条件：启动应用，打开任一文档。
- 操作步骤：展开主菜单，逐级检查「文件」「搜索」「视图」「退出」。
- 预期结果：
  - 文件 ▸：新建(Ctrl+N) / 打开…(Ctrl+O) / 保存(Ctrl+S) / 另存为…(Ctrl+Shift+S) / 关闭标签页(Ctrl+W) / 编码 ▸（内含 通过编码重新加载 ▸ UTF-8/GBK、通过编码保存 ▸ UTF-8/GBK）；
  - 搜索 ▸：查找…(Ctrl+F) / 替换…(Ctrl+H) / 下一个(F3) / 上一个(Shift+F3)；
  - 视图 ▸：深色主题 / 自动换行（标题为「视图」，不再是「查看」）；
  - 退出在顶层；快捷键文本右对齐显示。
- 优先级：P0

### TC-002: 无文档时搜索条目置灰
- 前置条件：仅欢迎页（无任何文档）。
- 操作步骤：主菜单 → 搜索。
- 预期结果：查找… / 替换… / 下一个 / 上一个 全部禁用置灰；「文件」内 保存 / 另存为… / 关闭标签页 / 编码 置灰状态与改前一致；新建 / 打开… 可用。
- 优先级：P0

### TC-003: 查找…入口行为
- 前置条件：打开文档，选中一段不含换行的文本。
- 操作步骤：主菜单 → 搜索 → 查找…。
- 预期结果：打开查找替换对话框（顶部对齐模态），查找框内容为选区文本且全选，背后全部匹配高亮；焦点在查找框。
- 优先级：P0

### TC-004: 替换…入口行为
- 前置条件：同 TC-003。
- 操作步骤：主菜单 → 搜索 → 替换…。
- 预期结果：打开同一对话框，焦点在替换输入框。
- 优先级：P0

### TC-005: 下一个 / 上一个跳转
- 前置条件：执行过一次查找（有多个匹配）后按 Esc 关闭对话框。
- 操作步骤：主菜单 → 搜索 → 下一个 / 上一个 交替点击数次。
- 预期结果：跳转到下一/上一匹配并滚动可见、以原生选区呈现（环绕）；与 F3 / Shift+F3 行为一致；不恢复全部高亮（DEC-009）。
- 优先级：P0

### TC-006: 无匹配时下一个/上一个无操作
- 前置条件：打开文档但从未查找，或上次查找串无匹配。
- 操作步骤：点击 下一个 / 上一个。
- 预期结果：无任何变化，不崩溃、不弹窗。
- 优先级：P1

### TC-007: 对话框打开时菜单不可达
- 前置条件：查找对话框打开。
- 操作步骤：尝试点击主菜单按钮。
- 预期结果：被模态遮罩阻断，主菜单无法打开（与改前一致）。
- 优先级：P1

### TC-008: 既有菜单条目零回归
- 前置条件：打开含未保存修改的文档。
- 操作步骤：逐项触发 文件→新建 / 打开… / 保存 / 另存为… / 关闭标签页；编码→通过编码重新加载（未保存时确认框）/ 通过编码保存；视图→深色主题 / 自动换行；退出（未保存时确认流程）。
- 预期结果：与重组前行为完全一致（确认框、置灰条件、编码当前项打勾、工具栏自动换行按钮状态联动等）。
- 优先级：P0

### TC-009: 窗口级快捷键零回归
- 操作步骤：依次使用 Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S / Ctrl+W / Ctrl+F / Ctrl+H / F3 / Shift+F3 / Ctrl+Tab / Ctrl+Shift+Tab。
- 预期结果：全部与改前一致；菜单中显示的快捷键文本与实际生效快捷键一致。
- 优先级：P0

### TC-010: 构建与单元测试
- 操作步骤：见「测试命令」。
- 预期结果：构建成功；ctest 全部通过（查找引擎等既有单测零回归）。
- 优先级：P0

### TC-011: offscreen 冒烟
- 操作步骤：`QT_QPA_PLATFORM=offscreen` 启动 `build\qcnote.exe`，数秒后结束进程。
- 预期结果：启动不崩溃、无 QML 错误输出，正常结束。
- 优先级：P0
