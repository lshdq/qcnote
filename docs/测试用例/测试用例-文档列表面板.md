# 测试用例：文档列表面板

## 测试范围

新增 `ui::DocListPanel` 组件（src/ui/doclist.h/.cpp）、core 会话持久化扩展
（docListVisible/docListWidth）、main.cpp 组装接线（布局/路由/命令/selftest）、
CMake 构建目标、test_doclist 单测与 verify-doclist-selftest.ps1。回归覆盖
既有 9 套 Catch2 与全部 verify-*.ps1。

## 用例列表

### TC-001: 面板默认隐藏与菜单开关
- 前置条件：全新用户目录（无会话 ini），启动程序。
- 操作步骤：观察初始无面板；打开菜单 视图▸文档列表 点击。
- 预期结果：默认隐藏；勾选后面板出现于左侧（工具栏底~状态栏顶），再点取消
  勾选隐藏；编辑区随之收缩/铺满，菜单勾选态实时正确。
- 优先级：P0

### TC-002: 列表条目与文档状态同步
- 前置条件：面板可见；新建 2 个未命名文档 + 打开 2 个磁盘文件。
- 操作步骤：依次新建、打开、关闭、修改内容、另存为、重命名。
- 预期结果：条目数量/顺序与 Tab 条一致；显示名、未保存 ● 标记、路径
  tooltip 可用性（hasPath）实时同步；关闭文档后条目消失且活动条目正确。
- 优先级：P0

### TC-003: 点击切换活动文档
- 前置条件：面板可见，≥3 个文档，当前活动为第 1 个。
- 操作步骤：点击列表第 3 条；再点击 Tab 条第 2 条。
- 预期结果：点击列表条目 → 该文档激活（列表高亮、Tab 高亮、标题栏、
  状态栏联动，焦点回到编辑器）；反向经 Tab 切换时列表高亮同步移动。
- 优先级：P0

### TC-004: 分隔条拖拽调整宽度
- 前置条件：面板可见，默认宽 200 逻辑像素。
- 操作步骤：hover 分隔条（光标变 IDC_SIZEWE）；按住拖至 100、拖至超过
  客户区宽/3、拖至窗口极窄；按 Esc 取消拖拽；拖拽中把鼠标移出窗口松手。
- 预期结果：宽度实时调整且钳制 [120, 客户区宽/3]；编辑区实时重排；Esc
  回拖拽前宽度；捕获丢失/失焦安全收口不悬挂；拖拽结束后宽度持久化。
- 优先级：P0

### TC-005: 会话持久化与恢复
- 前置条件：面板可见、宽度拖至 260；正常退出重启。
- 预期结果：重启后面板仍可见、宽度 260（DPI 同值换算）；旧版 ini（无新键）
  读取回退默认（隐藏、200）；值越界时恢复钳制。
- 优先级：P0

### TC-006: 溢出滚动与滚动条
- 前置条件：面板可见；创建使条目总高超出面板高的文档数（如 40 个）。
- 操作步骤：滚轮向下/向上；点击滚动条轨道与箭头；程序化激活可视区外条目。
- 预期结果：滚动钳制 [0, maxScroll]；滚动条滑块比例正确、主题色渲染；
  激活条目自动滚入可视区；无溢出时滚动条不显示且滚轮无操作。
- 优先级：P1

### TC-007: 右键菜单命令
- 前置条件：面板可见，≥3 个文档（含未命名与有路径条目）。
- 操作步骤：右键有路径条目 → 重命名…、打开所在文件夹；右键任一条目 →
  关闭右边所有/关闭左边所有/关闭其他文件；右键未命名条目。
- 预期结果：命令语义与 Tab 右键一致；批量关闭走同一确认流程；未命名条目
  的重命名/打开所在文件夹置灰不隐藏；不激活被右键的条目。
- 优先级：P1

### TC-008: 空态与欢迎页联动
- 前置条件：面板可见；关闭全部文档进入欢迎页；再新建一个文档。
- 预期结果：空面板照常显示（无条目、无滚动条）；欢迎页内容在面板右侧
  居中；新建文档后面板出现条目、欢迎页消失、编辑区正常接管。
- 优先级：P1

### TC-009: 双主题换肤
- 前置条件：面板可见且有条目（含活动/悬停/未保存 ● 标记、滚动条）。
- 操作步骤：切换 视图▸深色主题，再切回浅色。
- 预期结果：面板底色/文字/高亮/指示条/滚动条即时换肤无残留；主题选择
  本身仍随会话记忆（不回归）。
- 优先级：P1

### TC-010: DPI 缩放
- 前置条件：100% DPI 主屏 + 200% DPI 副屏（或 DPI 模拟）。
- 操作步骤：拖动窗口跨屏；面板可见状态下在两屏分别点击条目、拖拽分隔条。
- 预期结果：条目几何/命中/字体/滚动条宽度按新 DPI 重算；宽度逻辑像素
  语义稳定；命中无偏移。
- 优先级：P1

### TC-011: 纯函数单测（几何/命中/钳制）
- 前置条件：构建 test_doclist 目标。
- 操作步骤：运行 ctest -R doclist。
- 预期结果：条目几何/命中（含滚动偏移）、滚动钳制、宽度钳制、分隔条
  命中、右键菜单模型、无障碍名称、同值短路全部断言通过；DPI 200% 换算
  用例正确。
- 优先级：P0

### TC-012: selftest 自动化链路
- 前置条件：构建 qcnote.exe。
- 操作步骤：pwsh -NoProfile -File tests\verify-doclist-selftest.ps1
  （--headless 启动，不扰前台）。
- 预期结果：面板显隐/编辑区收缩、条目同步、点击切换、拖拽调宽（合成
  消息）、滚动、空面板、会话往返各阶段断言全过；结果文件生成且 PASS。
- 优先级：P0

### TC-013: 既有功能回归
- 前置条件：全部改动就绪。
- 操作步骤：ctest --test-dir build-win --output-on-failure；依次运行既有
  全部 verify-*.ps1（menu/tabs/doc/search/theme/instance-shell/
  session-draft/portable-deploy/smoke/metrics）。
- 预期结果：全部既有套件无回归（尤其 Tab 条布局、会话 e2e、指标）。
- 优先级：P0

### TC-014: 防扰与资源清理
- 前置条件：自动化验证全部完成。
- 操作步骤：观察任务栏与前台焦点；检查进程退出。
- 预期结果：全程无可见窗口、无任务栏闪现、不抢焦点（--headless /
  --noactivate 钩子沿用）；退出无句柄泄漏导致的挂起。
- 优先级：P1

## 测试命令

```powershell
# 构建（Release）
cmake -B build-win -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-win

# 单元测试（9 套 Catch2）
ctest --test-dir build-win --output-on-failure

# 本功能 selftest（headless）
pwsh -NoProfile -File tests\verify-doclist-selftest.ps1

# 既有 selftest/e2e/冒烟/指标（回归）
pwsh -NoProfile -File tests\verify-menu-selftest.ps1
pwsh -NoProfile -File tests\verify-tabs-selftest.ps1
pwsh -NoProfile -File tests\verify-doc-selftest.ps1
pwsh -NoProfile -File tests\verify-search-selftest.ps1
pwsh -NoProfile -File tests\verify-theme-selftest.ps1
pwsh -NoProfile -File tests\verify-instance-shell-e2e.ps1
pwsh -NoProfile -File tests\verify-session-draft-e2e.ps1
pwsh -NoProfile -File tests\verify-portable-deploy-selftest.ps1
pwsh -NoProfile -File tools\verify-smoke.ps1
pwsh -NoProfile -File tools\verify-metrics.ps1 -ExePath build-win\qcnote.exe
```

- 业务代码：会话持久化（test_session 增补）、组装层接线与 selftest
- 通用：构建、回归、防扰约定
