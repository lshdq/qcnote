### 2.1 无活动文档 + 文件缺失冲突条目 → resolveConflicts(true) → 激活

用例：`TestDraftCacheManager::conflictResolveRestoresActivatesWhenNoActiveDocument`（tst_draftcachemanager.cpp:936）

场景构造（与开发自测同等的独立视角核实）：
- 预放置文件缺失冲突条目（url 指向不存在的 `missing-act.txt`，missing=true）
- `DocumentManager mgr(nullptr)`，前置断言 `activeDocument() == nullptr`
- `restoreDrafts()` → 断言 `conflictsFound` 发出 1 次、documents 数为 0（未先行恢复）
- `resolveConflicts(true)` → 断言恢复未命名文档 1 个、content=`missing-dirty`、**`activeDocument()` 指向恢复文档（DEC-006）**

XML 输出结果：


**结论：通过。**

### 2.3 代码走查确认

`draftcachemanager.cpp` `resolveConflicts()`（282–319 行）：`activeBefore` 仅在 `restore && m_manager` 时记录；恢复后 `!activeBefore && firstRestored && documents().contains(firstRestored.data())` 才激活；丢弃分支（restore=false）`firstRestored` 恒空、不激活。QPointer 防悬垂 + contains 校验，与 restoreDrafts 末尾激活逻辑风格一致。实现与用例、需求 DEC-006 描述相符。
