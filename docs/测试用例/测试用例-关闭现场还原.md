# 测试用例：关闭现场还原（标签顺序与活动标签）

## 测试范围

SessionManager 未命名条目记录与暂存接口、DocumentManager 按位插入、DraftCacheManager 保序恢复与激活优先级、端到端现场还原。

## 用例列表

### TC-001: 会话记录未命名条目位置与 uid
- 前置条件：注入临时会话文件的 SessionManager
- 操作步骤：打开 [文件A, 未命名1(有内容), 文件B] → 触发保存
- 预期结果：documents/size=3；条目 2 无 url 但有 uid（= 未命名文档 uid）；条目 1/3 有 url；顺序与标签栏一致
- 优先级：P0

### TC-002: 活动标签为未命名时记录 activeUid
- 前置条件：同上，活动 = 未命名1
- 操作步骤：保存会话
- 预期结果：documents/activeUid = 未命名1 的 uid；无 active 键
- 优先级：P0

### TC-003: 活动标签为文件时维持现状
- 前置条件：活动 = 文件B
- 操作步骤：保存会话
- 预期结果：documents/active = 文件B 的 URL；无 activeUid 键
- 优先级：P1

### TC-004: 恢复暂存接口
- 前置条件：会话文件含未命名条目
- 操作步骤：restoreDocuments 后查询 pendingDraftPosition(uid) / pendingActiveDraftUid()
- 预期结果：返回会话记录的位置与 uid；未知 uid 返回 -1；无记录返回空串
- 优先级：P0

### TC-005: 按位插入
- 前置条件：DocumentManager 已有若干文档
- 操作步骤：restoreUntitledDraft(content, name, index) 以合法/越界 index 调用
- 预期结果：文档插入指定位置（model 与 documents() 一致）；越界钳制到 [0, size]；-1 追加
- 优先级：P0

### TC-006: 保序恢复
- 前置条件：SessionManager 暂存 [文件A@0, 未命名1@1, 文件B@2]；草稿含未命名1 条目
- 操作步骤：restoreDocuments（开 A、B）→ restoreDrafts
- 颅期结果：最终顺序 [A, 未命名1, B]；未命名1 内容/modified 正确
- 优先级：P0

### TC-007: 激活优先级——activeUid 匹配
- 前置条件：TC-006 场景，activeUid = 未命名1 的 uid
- 操作步骤：restoreDrafts
- 预期结果：activeDocument = 未命名1（优先于 activeBefore=文件B 复位）
- 优先级：P0

### TC-008: 激活优先级——uid 不匹配回退
- 前置条件：activeUid 为不存在于草稿的 uid（如无内容未命名标签）
- 操作步骤：restoreDrafts
- 预期结果：回退现有规则（activeBefore 存活则复位；空则激活首个恢复文档）
- 优先级：P0

### TC-009: 无会话暂存回退
- 前置条件：C++ 测试无 SessionManager 实例（或会话无 uid 记录）
- 操作步骤：restoreDrafts
- 预期结果：未命名条目追加尾部（现状行为）、激活走既有规则
- 优先级：P1

### TC-010: 旧会话格式兼容
- 前置条件：会话文件为旧格式（未命名条目无 uid 键或不存在）
- 操作步骤：恢复
- 预期结果：行为与现状一致，无崩溃无错误弹窗
- 优先级：P1

### TC-011: 端到端现场还原（真实进程）
- 前置条件：便携标记法钉目录；e2e 驱动
- 操作步骤：建 [文件A, 未命名1(输入内容), 文件B]、活动=未命名1 → 热退出 → 重启
- 预期结果：标签顺序 [A, 未命名1, B] 且活动 = 未命名1（可经会话/草稿文件与驱动断言）
- 优先级：P0

### TC-012: 纯文件标签回归
- 前置条件：全量既有测试
- 操作步骤：ctest 全量
- 预期结果：10/10 无回归（会话恢复既有断言不破坏）
- 优先级：P0
