## 三、端到端测试（TC-010/011/012）执行方式与证据

### 驱动方式说明

- **写入侧**（真实进程无法合成键盘输入——offscreen 平台无原生窗口句柄，键盘/鼠标事件无路径注入）：由新增驱动 harness `build\e2e_draft_driver.exe`（源码 tests/test_window/e2e_draft_driver.cpp）完成，它加载**真实 Main.qml** 并经**真实 QML 输入链路**等价驱动：
  1. `QMetaObject` 调 Main.qml `doNewDocument()`（新建标签页的 QML 动作入口）；
  2. 定位活动编辑器 TextArea 调 `append()`——与用户在文末键入等价：TextArea.text 变化 → EditorArea `onTextChanged` → `doc.content` 回写 → `Document::contentChanged` → DraftCacheManager **真实 1000ms 防抖**挂起（harness 同时断言回写后 `doc.content` 与键入内容一致，链路打通才继续）。
- **终止侧**：TC-011/012 由编排脚本 `Stop-Process -Force` 真实强杀（退出码 -1 佐证非自然退出）；TC-010 经 QML `doQuit()` → `close()` → `onClosing` 放行 → `app.exec()` 自然返回（与 Ctrl+Q/X/Alt+F4 同一 QML 退出链路；offscreen 无 HWND，`taskkill` WM_CLOSE 不可用）。
- **恢复侧**：真实 `build\qcnote.exe`（offscreen + 便携标记）重启，黑盒文件级断言（与既有 verify-draftcache.ps1 同一断言链）：`restoreDrafts` **恢复即删旧条目** + 未命名重建为 modified 文档 → 1s 防抖后**按新 uid 续写唯一条目**且 content/name=未命名-1/url 空正确 → 证明"标签带内容恢复为未保存状态"；进程 4s 存活 + 无 QML 错误。
- **激活断言**：TC-011 另以 harness `restore` 模式直接读 DocumentManager 状态断言 `activeDocument` 指向恢复文档（DEC-002）。
- **失焦驱动**（TC-012）：`QGuiApplication` 的状态 setter 为私有 API，以 `QMetaObject::invokeMethod` 触发**真实 `applicationStateChanged` 信号**（→ DraftCacheManager 构造期连接的同一连接 → `onApplicationStateChanged(Inactive)` → `flushPending`），在键入后 200ms（防抖远未到期）触发。

### 执行结果（verify-hotexit-draft-e2e.ps1，28/28 通过）

**TC-010 热退出**（键入 `hotexit-e2e-热退出未命名内容`）：
- 驱动进程自然退出，退出码 0（doQuit→close→onClosing 放行→exec 返回），无 QML 错误；
- 落盘条目唯一 `uid=e6e95814-…`，字段 content/name=未命名-1/url 空全对（草稿保留未被清理）；
- 真实 qcnote.exe 重启 4s 存活、无 QML 错误；旧条目被恢复消费；按新 uid `f2237e9c-…` 续写唯一条目且字段正确 → **内容恢复为未保存状态**。

**TC-011 强杀**（用户原始场景，键入 `kill-e2e-强杀未命名内容`）：
- WROTE 标记证明真实输入链路打通；等 2 秒（防抖已落盘）后 `Stop-Process -Force` 强杀（退出码 -1 佐证）；
- 落盘条目唯一 `uid=7b68f40a-…` 字段全对；真实 qcnote.exe 重启恢复同上（新 uid `11818e1d-…` 续写）；
- 恢复激活直接断言（harness restore 模式，6 项全 PASS）：

```

[e2e] RESTORE-CHECK PASS exactly one restored document
```

**TC-012 失焦强杀**（键入 `blur-e2e-失焦未命名内容`）：
- 键入后 200ms 触发失焦信号（防抖 1000ms 未到期）；**失焦标记 → 强杀实测 47ms（< 1 秒）**；
- 该窗口内防抖不可能到期，**失焦 flush 是唯一落盘路径**——条目存在且字段正确（`uid=bcf7e281-…`）即失焦即写（DEC-003）在真实链路生效；
