# 测试用例：添加应用图标

## 测试范围

- 图标资产生成链（SVG → PNG → ICO）
- exe 图标嵌入（.rc / windres / CMake 集成）
- 运行时窗口图标（setWindowIcon + Qt6::Svg 资源加载）
- 构建与现有功能回归

## 用例列表

### TC-001: ICO 文件格式与尺寸完整性
- 前置条件：`src/icons/qcnote.ico` 已生成
- 操作步骤：解析 ICO 二进制头（ICONDIR + ICONDIRENTRY）
- 预期结果：含 16/24/32/48/64/256 六个条目；256 条目宽高字节为 0（表示 256）；PNG 数据合法
- 优先级：P0

### TC-002: exe 嵌入图标
- 前置条件：`build/` 完整构建通过
- 操作步骤：pwsh 执行 `[System.Drawing.Icon]::ExtractAssociatedIcon("build\qcnote.exe")`
- 预期结果：返回非空 Icon，宽高 > 0；导出 PNG 后为蓝底白字文档图案（非默认白板）
- 优先级：P0

### TC-003: 构建集成
- 前置条件：`src/qcnote.rc`、CMake 修改完成
- 操作步骤：`cmake -B build ...` + `cmake --build build`
- 预期结果：构建通过，无 windres 警告/错误；链接 Qt6::Svg 成功
- 优先级：P0

### TC-004: offscreen 冒烟运行
- 前置条件：TC-003 通过
- 操作步骤：`$env:QT_QPA_PLATFORM="offscreen"` 启动 `build\qcnote.exe`，确认进程存在后结束
- 预期结果：进程正常启动、4 秒内不崩溃（冒烟仅验证启动不崩溃；QIcon 加载失败不会导致崩溃，setWindowIcon 资源路径正确性由 TC-008 验证）
- 优先级：P0

### TC-005: 现有测试回归
- 前置条件：TC-003 通过
- 操作步骤：`ctest --test-dir build --output-on-failure`
- 预期结果：现有全部测试通过，无回归
- 优先级：P0

### TC-006: 生成链可重现
- 前置条件：icongen 工具 + make-ico.ps1 就绪
- 操作步骤：独立目录构建 icongen，对 `qcnote.svg` 重新生成 ICO
- 预期结果：重新生成得到结构与 TC-001 一致的 ICO（六档尺寸）
- 优先级：P1

### TC-007: 图标视觉验收
- 前置条件：ICO 已生成
- 操作步骤：向用户展示 256px PNG 预览
- 预期结果：用户确认设计满意（蓝底圆角方板 + 白色文档字形，浅/深任务栏均可辨）
- 优先级：P1

### TC-008: setWindowIcon 资源嵌入回归（双断言）
- 前置条件：`build/` 完整构建通过（与 TC-002 一致，可经 `-SkipExe` 跳过）
- 操作步骤：读取 `build\qcnote.exe` 全部字节，执行两条断言——
  - 断言 A（UTF-16 LE 完整路径）：搜索 `qt/qml/qcnote/icons/qcnote.svg` 的 UTF-16 LE 字节序列
  - 断言 B（UTF-16 BE rcc 资源树段名）：搜索 `qcnote.svg` 的 UTF-16 BE 字节序列，并校验命中前 6 字节的前 2 字节为 `00 0A`（段名字符数/UTF-16 码元数的大端前缀，非字节数；Qt rcc 的 qt_resourceName 条目 = 2 字节大端长度 + 4 字节哈希 + UTF-16 BE 单段名，资源树不存完整路径）；辅助段名 `icons`（前缀 `00 05`）命中时计入 PASS 明细
- 预期结果：两条断言全部命中 TC-008 才 PASS。断言 A 验证 main.cpp `setWindowIcon` 引用路径已编译进 exe（LE 完整路径只来自 main.cpp 字面量池，检出"路径写错"）；断言 B 验证 SVG 真实经 qt_add_qml_module RESOURCES 嵌入 rcc 资源树（检出"资源漏配"——漏配时字面量仍在，断言 A 单独会误 PASS）；QIcon 加载失败不崩溃不报错，冒烟（TC-004）无法发现这两类问题
- 优先级：P0

offscreen 冒烟：


## 图标回归脚本使用说明

`tests/icons/verify-icon.ps1`（需 pwsh 7+，脚本头部有 `#Requires -Version 7`）：

```powershell
# 默认：TC-001/002/008（ICO 校验 + exe 嵌入/资源断言）
pwsh.exe -NoProfile -File tests\icons\verify-icon.ps1
# 附加 offscreen 冒烟（TC-004）与生成链重现（TC-006）
pwsh.exe -NoProfile -File tests\icons\verify-icon.ps1 -WithSmoke -WithRegen
```

注：`-WithRegen` 依赖 icongen 工具；过程构建目录 `build-icongen/` 按构建目录约定清理后，需先重建再使用：

```powershell
$env:PATH = "D:\Program\Qt\Tools\CMake_64\bin;D:\Program\Qt\Tools\Ninja;" + $env:PATH
cmake -B build-icongen -S tools/icongen -G Ninja -DCMAKE_PREFIX_PATH=D:/Program/Qt/6.11.2/mingw_64 -DCMAKE_C_COMPILER=D:/Program/Qt/Tools/mingw1310_64/bin/gcc.exe -DCMAKE_CXX_COMPILER=D:/Program/Qt/Tools/mingw1310_64/bin/g++.exe
cmake --build build-icongen
```
