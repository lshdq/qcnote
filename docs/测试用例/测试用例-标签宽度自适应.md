# 测试用例：标签宽度自适应

## 测试范围

`src/qml/DocumentTabs.qml` 的 Tab 宽度自适应分配（最小 100、动态上限 W/4、
等比例收缩、饱和转滚动）；验证既有行为（省略/tooltip/滚动/键盘/无障碍）无回归。

## 用例列表

### TC-001: 单 Tab 短文件名取自然宽度
- 前置条件：应用启动，打开一个短名文档（如 `笔记.txt`）
- 操作步骤：观察该 Tab 宽度
- 预期结果：Tab 宽度 = 文字宽度 + 装饰宽度（● 标记按未保存状态出现），
  文字完整显示、无省略号、无多余空白，宽度明显小于旧固定 168px
- 优先级：P0

### TC-002: 超长文件名受 1/4 上限约束
- 前置条件：仅打开一个超长文件名文档（自然宽度远超 Tab 区宽度 1/4）
- 操作步骤：观察该 Tab 宽度与文字显示
- 预期结果：Tab 宽度 = floor(Tab 区可用宽度 / 4)（但不小于 100），
  文字省略显示，悬停 tooltip 显示完整文件名
- 优先级：P0

### TC-003: 多 Tab 空间充足各自独立适配
- 前置条件：打开 3 个以上文档，文件名长短差异明显，总自然宽度未超出 Tab 区
- 操作步骤：观察各 Tab 宽度
- 预期结果：各 Tab 宽度各自等于其自然宽度（短名 Tab 窄、长名 Tab 宽），
  所有文字完整显示，无省略号、无滚动条
- 优先级：P0

### TC-004: 空间不足等比例收缩
- 前置条件：打开多个文档使总自然宽度超出 Tab 区可用宽度，但收缩后可放下
- 操作步骤：观察各 Tab 宽度
- 预期结果：各 Tab 按（自然宽度 − 100）等比例收缩：长名 Tab 收缩量大、
  短名 Tab 收缩量小；所有 Tab 宽度 ≥ 100px；总宽度贴合可用空间，无滚动条
- 优先级：P0

### TC-005: 收缩饱和转横向滚动
- 前置条件：打开足够多文档，使全部 Tab 取 100px 后总宽度仍超出 Tab 区
- 操作步骤：观察 Tab 区
- 预期结果：各 Tab 均为 100px（不再更小），出现横向滚动条，可滚动查看
  全部 Tab；窗口控制按钮不被挤压
- 优先级：P0

### TC-006: 窗口连续缩放宽度实时重算
- 前置条件：打开多个文档，处于"空间不足收缩"状态
- 操作步骤：连续拖拽缩放窗口宽度（变宽再变窄，往返多次）
- 预期结果：Tab 宽度实时跟随重算（变宽逐步回展、变窄逐步收缩）；
  无肉眼可见抖动，无滚动条反复闪烁；跨越饱和边界时滚动条正确出现/消失
- 优先级：P1

### TC-007: 未保存标记影响自然宽度
- 前置条件：打开一个短名文档且空间充足，Tab 为自然宽度
- 操作步骤：编辑内容（● 标记出现）→ 撤销编辑至已保存状态（● 标记消失）
- 预期结果：标记出现时 Tab 自然宽度相应增加，消失时相应减小；
  空间充足状态下文字始终完整显示
- 优先级：P1

### TC-008: 另存为重命名后宽度跟随
- 前置条件：打开短名文档，Tab 为自然宽度
- 操作步骤：另存为明显更长/更短的文件名
- 预期结果：Tab 宽度立即按新文件名重算；tooltip 名称同步更新
- 优先级：P1

### TC-009: 极窄窗口上限退化不异常
- 前置条件：打开 2 个以上文档
- 操作步骤：将窗口宽度拖到很小（Tab 区宽度 < 400px，W/4 < 100）
- 预期结果：上限退化为 100px，行为与收缩饱和一致（全部 100px + 滚动），
  无宽度为负/零的 Tab、无绑定错误、无布局异常
- 优先级：P1

### TC-010: 既有交互无回归（键盘/关闭/激活）
- 前置条件：打开多个文档（含收缩与饱和两种状态）
- 操作步骤：左右方向键移动焦点、Enter/Space 激活、点击各 Tab 激活、
  点击各 Tab 关闭按钮
- 预期结果：键盘循环移动焦点且可见（positionViewAtIndex 生效）、激活/关闭
  行为与改动前一致
- 优先级：P1

### TC-011: 现有单元测试无回归
- 前置条件：项目已构建
- 操作步骤：`ctest --test-dir build --output-on-failure`
- 预期结果：全部既有测试通过
- 优先级：P0

### TC-012: offscreen 冒烟无 QML 错误
- 前置条件：项目已构建
- 操作步骤：`QT_QPA_PLATFORM=offscreen` 启动 qcnote.exe，检查 QML/控制台
  错误输出，随后结束进程
- 预期结果：无 QML 错误、无绑定循环（binding loop）警告；进程正常结束
- 优先级：P0

### TC-013: qmllint 改动行无警告
- 前置条件：无
- 操作步骤：对 `src/qml/DocumentTabs.qml` 运行 qmllint
- 预期结果：改动行无新增警告
- 优先级：P2

## 测试场景分类

- 业务代码（Qt Quick QML 界面组件）；TC-001~TC-010 依赖视觉核对窗口宽度与
  省略表现，offscreen 平台无法自动断言像素宽度，属人工验证项（由测试子智能体
  审查代码逻辑正确性 + 人工目视复核）；TC-011~TC-013 可自动化。
