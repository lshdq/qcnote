# 测试用例：标题栏按钮图标居中

## 测试范围

- `src/qml/CaptionButton.qml` minimize 图标绘制坐标（y=8.5 → y=5）。
- 回归：构建、既有 33 项 C++ 单元测试、offscreen 启动冒烟；确认本次改动未影响其他 glyph 与交互。

## 用例列表

### TC-001: minimize 图标坐标静态检查
- 前置条件：开发改动已写入 `src/qml/CaptionButton.qml`。
- 操作步骤：检查 `onPaint` 中 `case "minimize"` 分支的路径坐标。
- 预期结果：横线为 `moveTo(0, 5)` / `lineTo(10, 5)`（画布 10×10 的垂直中心）；`maximize` / `restore` / `close` / `menu` 分支坐标未被改动。
- 优先级：P0

### TC-002: 构建回归
- 前置条件：工作区已含本次改动。
- 操作步骤：`cmake --build build`。
- 预期结果：构建成功，无新增错误/警告。
- 优先级：P0

### TC-003: 单元测试全量回归
- 前置条件：构建成功。
- 操作步骤：`ctest --test-dir build --output-on-failure`。
- 预期结果：ctest 全量条目通过（1/1：test_core），其内部 QtTest 函数全部通过（退出码 0）。
- 优先级：P0

### TC-004: offscreen 冒烟运行
- 前置条件：`build/qcnote.exe` 存在。
- 操作步骤：`QT_QPA_PLATFORM=offscreen` 启动 exe，观察 4 秒后按 PID 结束进程。
- 预期结果：进程存活 ≥ 4s（启动不崩溃），全程无可见窗口。
- 优先级：P1

### TC-005: 视觉验收（人工）
- 前置条件：构建成功。
- 操作步骤：用户肉眼查看标题栏右侧三个窗口控制按钮。
- 预期结果：最小化横线位于按钮垂直中心，与最大化/还原、关闭图标中心对齐。
- 优先级：P1（不在自动化范围，留待用户确认）

## 测试命令

```powershell
# 构建（项目根目录）
$env:PATH = "D:\Program\Qt\Tools\CMake_64\bin;D:\Program\Qt\Tools\Ninja;" + $env:PATH
cmake --build build

# 单元测试
ctest --test-dir build --output-on-failure

# offscreen 冒烟（禁止可见窗口；结束后按 PID 结束进程）
$env:PATH = "D:\Program\Qt\6.11.2\mingw_64\bin;D:\Program\Qt\Tools\mingw1310_64\bin;" + $env:PATH
$env:QT_QPA_PLATFORM = "offscreen"
Start-Process -FilePath "E:\works\qcnote\build\qcnote.exe"
Get-Process qcnote | Stop-Process -Force
```
