## 消息级边界专项核对（本轮重点）

1. **按下后窗口存活且捕获生效**：TC-002 以 `GetGUIThreadInfo` 跨进程观测到 `hwndCapture == 主窗口`，直接证明 `SetCapture` 在按下处理内执行成功；旧「down 即执行」实现在此阶段已销毁窗口，无法通过该断言。
2. **同按钮松开才发起关闭**：TC-003 仅在按下→同按钮松开后观察到正常退出链（草稿/会话落盘 → ExitCode=0）。
3. **拖离取消后捕获释放、后续点击无阻塞**：TC-004 观测 capture=0x0（ReleaseCapture 收口）；TC-004b 证明会话复位后完整点击仍可关闭。
4. **菜单按钮 down 触发回归**：TC-005 全绿，`HTBORDER` 维持 down 触发，`TrackPopupMenu` 模态循环路径未受影响。
