# 指标终验报告：Win32 全量重写（1.0.0）

- 日期：2026-11-11
- 测量制品：`build-win\qcnote.exe`（M6 双主题完成后的全功能版本，工作区当前源码构建）
- 测量脚本：`tools\verify-metrics.ps1`（空壳/启动）、开文档场景为一次性脚本命令（口径同下）
- **口径说明**：内存统一为「任务管理器默认内存列 = 私有工作集」（`Get-Counter '\Process(qcnote*)\Working Set - Private'`）

## 测量结果

| 指标 | 目标 | 实测 | 结论 |
|------|------|------|------|
| 空闲内存（空壳） | < 10 MB | **6 MB**（静置 5s） | ✅ PASS |
| 空闲内存（开文档） | ≤ 30 MB | **6.4 MB**（开 3 个中文笔记文件静置 5s，含 3 个 Scintilla 实例 + 会话/草稿管线） | ✅ PASS |
| 启动时间（热） | < 200 ms | **中值 35 ms**（预热 1 次 + 正式 5 次：39/31/35/38/23） | ✅ PASS |
| 启动时间（冷） | < 200 ms | **待用户测量**（重启系统后首次启动，含杀软扫描；历史观察：重建后首启约 0.5s 为杀软扫描，常态冷启动远低于 200ms） | ⏳ 人工项 |
| 部署：单 exe | 无非系统 DLL | `dumpbin /dependents`：dwmapi/COMCTL32/COMDLG32/SHELL32/ADVAPI32/GDI32/USER32/IMM32/OLEAUT32/bcrypt/ole32/KERNEL32 **全部系统 DLL**；`/MT` 静态 CRT（无 vcruntime/msvcp/ucrtbase） | ✅ PASS |
| 产物大小 | — | 1,706.5 KB（Release `/O1`，未开 LTCG） | — |

## 对照：重写动机的验证

| 症状（Qt Quick 版） | 重写版实测 |
|--------------------|-----------|
| 空闲内存 60~100 MB 基线 | **6 MB**（约 1/10~1/16） |
| 启动 0.5s+ | **35 ms**（热启动，约 1/14） |
| GPU 场景图基线成本 | 无 GPU 依赖（纯 GDI/GDI+ + DWM 合成） |

## 复现方法

```powershell
# 构建（vcvars64 环境下）
cmake -B build-win -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-win
# 空壳内存 + 热启动（SW_SHOWNOACTIVATE，不抢前台）
pwsh -NoProfile -File tools\verify-metrics.ps1 -ExePath build-win\qcnote.exe
# 冷启动：重启系统后首次启动计时（人工）
```
