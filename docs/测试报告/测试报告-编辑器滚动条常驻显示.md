- ctest 总数：9 套（全部 QtTest 可执行）| 通过：9 | 失败：0 | 跳过：0
- 补充编写：2 条（`tests/test_editor/tst_editorintegration.cpp`）
  - `tcSB001_002_verticalPolicy_dynamic`：超高内容竖向滚动条 size<1.0 → policy=AlwaysOn、visible、interactive、可滚动（contentY 变更生效后 policy 仍常驻）；短内容 size≥1.0 → policy=AlwaysOff、不可见
  - `tcSB003_004_horizontalPolicy_wrapToggle`：NoWrap 超长行横向 AlwaysOn/可见/可拖拽；开启换行后横向 AlwaysOff/不可见；切回 NoWrap 恢复 AlwaysOn（双向动态切换回归）
- 实现说明：ScrollView 子树中存在实例化早期的 size==0 占位 ScrollBar（policy 默认 AsNeeded），测试按"size > 0 的活动实例"筛选断言目标（已在测试代码注释中说明）
