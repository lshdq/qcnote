## 决策列表

### DEC-001: 拖拽把手采用自定义 header 标题栏
- 阶段：方案设计（阶段 2）
- 背景：QML Dialog 的标题由框架内部渲染在内容列内，QML 侧无法访问内部标题项挂接手势；弹窗需要可发现的抓取区。
- 可选方案：① 自定义 `header:` 作为标题栏把手（标题文本移入 header）；② 在 `background:` 上挂 DragHandler 允许非交互区整体拖拽；③ 在内容区顶部叠加透明拖条。
- 最终选择：方案 ①。
- 选择理由：符合 Windows"标题栏拖动对话框"惯例，抓取区可发现；不与正文选择/按钮点击冲突；方案 ② 非惯例且易与内容交互争抢事件，方案 ③ 叠加层脆弱。
- 影响：`Dialog.title` 置空避免双标题，测试定位方式需同步适配；标题视觉需对齐现有 Material 样式。

### DEC-002: 以 MovableDialog 组件统一封装
- 阶段：方案设计（阶段 2）
- 背景：五个弹窗需要一致的拖动/边界/复位逻辑。
- 可选方案：① 新增 `MovableDialog.qml`（继承 Dialog）统一实现，各弹窗换根类型接入；② 每个弹窗散装实现；③ 仅提供附加拖条组件由各弹窗自行接线。
- 最终选择：方案 ①。
- 选择理由：单一改动点、行为一致、测试可按类型定位；散装实现重复且易漂移，纯附加组件无法覆盖复位/约束生命周期。
- 影响：Main.qml 四个对话框与 SearchDialog.qml 根类型替换为 MovableDialog；CMake 注册新 QML 文件。

### DEC-003: 位置采用"绑定默认 + 拖动后字面值"结构
- 阶段：方案设计（阶段 2）
- 背景：用户已选"每次打开复位默认位置"；同时既有测试要求未拖动时弹窗随窗口 resize 跟随居中。
- 可选方案：① 未拖动时 x/y 保持绑定（默认位置随 resize 重算），首次拖动切换为字面存储值；② 打开时一次性写入 x/y 字面值，resize 仅做 clamp。
- 最终选择：方案 ①。
- 选择理由：完整保留既有"resize 跟随"语义（tst_dialogstyle 原 TC 语义存活），拖动后行为符合用户"当次生效"的决策；方案 ② 会丢失未拖动态的跟随行为。
- 影响：实现引入 `userMoved` 状态，重开（aboutToShow）复位；resize 时仅对已拖动弹窗施加 clamp。

### DEC-005: 拖动 X 下界对齐框架约束（0 而非 -(width-keepWidth)）
- 阶段：执行开发（阶段 5）
- 背景：开发子智能体实测并核对 Qt 6.11 源码，`QQuickPopupPositioner` 对 Item 型 Popup 强制 effective x/y ≥ 0，负 x 请求恒被框架钳回 0，原批准公式的左向越出不可达；若仍存储负值会与框架实际位置脱节，产生反向拖动死区。
- 可选方案：① clamp 下界取 0 与框架对齐（左/上方向把手完整保留窗口内）；② 存储负值模拟左向越出（与框架行为脱节、不可靠）；③ 改用 Window 型 Popup（独立 OS 窗口）实现完全自由移动。
- 最终选择：方案 ①。
- 选择理由："把手不丢失"不变式仍满足且左/上方向更强；方案 ② 行为不可靠；方案 ③ 引入独立系统窗口、破坏模态遮罩语义，超出需求边界。
- 影响：右/下方向弹窗身体仍可部分越出窗口；测试用例 TC-003 不等式 `x ≥ -(width-keepWidth)` 在 0 下界下依然成立（0 ≥ 负值，约束更强），测试用例文档无需变更。

### DEC-006: 审查可选项不采纳为代码修复
- 阶段：代码审查（阶段 7）
- 背景：审查结论 0 阻塞 / 0 应改 / 3 可选：① clampX/clampY 上界 `hi<0` 时返回负值的防御（最小窗口 800×500 下物理不可达）；② Dialog.title 置空后读屏可访问名核验；③ AppTheme.textPrimary 与 Material 默认标题色的极微视觉差异。②③本质依赖真实窗口人工核验（TC-011 范畴）。
- 可选方案：① 对可选#1 补 `Math.max(0, hi)` 防御并按阶段 7 规则走"修复→基本验证→独立测试→独立审查"完整循环；② 不改代码，#1 记录为复用防御提示，#2/#3 并入 TC-011 核验点。
- 最终选择：方案 ②。
- 选择理由：#1 当前不可达且审查定级可选，一行防御的收益低于完整验证循环的成本；#2/#3 本就需要真实窗口人工执行。
- 影响：无行为变化；若未来放宽窗口最小尺寸或把 MovableDialog 复用到更小窗口场景，须先补 clamp 上界防御（见审查报告可选项 1）。
