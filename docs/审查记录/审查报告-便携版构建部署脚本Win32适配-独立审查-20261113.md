## 4. 其他发现（经复核成立，按严重度排序）

无阻塞项、无应改项。可选项 3 条：

1. **[可选] 健壮性: build-portable.ps1 cmake 未显式指定源目录，行为依赖当前工作目录** — build-portable.ps1:61,65（`cmake -B $BuildDir` 无 `-S`）— CMake 在无 source 参数时以 CWD 为源目录；从项目根之外运行时，若 CWD 无 CMakeLists.txt 则配置失败（exit 1，路径正确），若 CWD 恰为其他 CMake 项目则误配置该项目（最终因 `build-win\qcnote.exe` 缺失 Fail，不会发布错误产物，但浪费一次完整构建并污染 build-win，下次运行自愈）— 触发条件：`pwsh -File <绝对路径>\tools\build-portable.ps1` 且 CWD 非 `%TEMP%` 等无关目录 — 影响：失败路径收敛但报错不直观 — 建议：改为 `cmake -S $Root -B $BuildDir ...`（一行，消除 CWD 依赖；不修复仅损失跨目录可用性，不影响正确性与发布安全）。
2. **[可选] 磁盘占用: dist 历史版本便携目录与 zip 永不清理** — build-portable.ps1:75（仅清理同版本 `$PortableDir`）— 每个历史版本留下目录+zip（当前约 0.82MB×2/版本）随版本线性累积，无正确性影响（deploy 按 LastWriteTime 自动选最新）— 建议：可在摘要中提示历史产物数量，或提供可选 `-CleanOld` 开关；不修复仅磁盘缓慢增长。
3. **[可选] 文档同步: 新 selftest 未登记到项目指令的测试命令清单** — tests/verify-portable-deploy-selftest.ps1 存在且持久化，但 `.opencode/AGENTS.md` 的 selftest/e2e 命令列表未含它 — 影响：后续任务/子智能体按项目指令发现测试时遗漏该脚本，降低回归可达性 — 建议：项目指令维护者在下次更新 AGENTS.md 时补一行命令；不修复不影响本次需求。

撤销的候选问题（复核后不成立，记录理由）：

- 「finally 中 `Kill()` 竞态抛异常中断清理」— pwsh 7/.NET 实测 Kill 已退出进程不抛异常，不成立。
- 「vcvars 导入未检查 cmd /c 退出码」— 后续 `Get-Command cl.exe/cmake/ninja` 自检兜底（:41-45），导入失败必然被捕获 Fail，不成立。
- 「deploy 进程对象未 Dispose 依赖 GC」— 每次运行仅少量对象、随脚本退出释放，无累积场景，不构成真实资源风险（且为原样恢复的历史代码，pre-existing）。
