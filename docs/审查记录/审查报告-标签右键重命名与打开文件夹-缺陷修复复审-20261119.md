## 3. 依赖、兼容性与优化机会

- **make_preferred 语义边界**（重点核查项 2）：`preferredPath`(documentmanager.cpp:16-19)
  仅替换目录分隔符——根路径 `D:\` / `D:/`、UNC `\\server\share`、相对路径（保持相对）、
  空路径（保持空，三入口 empty 检查在归一后仍有效）、混合分隔符形态均为纯分隔符转换，
  无 lexically_normal 的 `.`/`..` 圆整副作用（与 DEC-005「语义最小」声明一致）。
  Windows 文件名不允许 `/`/`\` 字面量，无「分隔符歧义」输入。✓
- **与既有形态敏感/不敏感比较的交互**：
  - `documentForPath`(378-387) 用 `lexically_normal()` 比较，MSVC 上输出 preferred
    分隔符且 `operator==` 按词法元素形态不敏感（`C:/a`==`C:\a`）——归一前后查重
    结果一致，归一额外保证 url 落内存形态统一；rename 注释「lexically_normal 本身
    归一分隔符」(249) 与标准行为相符。✓
  - `storageForUrl`→`LocalStorage::supports`→`parseFileUrl`（storage.cpp:5-13）：纯
    路径（无 `://`）原样认领，归一后形态照常认领；归一顺带把 `D://x` 这类畸形形态
    （`find(L"://")` 会误拒）转为可认领的 `D:\x`——改善而非破坏。✓
  - `formatForPath`(401-411) 基于 `path.filename()`，与分隔符形态无关；当前无生产
    调用方（未来格式扩展入口）。✓
- **saveAs 遮蔽重载（DEC-008）与归一交互**（重点核查项 3）：`shadowed` 经
  `documentForPath(path)`(223) 以归一形态定位，`applyLoadedState(path,…)`(240) 使
  被遮蔽文档 url 重置为归一形态——修复后所有文档 url 恒反斜杠，该路径从「可能
  正斜杠」收敛为「必然反斜杠」，遮蔽重载语义不变。✓
- **DraftCacheManager 形态敏感去重键**（draftcachemanager.cpp:256-258 逐字符
  wstring 比较）：所有 entry.url 同源于 `urlValueToPath`（恒正斜杠），无混合形态
  输入，不构成风险；会话/草稿写侧 `pathToUrlValue` 未动，ini 字节级兼容保持。✓
- **重复调用/缓存/异步化**：`preferredPath` 为单次 path 拷贝 + 原地转换，仅在
  用户级操作入口调用一次，无热路径。无适用优化。✓
- **第三方依赖**：本轮零新增（CommDlgExtendedError 为 comdlg32 既有依赖范围）。✓

## 5. 复核声明（防误报）

- 所有问题均核实为活动代码（非注释块）；`preferredPath` 三调用点、
  `CommDlgExtendedError` 分支、两处新增 TEST_CASE 均直接读取当前源码确认。
- 归一完备性结论基于全仓库 `setUrl|applyLoadedState` grep（document.cpp:49/151 定义
  之外仅 documentmanager.cpp 5 处调用）与 `openPath|saveAs(|rename(` 调用点检索
  （main.cpp 8 处全部经三入口），非仅凭 diff 推断。
- `CommDlgExtendedError` 调用时机核实：位于 `GetSaveFileNameW` 返回 FALSE 分支内，
  中间仅 `g_fileDialogOpen=false` 与 `FocusActiveEditor()`（main.cpp:491-497，纯
  SetFocus，无 comdlg32 调用），错误码状态未被扰动；MSDN 契约用户取消时返回 0。
- `initialPath` 为 const 局部 wstring，生命周期覆盖 `wcsncpy_s` 与错误框使用；
  失败路径不依赖 buffer 内容。
- `path::operator==` 形态不敏感结论以 MSVC STL 实际行为 + 新增测试真实运行
  （ctest 8/8 × 4 轮）双重实证，非纯标准推断。
- make_preferred 对空/根/UNC/相对路径行为按 [fs.path.generic]/[fs.path.preferred]
  语义逐项推演，无虚构 API 行为。
