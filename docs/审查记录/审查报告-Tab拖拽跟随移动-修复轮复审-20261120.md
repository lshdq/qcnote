### 增量 2：tests/test_tabs.cpp 新增 n=1 用例（可选-2 修复）— 通过

用例「TabStrip 拖拽：单 Tab（n=1）条内跟随、越界钳制、松手不回调」（test_tabs.cpp:633-687）+ `#include <algorithm>`（:13，供 `std::min`/`std::max`）。断言与实现逐条核验：

| 断言 | 实现语义核验 | 结论 |
| --- | --- | --- |
| `maxDx = (area.right − w) − slot.left`（:657-658） | `dragMove`：`followLeft = x − dragGrabX_`（grabX = press.x − slot.left = w/2），clamp `[area.left, area.right − w]`；条内小幅越阈值时 `followDx = x − press.x = dragThresh + 2`，被 `maxDx` 封顶 → `min(dragThresh + 2, maxDx)` 精确等价 | ✓ |
| 大幅拉出条外（`area.right + 500`）后 `offsets[0] == maxDx` 且 `bounds.right + offset ≤ area.right`（:669-673） | clamp 上界 `maxLeft = area.right − w` → `followDx = maxLeft − slot.left = maxDx`；视觉右缘恰触条区右缘不越界 | ✓ |
| `dragInsertIndex() == 0`（全程，:660/:671） | `TabDragInsertIndex`：n=1 时循环唯一项 `i == idx` 被 continue → insert=0=from（无邻居） | ✓ |
| items/active/focus 全程零改动（:662-665/:674-676/:684-686） | 视觉偏移式不变式（首轮 R6 已证全路径） | ✓ |
| 松手 `cbCount == 0`、收口复位（`dragInsertIndex() == -1`、offsets 全 0）（:679-683） | `onLButtonUp`：to=0==from 不回调；`clearDragState` 复位全部拖拽量 | ✓ |
| 退化前提 | 单 Tab 布局 `w ≤ area` 宽（宽度自适应 cap 与饱和滚动保证），`maxDx ≥ 0`，不触发「条比 Tab 窄」退化分支 | ✓ |
