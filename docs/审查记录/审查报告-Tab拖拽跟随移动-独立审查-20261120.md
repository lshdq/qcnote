## 三、Java 公共模块主业务影响

不适用（非 Java 技术栈）。对应桌面侧第 3 步专项结论：

- 第三方依赖不可用影响：纯本地单 exe，无数据库/Redis/MQ/网络服务；无外部故障传导路径。
- 资源：GDI 对象（brush/pen）创建-选入-恢复-删除三连成对（paint 全路径核查）；SaveDC/RestoreDC 一对一且中间无提前 return；计时器 SetTimer/KillTimer 全收口路径配对（专项②）。
- CPU/长期运行：动画有界（每次跨线 ~8 帧 @10ms 请求节拍，收敛即停，无空转：dragMove 仅 pending 时起表）；拖拽每 move 一次 O(n) 几何 + tabArea 局部重绘，n 为 Tab 数（文本编辑器量级），无放大路径。
- 数据一致性：单 UI 线程消息序列化，无并发共享；提交一次原子回调，无部分成功窗口。
- 兼容性：无新增第三方依赖；TabStrip 公共接口纯新增（dragInsertIndex()/dragVisualOffsets()/kDragAnimTimerId/三纯函数），既有接口签名与语义零改动，`TabDragSwapIndex` 保留供原单测。

- 依赖冲突：无（需求明示无新增依赖，diff 核实仅改动既有 6 文件）。

## 五、其他发现（复核成立，按严重度降序）

**[可选-1] 检查项: 注释与实现模型漂移（「回滚视觉序」残留）** — 证据：tabs.h:244 `onCaptureChanged()` 注释「取消拖拽（回滚视觉序，不回调）」、tabs.cpp:730 `onWindowKillFocus` 注释「失焦取消：回滚视觉序，不回调」、main.cpp:4088-4089 WM_CAPTURECHANGED 注释「取消拖拽（DEC-002：回滚视觉序不回调…）」— 根因：本次改为视觉偏移式（DEC-001）后取消路径已无回滚（数据从未变动），三处旧注释未随模型更新 — 触发条件/放大路径：无（纯注释）— 影响：误导后续维护者以为取消路径存在数据回滚逻辑 — 建议：改为「清状态+停表+重绘回原位（数据从未变动）」，与 tabs.cpp:943-944 头注释口径统一。

**[可选-2] 检查项: 单 Tab（n=1）拖拽缺组件级证明性测试** — 证据：需求文档边界条目「单 Tab 拖拽：无邻居，Tab 在条内跟随光标，松手 from==to 不回调」；tests/test_tabs.cpp 矩阵最近邻为空几何与 2 Tab，无 n=1 输入（TC-001/002/组件用例均 ≥2 Tab 或空）— 根因：测试矩阵遗漏需求明示边界 — 触发条件/放大路径：未来改动邻居循环边界/让位量推导时，n=1 回归无测试拦截 — 影响：纯函数层面 n=1 行为经代码审查确认正确（唯一项 continue → insert=0=from；offsets 邻居循环为空；up 不回调），但按「行为变更附带会在回归时失败的测试」基线属缺口 — 建议：补 1 条 n=1 组件用例（addTab 单项 → down → 越阈值 move → 断言 dragging/dragVisualOffsets()[0]==dx/dragInsertIndex()==0 → up 断言无回调且收口复位）。

**[可选-3] 检查项: 拖拽态焦点环与抓起描边理论双框** — 证据：tabs.cpp:1212-1226 焦点环先画、1232-1250 被拖 Tab 置顶重画（含描边）；当 focusVisible_ && focusIndex_==dragFromIndex_ 时同一 Tab 先后画两个 accent 框 — 根因：置顶画序将拖拽描边叠于焦点环之上 — 触发条件/放大路径：真实鼠标路径 onLButtonDown:621 已清 focusVisible_，**仅合成驱动可构造**（单测 headless 键盘导航后注入拖拽）— 影响：仅理论视觉重叠（部分被置顶背景覆盖），无正确性/资源影响 — 建议：dragVis 时跳过被拖项焦点环（一行防御），或维持现状记录为已知合成路径防御性行为。

## 六、审查关注点专项核查（输入指定 8 项）

1. **拖拽状态机时序**：up 路径 clearDragState（停表）→ ReleaseCapture（此时 dragging_ 已 false，同步分发的 WM_CAPTURECHANGED 经 onCaptureChanged no-op，无重入）；Esc/捕获丢失/失焦统一 cancelDrag（捕获已丢失时 GetCapture()!=hwnd_ 跳过释放，防误伤）；回调内 setItems 到达时状态已复位（onLButtonUp:646 注释明示且顺序正确）。**一致、重入安全**。
2. **动画计时器生命周期**：起表仅 beginDrag 一次 + dragMove pending 时（无空转）；停表三路径（onTimer 收敛 / !dragging_ 陈旧节拍防御 / clearDragState 全收口）；dragAnimArmed_ 与 SetTimer/KillTimer 严格配对（arm 仅 hwnd_&&!armed，kill 恒清标志）；headless 无 hwnd 时起表跳过但 onTimer 节拍逻辑可被合成直驱（单测证实）。**无泄漏**。
3. **纯函数边界**：空几何（insert→0/offsets→空）、越界（钳制 [0,n−1]）、变宽（shift 从被拖槽位宽推导）、滚动偏移（bounds 含滚动、压缩推导随动）、ApproachPx 单调不越目标（整数 δ 下 round(δ·r)≤|δ|）与终止性（|Δ|≤1 精确落位 + 步进退化 ≥1px）。全部有矩阵测试且数学核实。**正确**。
4. **paint 平移路径**：SaveDC/RestoreDC 一对一；oldFont 选入/恢复配对，drawContent 内 markFont 切换后回 labelFont_；brush/pen 全部删除；非被拖先画、被拖置顶（背景+内容+描边）；裁剪 tabArea 保留（拖拽 Tab 不遮菜单/窗口控制）；拖拽态 hover 已让位。**成对无泄漏**。
