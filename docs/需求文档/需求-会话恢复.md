# 需求：会话恢复

## 背景与目标

应用当前每次启动都显示欢迎页，用户上次编辑的文件需要手动重新打开。目标是启动时自动恢复上次退出时的会话状态：重新打开上次打开的文件列表、恢复各文档光标位置、恢复窗口几何（大小/位置/最大化状态），让用户回到上次离开时的工作现场。

## 功能描述

### 核心功能

1. **会话持久化**
   - 新增 C++ `SessionManager`（QML 单例），统一持有会话文件（QSettings，IniFormat，UserScope，组织名/应用名均为 `qcnote`，落盘于用户目录 `qcnote.ini`）。
   - 会话文件分两节：
     - `[documents]`：按编号键记录打开文件列表（URL、光标位置）与活动文档 URL；
     - `[window]`：窗口 normal 几何（x/y/width/height）与最大化标志。
   - 只记录有 URL 的文档；未命名文档（无路径）不记录。
2. **自动保存（防抖）**
   - 监听 `DocumentManager::documentsChanged` / `activeDocumentChanged`，以及各 `Document` 的 `urlChanged`、`cursorPositionChanged`，统一 500ms 防抖后写盘。
   - 恢复过程中置 `m_restoring` 标志屏蔽连锁写，恢复完成统一写一次。
   - 连接 `qGuiApp->aboutToQuit` 立即 flush，保证防抖挂起状态在退出前落盘。
3. **启动恢复**
   - `Main.qml` `Component.onCompleted` 依次：`SessionManager.restoreDocuments()` → 应用窗口几何 → `visible = true`（初始不可见，避免几何跳变闪屏）。
   - 文档恢复：本地文件先做存在性预检查，缺失的**静默跳过**（不触发 openFailed 错误弹窗）；存活文件按原顺序交给 `openUrls()`（Tab 顺序 = 上次顺序）；逐文档恢复钳制后的光标位置；按记录的 active URL 激活，active 丢失则激活最后一个成功打开的文档。
   - 空会话或全部文件丢失：不动作，维持现状（欢迎页）。
4. **光标位置支持**
   - `Document` 新增 `cursorPosition` 属性（int，值相等不发射信号）；`applyLoadedState()` 不动该属性。
   - `EditorArea.qml` delegate 创建时从 `doc.cursorPosition` 初始化光标并 `ensureCursorVisible()`；监听 `doc.cursorPositionChanged` 应用到 TextArea；`editor.onCursorPositionChanged` 写回 `doc.cursorPosition`（同值无信号，无回写环）。
5. **窗口几何恢复**
   - `SessionManager::windowState()` 返回校验后的几何（宽高钳到 `[800×500, 屏幕可用区]`，位置须与某块屏幕 `availableGeometry` 相交，否则返回空由 QML 使用默认值）。
   - `Main.qml` 仅在 `visibility === Windowed` 时记录 x/y/width/height（保证存 normal 几何），`visibilityChanged` 记录 maximized 标志，经 `saveWindowState()` 并入同一防抖写盘。
   - 恢复时先应用几何，再按 maximized 标志恢复最大化状态。

### 边界与约束

- **缺失文件**（被删除/移动/重命名）：启动时静默跳过，不弹错误框，不打断启动。
- **会话文件损坏**：URL 存在性校验 + 光标/几何数值钳制，坏条目丢弃，不阻断启动。
- **显示器变更**：恢复几何与任何屏幕不相交时回退默认 1000×640 由系统摆放。
- **崩溃恢复**：持续防抖保存，崩溃最多丢失最后 500ms 内的光标变化，文件列表不丢。
- **另存为改路径**：监听 `Document::urlChanged`，会话随后更新为新 URL。
- **退出语义**：现有退出流程保证退出前所有修改过的文档要么保存、要么放弃关闭；"放弃"关闭的文档自然不在会话中，下次不恢复（符合预期）。
- **首次启动/无会话文件**：行为与现状完全一致（欢迎页）。
- 光标恢复仅含**位置**（字符偏移），不含选区与多光标状态。
- 不新增"是否启用会话恢复"设置项，默认开启。

## 输入输出

- **输入**：上次会话写入的 `qcnote.ini`（QSettings IniFormat，UserScope）。
- **输出**：
  - 启动时：恢复的文档集合（Tab 顺序、active、光标）、窗口几何与最大化状态；
  - 运行中/退出时：随文档集合与窗口状态变化更新的会话文件。

## 非功能需求（性能/安全/兼容性）

- 防抖 500ms，避免每次按键/拖动窗口落盘；会话文件仅数行 URL 与数值，写开销可忽略。
- 会话文件为用户目录私有配置，不写入项目目录；测试中经 `QSettings::setPath` 或注入文件路径重定向到临时目录，不污染真实配置。
- 回归红线：无会话文件时行为与现状完全一致；`openUrls`、关闭/退出流程等既有行为零改动。

## 依赖

- Qt 6 `QSettings`（QtCore，无新第三方依赖）。
- 既有 `DocumentManager`（文档生命周期、`openUrls`）、`Document`（文档状态）、`EditorArea`（光标宿主）。

## 验收标准

1. 打开若干文件、调整光标与窗口（含最大化）后退出，重新启动：文件按原 Tab 顺序全部重新打开，活动标签与各文档光标位置恢复，窗口几何与最大化状态恢复。
2. 退出前删除其中某个会话文件：重启后其余文件正常恢复，无错误弹窗。
3. 全部文件丢失或无会话文件：启动显示欢迎页，与现状一致。
4. 拔掉曾记录的副屏后启动：窗口落在可用屏幕内（回退默认几何），不出现不可见窗口。
5. 崩溃（进程被杀）后重启：文件列表与会话不丢。
6. 既有单元测试（test_core / test_editor / test_window）全部通过，无回归。
