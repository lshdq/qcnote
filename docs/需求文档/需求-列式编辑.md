# 需求：列式编辑

## 背景与目标

qcnote 当前为单光标纯文本编辑器（QML TextArea，每文档一个实例）。文本编辑场景中经常需要在多行的同一列批量输入/删除/修改内容（如批量加注释前缀、批量补行尾分号、批量修改对齐列），单光标操作繁琐。

目标：为编辑器添加 VS Code 风格的**完整多光标体系**，覆盖列选区、多光标同步编辑、列复制/粘贴/剪切，且不影响现有单光标编辑行为。

## 功能描述

### 核心功能

**多光标生成**

| 功能 | 快捷键/交互 |
|---|---|
| 在上/下方添加光标（保持当前列） | `Ctrl+Alt+Up` / `Ctrl+Alt+Down` |
| 鼠标任意位置添加光标 | `Alt+Click` |
| 鼠标矩形列选区（每行一个选区） | `Alt+Shift+鼠标拖拽` |
| 键盘矩形列选区 | `Ctrl+Alt+Shift+方向键` |
| 选中多行后每行行尾插入光标 | `Shift+Alt+I` |
| 依次选中下一个与当前词相同的文本 | `Ctrl+D`（无选区时先选中光标处单词；查找可环绕文档；大小写敏感精确匹配；无更多匹配时无操作） |
| 选中全部相同文本 | `Ctrl+Shift+L` |

**多光标编辑**（所有光标同步执行）

- 可打印字符输入（含中文，经输入法提交后分发到所有光标）
- `Backspace` / `Delete`（有选区删选区；无选标删字符，行首 Backspace 并入上一行）
- `Enter` 各光标处分段换行
- 方向键 / `Home` / `End`（含 `Shift` 扩展选择、`Ctrl+Left/Right` 按词移动）
- 列选区状态下输入：逐行替换各行选区

**列复制/粘贴/剪切**

- `Ctrl+C`：多个选区文本按行以 `\n` 拼接写入剪贴板（无选区的光标贡献空行）
- `Ctrl+X`：同 `Ctrl+C` 并删除所有选区
- `Ctrl+V`：剪贴板行数与光标数**相等**时逐行分发光标；**不相等**时每个光标插入整份文本（多行文本以 `\n` 连接）

**撤销与退出**

- 一次按键在所有光标产生的编辑合并为**单次撤销**（`Ctrl+Z` 一步回滚整批）
- `Esc` 退出多光标，保留最后（按位置排序最末）一个光标
- 鼠标单击（无 Alt）退出多光标，回到单击处单光标
- 多光标激活时收到未支持的编辑命令（如 `Ctrl+A`）：先退回单光标再执行原生命令

**状态提示**

- 状态栏在光标数大于 1 时显示"光标 ×N"

**可视化**

- 额外光标渲染为与原生光标一致的竖线（可闪烁）
- 各选区渲染高亮矩形（颜色取 AppTheme 语义 token）

### 边界与约束

- 中文输入法**预编辑**（组字窗口）只在主光标处由 TextArea 原生显示；**提交**的字符串分发到所有光标（与 VS Code 行为一致）
- 列选区鼠标拖拽暂不做拖出视口边缘的自动滚动（auto-scroll），后续版本增强
- `Home` 为简单语义：跳行首第 1 列（不做 VS Code 智能首次非空白切换）
- `Ctrl+D` 大小写敏感、精确匹配、不跨行匹配（单词不含换行）
- 多光标状态按文档（每个 TextArea 实例）独立保留；文档内容被外部重置（重新加载/另存覆盖）时自动退回单光标
- 已知系统冲突：Windows 显卡驱动可能占用 `Ctrl+Alt+方向键`（屏幕旋转热键），属系统级问题，不在应用内解决，帮助文档注明
- 无多光标（单光标）时**不拦截任何按键/鼠标事件**，现有编辑行为零变化

## 输入输出

- 输入：键盘事件（按键 + 修饰键组合）、鼠标事件（位置 + 修饰键）、剪贴板文本（UTF-8，`\n` 分行）、输入法提交字符串
- 输出：文档内容修改（经现有 `Document.content` 同步链路写入）、剪贴板文本、状态栏光标数量、覆盖层光标/选区渲染数据（位置列表与选区区间列表）

## 非功能需求（性能/安全/兼容性）

- 纯逻辑引擎不依赖 GUI 类型（仅 QtCore），可在控制台 QtTest 中全量单测
- 编辑指令从后往前应用保证批量偏移稳定；单批编辑在一个 `QTextCursor::editBlock` 内完成
- 千行规模文档上多光标操作无明显卡顿（指令计算 O(光标数 + 文档长度)）
- 不改动 `Document`/`DocumentManager`/`LocalStorage` 现有接口与行为
- QML 中颜色一律取 `AppTheme` 语义 token；状态表达不依赖纯颜色

## 依赖

- 依赖现有：`qcnote` QML 模块、`TextArea.textDocument`（QQuickTextDocument）、`positionToRectangle`/`positionAt`、`AppTheme`
- 不引入第三方库，不使用 Qt 私有头

## 验收标准

1. 功能表中全部交互按描述生效（详见 `docs/测试用例/测试用例-列式编辑.md`，P0 用例全部通过）
2. 引擎单元测试全量通过：`ctest --test-dir build --output-on-failure`
3. 一次多光标按键编辑可被一次 `Ctrl+Z` 完整回滚
4. 单光标场景行为与改动前完全一致（回归）
5. offscreen 冒烟启动不崩溃；人工交互用例清单验证通过
