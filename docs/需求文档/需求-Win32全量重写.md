# 需求：Win32 全量重写（qcnote 1.0.0）

## 背景与目标

将 qcnote（Qt 6 Quick/QML 文本编辑器，约 9.6k 行）**全量重写**为**纯 Win32 + Scintilla 静态链接 + C++23 + MSVC** 的 Windows 单文件绿色小工具。

动机：Qt Quick 版空闲内存占用高（基线 60~100 MB）、启动偏慢（0.5s+）、界面响应不顺畅，根因是 QML 引擎 + GPU 场景图的固有基线成本，优化无法突破。用户定位为日常使用的小工具，三项指标优先级高于功能丰富度。

技术选型已由《qcnote-Win32重写方案.md》（2026-11-10 技术选型评估会话产出）逐项锁定，本需求文档将其与现有功能基准（`docs/` 18 篇需求文档 + 19 篇决策记录 + 最新代码行为，基线 commit `4e313f0`）整合为重写版正式需求。

**硬要求：功能对等迁移**——以下第「功能描述」节 A~F 各表为验收基准（A 5 项 + B 5 项 + C 4 项 + D 5 项 + E 5 项 + F 扩展点 2 条，合计 26 条目），语义以 `docs/` 历史文档与决策记录（DEC-xxx）为准，不得凭猜测简化。

## 功能描述

### 核心功能

#### A. 文档与标签

| # | 功能 | 对等语义（含决策引用） |
|---|------|----------------------|
| A1 | 多标签文档 | 新建 Ctrl+N（未命名-N 递增）；打开 Ctrl+O（多选、重复路径激活已有标签）；保存 Ctrl+S（无路径先转另存为）；另存为 Ctrl+Shift+S（遮蔽其他已打开文档时重载该文档，初始化 DEC-008）；关闭标签 Ctrl+W；Ctrl+Tab / Ctrl+Shift+Tab 循环切换标签 |
| A2 | Win11 连通式标签条 | 活动 Tab 顶圆角卡片与工具栏同色；非活动 Tab 透明 + 悬停半透明高亮；标签间竖分隔线（非活动标签左缘、两侧邻居非活动时显示）；**无每标签关闭按钮**（关闭走右键菜单 / Ctrl+W / 主菜单）；宽度自适应（下限 100px、单 Tab 上限 max(100, W/4)、按可收缩量等比收缩、向下取整、饱和回退横向滚动）；未保存 ● 标记；超长省略 + tooltip 完整名；溢出横向滚动（窗口控制按钮永不被挤压）；键盘导航（左右方向键循环焦点、Enter/Space 激活、Menu/Shift+F10 弹右键菜单） |
| A3 | 标签右键菜单 | 关闭当前文件 / 关闭右边所有 / 关闭左边所有 / 关闭其他文件；右键不激活标签；批量关闭逐个三选确认、完成后激活被右键标签（锚点） |
| A4 | 标签关闭三选确认 | 保存 / 不保存（同时清理草稿）/ 取消——保留；**仅应用退出免提示**（热退出，见 C4） |
| A5 | 欢迎页 | 无文档时显示，含「打开文件…」文字按钮 |

#### B. 编辑

| # | 功能 | 对等语义 |
|---|------|---------|
| B1 | 换行与编码 | 内存一律 LF、无 BOM；Document 记录原换行风格（CRLF/LF），保存时写回，新文档 LF；读 UTF-8 容忍 BOM（剥离，保存原样写回）；GBK（CP936，Win32 NLS API）；自动识别：UTF-8 BOM → 严格 UTF-8 校验 → GBK（无法解码字节以 U+FFFD 呈现）；「通过编码重新加载」（有未保存修改先确认框；未命名文档禁用；重载后换行重探测、光标钳制、不置脏）；「通过编码保存」一步完成转换；GBK 不可编码字符保存失败 + 错误消息含字符与行号（写盘前校验）；状态栏显示 UTF-8 / UTF-8 BOM / GBK；会话按文档记忆编码，旧会话无记录回退自动识别 |
| B2 | 自动换行 | 视图菜单「自动换行」切换；NoWrap 时长行横向滚动 |
| B3 | 滚动条常驻 | 竖向：内容超高时常驻显示，短内容隐藏；横向：NoWrap 长行常驻，开启换行后隐藏（动态切换）；滚轮到边界无过冲回弹 |
| B4 | 多光标列编辑 | 快捷键：Ctrl+Alt+↑/↓ 添加光标、Alt+单击任意位置、Alt+Shift+拖拽矩形列选（视觉逐行命中、短行钳制行末、全角/Tab 真实宽度对齐）、Ctrl+Alt+Shift+方向键盘列选（期望 x 粘性、Left/Right 不跨行、无虚拟空间）、Shift+Alt+I 选中行行尾插光标、Ctrl+D 依次选中相同词（无选区先选当前词、大小写敏感、不跨行、环绕、严格重叠判定——端点相接允许追加）、Ctrl+Shift+L 选中全部相同；编辑：可打印字符（含中文 IME 提交分发到所有光标，预编辑只在主光标）、Backspace/Delete（行首 Backspace 并行）、Enter 分段换行、方向键/Home/End（含 Shift 扩展、Ctrl 按词）、列选区输入逐行替换；剪贴板：Ctrl+C 多选区按行 \n 拼接（无选区光标贡献空行）、Ctrl+X 同 C 并删除、Ctrl+V 行数==光标数逐行分发否则每光标插整份；一次按键全光标编辑合并为**单次撤销**；Esc 退出保留按位置最末一个光标；鼠标单击退出；未支持命令（如 Ctrl+A）先退单光标再执行；多光标状态按文档独立保留，文档外部重置自动退出；状态栏「光标 ×N」；**与查找互斥**（打开查找对话框即退出多光标） |
| B5 | 查找替换 | Ctrl+F/Ctrl+H 打开同一模态对话框（顶部对齐 y≈96，可拖动）；打开预填：有不含换行的选区→填入并全选，否则上次查找串并全选；Esc/关闭按钮关闭并清除全部匹配高亮（**不清匹配状态**，F3 可继续）；三开关：区分大小写（默认关）、全字匹配（默认关，正则时禁用置灰）、正则表达式（默认关，PCRE 语义、`.` 不匹配换行、`^`/`$` 仅全文首尾、多行由 `(?m)` 控制）；输入即实时计算：全部匹配高亮（indicator）+「第 N 个 / 共 M 个」；无匹配显示「无匹配」；无效正则显示错误不崩溃；Enter/查找下一个、Shift+Enter 上一个、到达末尾**环绕**；F3/Shift+F3 关闭态沿用上次参数跳转（不恢复全部高亮，原生选区+滚动可见）；「替换」替换当前后自动跳下一个；「全部替换」单次撤销、完成后显示「已替换 N 处」；替换串捕获组 `$1..$99` 与 `\1..\9` 等价、`$$` 字面 `$`、引用不存在组输出空串；**零长度匹配跳过**（不计入不高亮不替换）；匹配数 >10000 显示「>10000」、停止绘制高亮（导航替换仍可用）；全部替换按原文本坐标一次性计算；当前匹配=原生选区+描边（非颜色线索）；文档外部重置时重算匹配（当前索引归 -1）；活动文档切换时匹配状态重算；无文档时 Ctrl+F/Ctrl+H 无操作；查找/替换串与开关状态会话内保留（内存）；菜单「搜索」四项入口（查找…/替换…/下一个/上一个，行为与快捷键一致，欢迎页置灰） |

#### C. 会话与草稿

| # | 功能 | 对等语义 |
|---|------|---------|
| C1 | 会话恢复 | 记录：有 URL 文档列表（顺序、URL、光标位置、编码）+ 活动标签 + 窗口 normal 几何 + 最大化标志；500ms 防抖统一写盘 + 退出前 flush；启动恢复：文件存在性预检（缺失/目录/坏条目**静默跳过**零弹错）、按原顺序打开、逐文档恢复钳制后光标、按记录激活（active 丢失激活最后成功文档）；全部丢失→欢迎页；几何校验（宽高钳到 [800×500, 屏幕可用区]，位置须与某屏相交否则回退默认 1000×640）；显示器变更不产生不可见窗口；崩溃最多丢最后 500ms 光标变化；另存为后 URL 更新；光标恢复仅位置不含选区 |
| C2 | 关闭现场还原 | 未命名文档在会话中记录 uid + 标签栏位置（编号键）；活动标签为未命名时记 activeUid；重启恢复：文件条目按原顺序、未命名草稿按会话位置升序稳定插入，最终标签顺序=关闭时顺序；激活优先级：activeUid 匹配 > 会话 active URL > 首个恢复文档；无内容未命名标签不恢复（空位消除）；旧格式会话（无 uid 键）容错跳过 |
| C3 | 草稿缓存 | 缓存目录：便携模式 exe 旁 `drafts/`，否则 `%LOCALAPPDATA%` 下 `drafts/`；每文档一个 `<uid>.json`（原子写，字段：version/url/untitledName/content/cursor/lineEnding/encoding/hasBom/baselineHash/savedAt）；脏文档内容变化 1s 防抖排队写（只重写变化条目，写失败静默容错）；**失焦即写**（flushPending）；清理：内容回到基线（保存/另存/撤销回基线/编码重载）删条目；关闭仍脏（放弃路径）删条目；正常退出经流程清理；恢复（会话恢复之后）：有 URL 且磁盘哈希==baselineHash → 静默应用为未保存修改（光标钳制、删条目）；哈希不符或文件缺失 → 冲突汇总对话框（单框列出全部冲突，「恢复」=缓存覆盖为未保存修改（文件缺失恢复为未命名）/「丢弃」=删条目）；未命名条目 → 重建未命名文档（沿用显示名、编号器跳过占用号、标记已修改）；损坏/版本不符 → 静默删除；同 URL 多条目按 savedAt 最新去重；恢复不改变会话设定的活动标签（空场景激活首个恢复文档） |
| C4 | 热退出 | X/Alt+F4/菜单「退出」：无模态对话框打开时**直接退出免提示**；未保存修改（含未命名）经草稿保留，下次启动恢复；模态对话框打开时拒绝关闭 |

| # | 功能 | 对等语义 |
|---|------|---------|
| E1 | 一体化无边框标题栏 | 布局：菜单按钮 → Tab 条 → 最小化/最大化/关闭（图标垂直居中，Win11 风格；最大化↔还原图标切换）；空白区（含 Tab 条无 Tab 覆盖处）按住拖动超 4px 启动系统移动；双击空白最大化/还原；**最大化时拖拽 → 还原 + 光标比例锚定 + 继续系统拖拽**；8 向边缘缩放；Win+方向贴靠、Aero Snap；Win11 Snap Layouts（最大化按钮悬停）；右键标题栏系统菜单；Per-Monitor V2 DPI（各 DPI 下按钮尺寸/字体缩放正确）；主菜单分组：文件▸（新建/打开…/保存/另存为…/关闭标签页/编码▸（通过编码重新加载▸UTF-8/GBK、通过编码保存▸UTF-8/GBK，三级级联，当前项打勾））、搜索▸（查找…/替换…/下一个/上一个）、视图▸（深色主题/自动换行）、退出（顶层）；菜单项显示快捷键文本 |

| E4 | 弹窗可拖动 | 应用内自绘弹窗（未保存确认、错误、编码重载确认、草稿冲突、查找替换）标题栏把手可拖动；边界约束（把手保留窗口内可抓回）；每次打开复位默认位置（Main 对话框居中、查找对话框顶部对齐 y≈96）；未拖动时窗口 resize 弹窗跟随默认位置 |
| E5 | 双主题 | 浅色/深色两套语义配色（token 体系移植自 AppTheme.qml）；视图菜单「深色主题」切换即时生效；非客户区（标题栏/滚动条/IME 候选窗）随 DwmSetWindowAttribute 联动暗色 |

#### F. 架构扩展点（本次不实现，不得堵死）

- **format 层**：文档格式抽象 + 纯文本默认兜底（未知扩展名按纯文本）；未来 Markdown/JSON 在同层新增实现注册
- **storage 层**：存储抽象按 URL scheme 分发；`file://` 由本地存储实现；未来网络存储同层新增

### 边界与约束（本期不做）

- 不做：Markdown/JSON 语法高亮渲染、网络存储、设置页、打印、i18n 框架、最近文件、Tab 拖拽排序、拆分窗口、多光标拖拽自动滚出视口增强（Scintilla 原生自带拖选自动滚动，优于 Qt 版，属增强）
- 大文件（>10MB）不做性能优化，允许卡顿，不作为缺陷
- 用户可见字符串直接写中文，不做 i18n 抽取
- 不迁移 Qt 特有 workaround（PointHandler 拖选驱动、Flickable 抢夺防御、Canvas 重绘触发等约 30 项补丁在 Scintilla 下自然消失）
- 纯文本阶段不引入 Lexilla（将来 Markdown 高亮再评估）

## 输入输出

- 输入：本地文本文件（UTF-8 带/不带 BOM、GBK/GB2312；CRLF/LF/CR 混合换行）；用户键鼠/IME 交互；命令行位置参数；已运行实例转发的 `WM_COPYDATA` 参数；上次会话/草稿持久化数据
- 输出：按文档编码与换行风格写回的本地文件（原子写）；会话 ini 与草稿 JSON（防抖落盘）；单 exe 产物（`/MT`，无外部 DLL 依赖）

## 非功能需求（性能/安全/兼容性）

| 指标 | 目标 | 度量方法 |
|------|------|---------|
| 空闲内存（空壳） | **< 10 MB**（预期 3~6 MB） | 任务管理器默认「内存」列（**私有工作集**口径）；启动后无文档仅欢迎页静置 5 秒读取 |
| 空闲内存（开文档） | **≤ 30 MB**（预期 6~15 MB） | 打开若干典型小笔记文件后静置读取 |
| 启动时间 | **< 200 ms**（预期 20~80 ms） | 冷启动（重启后首次含杀软）与热启动分别计时到主窗口可见 |
| 部署 | **单 exe 免安装** | `dumpbin /dependents` 无非系统 DLL；exe 直接运行 |

- M0 完成即建立基线测量，不等收尾；测量脚本/方法持久化到 `tools/`（口径注明私有工作集）
- 目标平台 Windows 10/11 x64；MSVC（VS Build Tools 2026）编译，`/std:c++23`（Scintilla TU `/std:c++20` 混编无 ODR 问题）；`/MT` 静态 CRT；Release `/O1` 或 `/Os` 优先小体积
- 依赖一律 vendored 源码（WIL 头文件、Scintilla 源码、Catch2 v3），不引入包管理器
- C++ 核心逻辑（编码探测、换行归一、查找引擎、会话/草稿序列化、列选语义映射等）必须有 **Catch2 v3** 单元测试覆盖；GUI 走进程级冒烟 + 真机人工验收清单
- **中文 IME 输入是最大功能风险**（Scintilla 组合窗/候选窗行为），M2 里程碑必须实测（组合窗跟随、候选窗位置、GB 区字符输入）
- Scintilla 与 PMv2 DPI 的字体缩放专门验证（M1/M2）
- 保留旧 `build/` 目录与 Qt 工具链资产不动；旧 `src/`、`tests/`、`tools/icongen` 在 M0 新骨架就绪后一次性删除（git 历史可追溯）；`src/icons/` 图标资产保留复用
- 无边框窗口必做项逐项验证：`WM_NCCALCSIZE`、`WM_NCHITTEST`、Snap Layouts、Aero Snap、双击标题栏、PMv2 DPI、系统菜单
- 卡壳时优先对照 Notepad++ / Notepad2（同为 Win32+Scintilla 开源栈）参考实现
