# 需求：正则搜索与替换

## 背景与目标

qcnote 当前为纯文本编辑器（QML TextArea + 多光标体系），**没有任何查找/替换功能**。文本编辑场景中查找定位、批量改写（如统一替换变量名、按模式批量修改）是高频操作。

目标：为编辑器添加**正则表达式搜索与替换**功能，支持纯文本与正则两种模式、大小写/全字选项、全部匹配高亮、逐个/全部替换，且不影响现有编辑行为（单光标、多光标、会话恢复等零回归）。

## 功能描述

### 核心功能

**打开 / 关闭**

| 操作 | 行为 |
|---|---|
| `Ctrl+F` | 打开查找替换对话框（模态），聚焦查找输入框 |
| `Ctrl+H` | 打开同一对话框，聚焦替换输入框 |
| `Esc` / 关闭按钮 | 关闭对话框，清除全部匹配高亮 |
| 打开时预填 | 编辑器有**不含换行**的选区 → 填入查找框并全选；否则填入上次查找串并全选 |

- 对话框为**模态**（打开期间锁定其他编辑操作），**顶部对齐**于窗口（不居中），避免遮挡编辑区，保证背后匹配高亮可见。
- 查找串、替换串与三个选项开关的状态**会话内保留**（内存，不写盘）。
- 多光标激活时打开对话框 → 自动退出多光标（互斥）。
- 对话框打开状态纳入 `Main.qml` 的 `uiLocked()`（与其他模态流程互斥）。

**查找**

- 输入即实时计算：全部匹配高亮 + 计数显示「第 N 个 / 共 M 个」。
- 无匹配显示「无匹配」；无效正则显示错误文本（如「无效的正则表达式」），不崩溃。
- 跳转：`Enter` / 「查找下一个」按钮 → 下一个匹配；`Shift+Enter` → 上一个；到达末尾**环绕**。
- `F3` / `Shift+F3`：对话框关闭时也可继续下一个/上一个（沿用上次的查找参数）。
- 当前匹配以 TextArea **原生选区**呈现并滚动到可见；高亮层为当前匹配绘制**描边**（非颜色线索区分于其他匹配）。

**匹配选项（三个开关）**

| 开关 | 默认 | 说明 |
|---|---|---|
| 区分大小写 | 关 | 关闭时忽略大小写 |
| 全字匹配 | 关 | 仅纯文本模式生效；正则开启时**禁用置灰** |
| 正则表达式 | 关 | 开启后查找串按 `QRegularExpression`（PCRE）解释；关闭时按字面文本查找 |

**替换**

- 「替换」：替换当前匹配后自动跳到下一个匹配。
- 「全部替换」：一次性替换所有匹配，完成后对话框内显示「已替换 N 处」。
- 替换串支持捕获组引用：`$1`..`$99` 与 `\1`..`\9`（两者等价）；`$$` 输出字面 `$`；引用不存在的组输出空串。
- 替换仅作用于**当前活动文档**（不做跨文件）。

**可视化**

- 全部匹配：覆盖层半透明底色高亮（颜色取 `AppTheme` 新增语义 token）。
- 当前匹配：原生选区 + 高亮层描边矩形。

### 边界与约束

- 正则语义：`.` 不匹配换行；`^`/`$` 默认仅匹配整个文本首尾；多行语义由用户以 `(?m)` 等内联选项自行控制。
- **零长度匹配跳过**（如 `a*` 的空匹配不计入、不高亮、不产生替换），防止死循环与无意义高亮。
- 全部替换按**原文本坐标一次性计算**，替换产物不再参与本轮匹配。
- 匹配数超过 **10000**：计数显示「>10000」，全部高亮停止绘制（性能防护），导航与替换仍可用。
- 撤销：「替换」一次一步；「全部替换」整体为**单次撤销**（单 `editBlock`）。
- 文档内容被外部重置（重新加载/编码重载）时若对话框打开 → 重算匹配（防御性钳制）。
- 模态打开期间活动文档不变（标签切换等已被 `uiLocked()` 阻止）。
- 无文档（欢迎页）时 `Ctrl+F`/`Ctrl+H` 无操作。

## 输入输出

- 输入：查找模式串、替换串、三开关状态、当前文档文本（内存中 LF 表示）
- 输出：
  - 文档内容修改（经现有 `TextArea.text` ↔ `doc.content` 同步链路回写，撤销/保存/会话恢复零改动）
  - 匹配区间列表与当前索引（供高亮层与计数）
  - 错误信息（无效正则）

## 非功能需求（性能/安全/兼容性）

- 纯逻辑引擎仅依赖 QtCore（QRegularExpression），可在控制台 QtTest 中全量单测。
- 千行规模文档、万级匹配数下打开/输入/跳转无明显卡顿：`findAll` 单遍 O(n)，导航 O(1)，高亮绘制受 10000 上限约束。
- 编辑指令从后往前应用保证批量偏移稳定；替换批次在单 `QTextCursor::editBlock` 内完成。
- 不引入第三方库，不使用 Qt 私有头。
- 不改动 `Document`/`DocumentManager`/`LocalStorage` 现有接口与行为。
- QML 颜色一律取 `AppTheme` 语义 token；错误/无匹配状态必须有非颜色线索（文本）。

## 依赖

- 依赖现有：`qcnote` QML 模块、`TextArea.textDocument`（QQuickTextDocument）、`MultiCursorLayer` 的按可视行拆段算法（提取为共享代码）、`DialogButtonBox`/`DialogButton`、`AppTheme`、`uiLocked()` 流程框架
- 不引入第三方库

## 验收标准

1. 功能表中全部交互按描述生效（详见 `docs/测试用例/测试用例-正则搜索与替换.md`，P0 用例全部通过）
2. 引擎单元测试全量通过：`ctest --test-dir build --output-on-failure`
3. 「全部替换」可被一次 `Ctrl+Z` 完整回滚；「替换」每步对应一次撤销
4. 不使用查找功能时编辑行为与改动前完全一致（单光标、多光标、会话恢复回归）
5. offscreen 冒烟启动不崩溃；人工交互用例清单验证通过
