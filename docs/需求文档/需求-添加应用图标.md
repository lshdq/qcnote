# 需求：添加应用图标

## 背景与目标

qcnote 当前可执行文件未嵌入任何图标资源，Windows 资源管理器、任务栏、窗口标题栏均显示系统默认白板图标。本需求为应用添加统一的品牌图标：

1. exe 嵌入多尺寸 `.ico`，资源管理器/任务栏/标题栏自动生效
2. 运行时显式设置 `QGuiApplication::setWindowIcon`，为未来跨平台（Linux）铺路

## 功能描述

### 核心功能

- **图标母版**：`src/icons/qcnote.svg`（1024 viewBox）——accent 蓝 `#3564d4` 圆角方板（圆角率约 22%）+ 白色填充式文档字形（折角 + 文字线条），呼应工具栏 `new.svg` 母题；填充式设计保证 16px 下清晰
- **ICO 产物**：`src/icons/qcnote.ico`，含 16/24/32/48/64/256 六档尺寸，PNG 压缩条目（Win10+ 标准）
- **exe 嵌入**：`src/qcnote.rc`（`IDI_ICON1 ICON "icons/qcnote.ico"`）加入 `qt_add_executable`，MinGW 经 windres 编译
- **运行时窗口图标**：`main.cpp` 中 `setWindowIcon(QIcon(":/qt/qml/qcnote/icons/qcnote.svg"))`，exe 链接 `Qt6::Svg`
- **生成工具**：`tools/icongen/`（Qt Svg 光栅化控制台程序，独立构建）+ `tools/make-ico.ps1`（PNG→ICO 打包脚本），换图标可一键重新生成

### 边界与约束

- 不改动工具栏功能图标（new/open/save.svg）与 `AppTheme.qml`
- ICO 采用 PNG 压缩条目，不兼容 XP（Qt 6 仅支持 Win10+，无影响）
- icongen 工具不进入主构建（`tools/icongen` 独立 CMake 工程，过程构建目录用后即清）
- 本机无 ImageMagick/Inkscape/Python，生成链全部依赖本机 Qt 工具链，零外部依赖

## 输入输出

- 输入：`src/icons/qcnote.svg`（图标母版，设计源文件，入库）
- 输出：`src/icons/qcnote.ico`（生成物，入库）、`build/qcnote.exe`（嵌入图标）

## 非功能需求（性能/安全/兼容性）

- 光栅化使用 QSvgRenderer 默认抗锯齿，各尺寸清晰
- 蓝底白字方案在浅色/深色任务栏均可辨
- `.rc` 文件保持纯 ASCII，规避 windres 编码问题
- 运行时 QIcon 加载 SVG 依赖 Qt6 Svg 图标引擎插件，开发期从 Qt 安装目录加载；部署时 `windeployqt` 自动携带

## 依赖

- Qt 6.5+ `Svg` 组件（`D:\Program\Qt\6.11.2\mingw_64`，已确认安装）
- CMake 对 `.rc` 的内建支持（MinGW windres）

## 验收标准

1. `build/qcnote.exe` 嵌入图标：`[System.Drawing.Icon]::ExtractAssociatedIcon()` 提取非空且尺寸正确
2. `src/icons/qcnote.ico` 含 16/24/32/48/64/256 六档尺寸
3. 主构建目录 `build/` 完整构建通过，`ctest` 现有测试全部通过
4. offscreen 冒烟运行正常（`QT_QPA_PLATFORM=offscreen`）
5. `src/icons/qcnote.svg` 经 qt_add_qml_module RESOURCES 嵌入，运行时 `setWindowIcon` 生效（offscreen 冒烟仅验证启动不崩溃；资源嵌入与路径正确性由 TC-008 双断言验证——断言 A：exe 字节中搜索 `qt/qml/qcnote/icons/qcnote.svg` 的 UTF-16 LE 序列，验证 main.cpp 引用路径已编译进 exe；断言 B：搜索带 `00 0A` 大端长度前缀的 UTF-16 BE 段名 `qcnote.svg`，验证资源真实嵌入 rcc 资源树；两者合取覆盖"路径写错"与"资源漏配"两类回归）
