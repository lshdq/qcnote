# 需求：标签宽度自适应

## 背景与目标

文档 Tab（`src/qml/DocumentTabs.qml`）当前为固定宽度 168px：短文件名浪费空间、
视觉零碎；长文件名即使标题栏有大量空白也直接省略显示。

目标：Tab 宽度在最小值与动态上限之间按自身文字自然宽度自适应；空间不足时
等比例收缩，收缩饱和后回退到既有横向滚动。

## 功能描述

### 核心功能

宽度分配算法（N 个 Tab，Tab 区可用宽度 W，Tab 间距 2px，gaps = 2 × (N−1)）：

1. **最小宽度**：100px（固定下限）；
2. **单 Tab 动态上限**：`cap = max(100, floor(W / 4))`（窗口极窄时退化为最小值，
   避免上限小于下限的矛盾）；
3. **自然宽度**：`n_i = min(文字自然宽度 + 装饰宽度, cap)`；
   - 文字自然宽度：与 Tab 标签同字体（pixelSize 13、默认字体族）实测；
   - 装饰宽度：未保存 ● 标记（含左边距 8、右侧间距 5；无标记时左边距 10）、
     关闭按钮（20px、右缘 4px）、标签与关闭按钮间距 2px；
4. **空间充足**（`Σn_i + gaps ≤ W`）：`w_i = n_i`，各 Tab 独立适配、文字完整显示；
5. **空间不足**：缺口 `D = Σn_i + gaps − W`，总可收缩量 `C = Σ(n_i − 100)`，
   `D < C` 时 `w_i = n_i − D/C × (n_i − 100)`（按可收缩量等比例收缩，不低于 100）；
6. **收缩饱和**（`D ≥ C`）：全部 Tab 取 100px，进入既有横向滚动。

### 边界与约束

- 仅修改 `src/qml/DocumentTabs.qml`，不改 C++ 代码、不改 `TitleBar.qml`；
- 保留既有行为：超长省略（ElideRight）+ tooltip 完整名、溢出横向滚动 +
  滚动条、键盘导航（左右方向键/Enter/Space）、无障碍名称（含未保存状态）、
  窗口控制按钮永不被挤压；
- 宽度重算触发源：文档打开/关闭（模型 count 变化）、文档重命名
  （displayName 变化）、未保存状态切换（modified 变化）、Tab 区宽度变化
  （窗口缩放）；
- 收缩值向下取整，保证 contentWidth 不因舍入虚增导致滚动条误判闪烁；
- 装饰尺寸常量在组件内单点定义，宽度计算与 delegate 布局共用。

## 输入输出

- 输入：Tab 区可用宽度 W、各文档 displayName、modified 状态、文档数量；
- 输出：各 Tab 的显示宽度（100 ≤ w_i ≤ n_i）；无数据输出。

## 非功能需求（性能/安全/兼容性）

- 宽度重算在触发源变化的一帧内完成，窗口连续缩放无肉眼可见抖动、无滚动条闪烁；
- 计算量为 O(N)（每 Tab 一次文字测量），典型几十个 Tab 无性能问题；
- 不引入定时器、轮询或 C++ 侧改动；
- 深色/浅色主题均适用（宽度与主题无关）。

## 依赖

- 无新增依赖；仅修改 `src/qml/DocumentTabs.qml` 一个文件。

## 验收标准

1. 单个短文件名 Tab 宽度为其自然宽度（文字完整、无多余空白）；
2. 单个超长文件名 Tab 宽度不超过 Tab 区可用宽度的 1/4，超出部分省略、
   tooltip 显示完整名；
3. 多 Tab 且空间充足时，各 Tab 按自身文字独立取宽，短名 Tab 窄、长名 Tab 宽；
4. 空间不足时各 Tab 按可收缩量等比例收缩，任何 Tab 不低于 100px；
5. 全部收缩到 100px 仍放不下时出现横向滚动（既有行为）；
6. 另存为重命名、未保存标记出现/消失、窗口连续缩放后 Tab 宽度均正确重算；
7. 现有单元测试（ctest）全部通过；offscreen 冒烟无 QML 错误；
   qmllint 对改动行无新增警告。
