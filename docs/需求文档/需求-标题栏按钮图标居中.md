# 需求：标题栏按钮图标居中

## 背景与目标

- 用户反馈：标题栏最小化与最大化按钮的图标没有居中对齐。
- 根因：`src/qml/CaptionButton.qml` 的 Canvas（10×10，`anchors.centerIn` 于按钮）内，
  minimize 横线绘制在 **y=8.5**（Win10 式"底部基线"画法），视觉中心下移约 3.5px；
  相邻 maximize 方框（`rect(0.5, 0.5, 9, 9)`）几何上居中，两者参照不一致，
  观感上"都没对齐"。
- 目标：所有标题栏窗口控制图标（menu / minimize / maximize / restore / close）
  以按钮中心点垂直居中（Windows 11 风格）。

## 功能描述

### 核心功能

- 将 minimize 图标横线从 y=8.5 移至画布垂直中心 **y=5**（与 menu 中线、
  close 交叉中心一致）。

### 边界与约束

- 仅修改 minimize 分支的绘制坐标；maximize / restore / close / menu 已几何居中，不动。
- 不改按钮尺寸（44×40）、标题栏布局（垂直居中锚定）与任何交互行为。
- 不引入字体图标或图片资源，保持 Canvas 矢量绘制方案。
- 工作区存在前序任务未提交改动（详见审查范围文档），本次改动必须与之隔离可辨。

## 输入输出

- 输入：无（纯视觉绘制变更）。
- 输出：标题栏"最小化"按钮内横线位于按钮垂直中心，与"最大化/还原""关闭"图标中心对齐。

## 非功能需求（性能/安全/兼容性）

- 无性能、安全、兼容性影响：仅一处绘制坐标数值变更，不触碰逻辑、数据与接口。

## 依赖

- 无新增依赖。

## 验收标准

1. `CaptionButton.qml` minimize 分支横线绘制坐标为 y=5（画布垂直中心）。
2. `cmake --build` 构建通过；ctest 全量条目（test_core，1/1）通过、其内部 QtTest 函数全部通过（退出码 0）；offscreen 冒烟启动不崩溃。
3. 视觉验收（用户肉眼，不在自动化范围）：三个窗口控制按钮图标垂直方向中心对齐。
