# 需求：文档列表面板

## 背景与目标

qcnote 当前仅通过顶部 Tab 条展示与切换打开的文档，文档较多时 Tab 条横向溢出、
查找目标文档效率低。参照 Notepad++ 的 Document List 面板，新增一个常驻侧边
文档列表区域，集中展示全部打开文档，点击即切换活动文档，提升多文档场景下的
定位效率。

- 执行模式：Auto 模式（用户已于阶段 2 确认）
- 构建：执行（默认）
- 独立测试：执行（默认）
- 独立审查：执行（默认）
- 用户明确跳过项：无

## 功能描述

### 核心功能

1. **左侧文档列表面板**
   - 停靠位置：窗口左侧，纵向范围 = 工具栏底 ~ 状态栏顶（与编辑区同带）；
     面板可见时编辑区（Scintilla 实例集合）与欢迎页内容区向右收缩。
   - 平铺列表：每行显示一个文档（displayName + 未保存 ● 标记，语义与 Tab 条
     同源），不分组、不折叠。
   - 活动文档高亮：背景高亮块 + 左侧 accent 指示条（形状线索，非纯颜色）。
   - 悬停高亮；tooltip 悬停延迟 600ms 显示完整路径（仅有磁盘路径的条目）。
   - 无文档（欢迎页态）时照常显示空面板（对齐 Notepad++ 常驻语义）。

2. **显隐开关**
   - 菜单唯一入口：视图▸「文档列表」勾选项（对齐行号/自动缩进先例，无快捷键）。
   - 开关状态与面板宽度均随会话持久化（[editor] 节，前向兼容读写）。

3. **宽度拖拽调整**
   - 面板右缘 4 逻辑像素宽分隔条，hover 显示左右调整光标（IDC_SIZEWE）。
   - 按住拖拽调整宽度，实时重排编辑区；钳制 [120, 客户区宽/3]（逻辑像素，
     取整换算）。
   - 拖拽期间 SetCapture，松手/捕获丢失/失焦统一收口；Esc 取消回原宽。
   - 宽度持久化为逻辑像素（96 DPI 基准，跨 DPI 稳定），恢复时钳制。

4. **滚动**
   - 条目总高超出面板高时：滚轮垂直滚动（步长 = 3 行）+ 自绘滚动条
     （轨道 + 比例滑块 + 上下箭头按钮，主题色渲染）。
   - 程序化激活（点击/命令切换文档）时滚动使活动条目完整可见。

5. **右键菜单（复用 Tab 右键命令集）**
   - 关闭当前文件 / 关闭右边所有 (N) / 关闭左边所有 (N) / 关闭其他文件 (N)；
     尾部「文件重命名…」「打开所在文件夹」（仅有磁盘路径条目可用）。
   - 与 Tab 右键同一命令枚举、同一路由，经由面板条目 index 上抛。

6. **数据与事件**
   - 数据源 = DocumentManager 文档列表快照（与 Tab 条同源同批刷新）：
     documentsChanged / activeDocumentChanged / documentModifiedChanged /
     documentMetadataChanged 全部接入。
   - 主题切换（浅/深）即时换肤；DPI 变化按逻辑 token 重算。

### 边界与约束

- **不做**：文件夹分组树模式（Notepad++ Folder 视图）——记为后续扩展项；
  面板显隐快捷键；文档拖拽进面板打开；面板左右换边停靠。
- 面板不抢编辑器焦点：点击条目切换文档后焦点归还活动编辑器。
- 面板区域鼠标消息由主窗口路由（自绘组件非子窗口），与工具栏/状态栏同模式。
- 自测模式（--selftest-doclist）不读写真会话文件（SelftestModeActive 增补）。

## 输入输出

- 输入：DocumentManager 文档快照（displayName/modified/url）；鼠标/滚轮/键盘
  消息（主窗口转发）；菜单命令（ToggleDocList）。
- 输出：面板绘制（主题色板）；onDocActivated(index) / onDocContextCommand
  (index, Command) 回调；会话 ini [editor] 新键 docListVisible / docListWidth。
- 会话格式：qcnote.ini [editor] 节追加 `docListVisible=true|false` 与
  `docListWidth=<int 逻辑像素>`；缺失时回退默认（隐藏 / 200），旧版本读取
  新 ini 忽略未知键，零影响。

## 非功能需求（性能/安全/兼容性）

- **性能**：100 文档列表刷新无感知卡顿（同批快照 + 同值短路置脏）；拖拽
  调宽仅重布局不重建实例。
- **安全**：不触碰磁盘（纯 UI 层）；会话写入沿用原子写路径。
- **兼容性**：
  - 会话 ini 前向兼容（新键缺失回退默认；旧版读新文件忽略未知键）。
  - 既有 timer id 1-7 已占，面板 tooltip 用 8；WM_APP+13 selftest 消息顺延。
  - 双主题（LightPalette/DarkPalette）全覆盖，无散落硬编码色值。
  - DPI：PerMonitorV2 下逻辑 token 经 Scale() 换算，跨屏拖动重算。
- **可访问性**：未保存状态入无障碍名称；键盘焦点环；状态表达非纯颜色。

## 依赖

- 复用：ui/theme（色板与 Scale）、ui/menu（MenuHost/MenuModel 右键菜单）、
  ui/tooltip（ManualTooltip）、ui/tabs 的 BuildTabContextMenu 命令集、
  core/sessionmanager（[editor] 节读写管线）。
- 不新增第三方依赖；不修改 vendor/。

## 验收标准

1. 视图▸「文档列表」勾选切换面板显隐；编辑区/欢迎页随之收缩或铺满，无闪烁、
   无残留重绘。
2. 打开/关闭/另存为/重命名文档时列表实时同步（数量、显示名、● 标记、路径
   tooltip 可用性）；点击列表条目切换活动文档且 Tab 条/标题/状态栏联动。
3. 拖拽分隔条调整宽度实时生效，钳制边界正确；宽度与显隐状态重启后恢复
   （含旧 ini 无键回退默认）。
4. 列表溢出时可滚轮滚动 + 滚动条可用；激活条目自动滚入可视区。
5. 右键菜单命令与 Tab 右键语义一致（批量关闭/重命名/打开所在文件夹）。
6. 浅色/深色主题切换即时换肤；100% / 200% DPI 下布局与命中正确。
7. 全部既有 9 套 Catch2 单测与既有 verify-*.ps1 脚本回归通过；新增
   test_doclist 单测与 verify-doclist-selftest.ps1 通过（headless，不扰前台）。
