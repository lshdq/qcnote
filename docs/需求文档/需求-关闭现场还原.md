# 需求：关闭现场还原（标签顺序与活动标签）

## 背景与目标

热退出（关闭免提示）已落地后，用户实测发现重启未回到关闭时现场：关闭时正在编辑**未命名标签**，重启后激活的却是文件标签；且未命名标签恢复后统一**追加在尾部**，关闭时的标签顺序被打乱。

根因：会话只记录有 URL 的文档（顺序 + 活动标签 URL），未命名文档的活动状态与位置完全丢失；草稿恢复只负责「把内容找回来」，按条目文件名字典序追加。

目标：重启后**标签顺序与活动标签完全还原关闭时现场**——不管活动标签是已保存（文件）还是未保存（未命名）标签。

## 功能描述

### 核心功能

1. **会话记录完整标签序列（SessionManager）**
   - `[documents]` 按编号记录标签栏顺序：文件文档维持现状（url/cursor/encoding）；**未命名文档新增记录 `documents/N/uid`**（N 为其在标签栏中的原始位置编号，uid 即 Document 构造生成的不可变标识，与草稿条目主键同源）。
   - 活动标签：有 URL 时维持现状记 `documents/active`；为未命名文档时记 `documents/activeUid`（saveNow 整组重写保证两键不并存残留）。
2. **会话恢复暂存（SessionManager）**
   - 恢复时文件条目按原顺序打开（现状不变）；未命名条目内容在草稿中，此时仅暂存「uid → 会话位置」映射与 activeUid，新增查询接口：`int pendingDraftPosition(const QString &uid) const`（无记录 -1）与 `QString pendingActiveDraftUid() const`。
3. **按位插入（DocumentManager）**
   - `restoreUntitledDraft(content, untitledName, insertIndex = -1)`：-1 追加（默认，兼容既有调用）；否则钳制到 [0, size] 后同步插入内部列表与 QML model。
4. **草稿恢复保序与激活（DraftCacheManager）**
   - 未命名条目处理顺序改为**按会话位置升序**（无位置记录的排最后），逐个插入其会话绝对位置——文件文档已由会话恢复就位，稳定插入保证最终顺序 = 关闭时顺序。
   - 激活优先级：条目 uid 匹配 `pendingActiveDraftUid()` 的文档 **>** 会话活动文档复位（activeBefore）**>** 空场景激活首个恢复文档（上一工作流 DEC-002/006 规则作为兜底）。
   - SessionManager::instance() 判空（C++ 测试环境可能无会话单例）→ 跳过位置/激活匹配，回退现有规则。

### 边界与约束

- **旧会话文件兼容**：无 uid 键的未命名条目（旧格式不记录未命名，仅防御）跳过；`documents/N` 条目 url 与 uid 均空视为损坏丢弃（现状行为）。
- **无内容未命名标签**（无草稿）：不恢复（既定设计）——保序时其空位自然消除，其余标签相对顺序不变。
- **位置越界**：插入位置钳制到当前列表长度内；草稿条目比会话记录多（会话丢失场景）按追加处理。
- **文件缺失近似**（DEC-008）：关闭时位于缺失文件之后的未命名标签，与缺失文件之后存活文件的相对顺序可能颠倒（未命名彼此相对顺序不受影响）；完全精确需会话/草稿协同重排，成本高于收益，接受此近似。
- **文件标签激活**：现状（active URL 恢复）已正确，零改动。
- 便携模式、编码记忆、窗口几何等会话既有行为零变化；草稿写入/清理/冲突流程零变化。
- 用户并行开发中的滚动条改动（EditorArea.qml、tst_editorintegration.cpp、docs/测试报告/）不触碰。

## 输入输出

- **输入**：关闭时的标签序列（含未命名位置/uid）与活动标签标识；草稿条目内容。
- **输出**：重启后标签顺序与关闭时一致；活动标签 = 关闭时的活动标签（含未命名）。

## 非功能需求（性能/安全/兼容性）

- 会话条目每文档新增至多一个 uid 字段（36 字符），写盘开销可忽略。
- 回归红线：纯文件标签场景的会话恢复（顺序/active/光标/几何）与现状逐字节等价；全量 ctest 无回归。

## 依赖

- 既有 Document::uid()（草稿条目主键，同源标识）、SessionManager 防抖写盘、DraftCacheManager 恢复管线、上一工作流的恢复激活规则。

## 验收标准

1. 标签栏为 [文件A, 未命名1(有内容), 文件B]，活动 = 未命名1：退出重启 → 标签顺序仍为 [A, 未命名1, B]，活动 = 未命名1（内容为未保存状态）。
2. 标签栏为 [未命名1, 文件A, 未命名2]，活动 = 未命名2：退出重启 → 顺序与活动均还原。
3. 活动为文件标签（任意位置）：行为与现状一致（已覆盖，回归验证）。
4. 未命名标签无内容：不恢复，其余标签顺序不变。
5. 无会话/无草稿（首启、或会话文件旧格式）：行为与现状一致。
6. 全量 ctest 通过，无回归。
