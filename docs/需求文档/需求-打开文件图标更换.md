# 需求：打开文件图标更换

## 背景与目标

工具栏「打开文件」按钮当前使用闭合文件夹图标（`src/qml/icons/open.svg`），视觉上表达的是"文件夹"而非"打开"动作，语义不准确。目标：更换为语义更明确的 folder-open（掀开盖子的文件夹）图标，使其一眼可读出"打开"动作。

## 功能描述

### 核心功能

- 替换 `src/qml/icons/open.svg` 的内容为 Lucide `folder-open` 图标路径。

### 边界与约束

- 仅改图标资源文件内容：不改文件名、不改 `Toolbar.qml` 引用、不改 `src/CMakeLists.txt` 资源清单。
- 保持与 `new.svg` / `save.svg` 完全一致的风格参数：24×24 viewBox、`fill="none"`、`stroke="#000000"`、`stroke-width="2"`、圆角线帽/连接。
- 颜色仍由 QML 侧 `icon.color` 染色，SVG 内不引入任何颜色。
- 欢迎页「打开文件…」按钮为纯文字按钮，不在本次范围内。

## 输入输出

- 输入：folder-open 的 SVG 路径数据（Lucide）。
- 输出：工具栏打开按钮显示掀开盖子的文件夹图标，尺寸/颜色/悬停与禁用行为不变。

## 非功能需求（性能/安全/兼容性）

- 纯静态资源替换，无性能影响。
- 图标经 Qt 资源系统打包，加载方式不变，无兼容性风险。

## 依赖

- 无新增依赖。

## 验收标准

1. `open.svg` 为 folder-open 图形，风格参数与现有图标一致。
2. `cmake --build build` 构建通过。
3. offscreen 启动无 SVG 加载报错，既有 ctest 单元测试全部通过。
