# 需求：查找替换菜单入口

## 背景与目标

查找替换功能（见 `docs/需求文档/需求-正则搜索与替换.md`）已通过 `Ctrl+F` / `Ctrl+H` / `F3` 快捷键提供，但主菜单没有任何入口，不使用快捷键的用户难以发现该功能。同时现有主菜单为扁平结构（新建 / 打开 / 保存 / 另存为 / 关闭标签页 / 编码 / 查看 / 退出），条目增多后缺乏分组。

目标：

1. 主菜单重组为分组结构：新增「文件」子菜单收纳现有文件操作与「编码」子菜单；「查看」子菜单更名为「视图」。
2. 新增「搜索」子菜单，提供「查找」「替换」入口与「下一个」「上一个」跳转入口，行为与既有快捷键完全一致。

## 功能描述

### 核心功能

重组后菜单结构与行为：

| 菜单 | 条目 | 快捷键文本 | 行为 |
|---|---|---|---|
| 文件 ▸ | 新建 | Ctrl+N | 同现有（`doNewDocument`） |
| 文件 ▸ | 打开… | Ctrl+O | 同现有（`doOpenDialog`） |
| 文件 ▸ | 保存 | Ctrl+S | 同现有（`doSave`，含未命名转另存为） |
| 文件 ▸ | 另存为… | Ctrl+Shift+S | 同现有（`doSaveAs`） |
| 文件 ▸ | 关闭标签页 | Ctrl+W | 同现有（未保存确认流程） |
| 文件 ▸ | 编码 ▸ | — | 原样整体迁入（通过编码重新加载 ▸ / 通过编码保存 ▸，三级级联保留） |
| 搜索 ▸ | 查找… | Ctrl+F | 同 `Ctrl+F`（`doFind`）：打开对话框聚焦查找框，选区预填、多光标自动退出 |
| 搜索 ▸ | 替换… | Ctrl+H | 同 `Ctrl+H`（`doReplace`）：打开对话框聚焦替换框 |
| 搜索 ▸ | 下一个 | F3 | 同对话框关闭态 `F3`（`searchJumpGlobal(true)`）：沿用上次查找参数与保留的匹配状态跳转 |
| 搜索 ▸ | 上一个 | Shift+F3 | 同对话框关闭态 `Shift+F3`（`searchJumpGlobal(false)`） |
| 视图 ▸ | 深色主题 / 自动换行 | — | 原样保留（仅子菜单标题由「查看」改为「视图」） |
| — | 退出 | — | 原样保留在顶层 |

### 边界与约束

- 「搜索」四项均要求有活动文档：欢迎页（无文档）时置灰，与「保存」「关闭标签页」现状一致。
- 「下一个 / 上一个」为对话框关闭态语义（DEC-009）：沿用上次查找串与控制器保留的匹配状态跳转，**不恢复全部高亮**；无查找串或无匹配时无操作。
- 查找对话框为模态，打开期间主菜单不可达，因此菜单项无需处理「对话框已打开」分支。
- 菜单项 `onTriggered` 执行时菜单已关闭（`menuVisible` 为 false），不会被 `Main.uiLocked()` 早退拦截——与现有「菜单→保存」「菜单→退出」同一路径。
- 快捷键仍由窗口级 `Shortcut` 统一处理，菜单仅用 `KeyMenuItem` 自绘右对齐快捷键文本（不新增按键绑定）。
- 「文件」子菜单内条目的 enabled 绑定、注释、行为原样保留，仅层级变化。

## 输入输出

- 输入：菜单点击（主菜单 → 搜索 → 各条目）。
- 输出：
  - 「查找… / 替换…」：打开查找替换对话框（顶部对齐模态）并聚焦对应输入框；
  - 「下一个 / 上一个」：当前文档内跳转到下一/上一匹配（原生选区 + 滚动可见），不修改文档内容。

## 非功能需求（性能/安全/兼容性）

- 纯 QML 改动（`TitleBar.qml` / `Main.qml`），不触碰 C++（`SearchEngine` / `SearchController`）接口与行为。
- 既有行为零回归：文件/编码/视图(查看)/退出条目、全部窗口级快捷键、Tab 区、标题栏拖拽/双击最大化。
- 样式沿用 `AppTheme` 语义 token 与既有 `KeyMenuItem` 款式，无新增硬编码色值。
- 不引入新依赖、新 QML 模块。

## 依赖

- 现有 `Main.qml` 的 `doFind()` / `doReplace()` / `searchJumpGlobal(forward)`。
- `SearchDialog` / `SearchController`（会话级单实例，`EditorArea.searchController`）。
- `TitleBar.qml` 的 `KeyMenuItem` 内联组件（需提升至根作用域供子菜单复用）。

## 验收标准

1. 菜单结构与命名符合上表；原「查看」显示为「视图」。
2. 欢迎页（无文档）时「搜索」四项置灰；有文档时可用。
3. 「查找… / 替换…」打开对话框并聚焦对应输入框，选区预填生效，多光标激活时先退出。
4. 「下一个 / 上一个」与 `F3` / `Shift+F3` 行为一致（含无匹配时无操作、不恢复全部高亮）。
5. 「文件」「编码（三级级联）」「视图」「退出」零回归；`ctest` 全绿；offscreen 冒烟不崩溃。
